# 返金について

SimiRouter 中継サービスをご利用いただきありがとうございます。返金を申請する場合は、以下の説明をよくお読みください。

## 1. 返金条件

次の条件を満たすアカウントは返金を申請できます。

1. アカウント所有者本人による申請であること。
2. チャージから 120 日以内であること。
3. 規約違反の利用記録がないこと。
4. 返金可能な現金元本の残高があること。

API の不正利用、プラットフォームへの攻撃、架空取引、異常な裁定取引、不正な再販売などがある場合、プラットフォームは審査を停止、または返金を拒否する権利を有します。

## 2. 返金額の計算

返金対象は、実際に支払った現金元本のうち未使用の部分のみです。

計算式は以下のとおりです。

**返金額 = 実際の支払総額 − 使用済み元本**

説明：

* **実際の支払総額**：チャージ時に実際に支払った現金額。付与残高、キャンペーン報酬、紹介報酬、ポイント充当などの非現金部分は含みません。
* **使用済み元本**：実際の API 消費量を、チャージ時の割引率に応じて換算した現金原価。
* **付与残高、キャンペーン報酬、紹介報酬、ポイント充当などは、出金や返金の対象外です。**

### 例 1：割引なしのチャージ

100 元分を 100 元で購入し、50 元分を使用した場合：

**返金額 = 100 − 50 = 50 元**

### 例 2：割引付きチャージ

100 元分を 80 元で購入した場合は 20% 割引です。50 元分を使用した場合：

使用済み元本 = 50 × 0.8 = 40 元

返金額 = 80 − 40 = 40 元

### 例 3：複数回のチャージ

複数のチャージ記録がある場合、時刻、チャージ額、実際の支払額、割引、利用記録を総合して計算します。

最終的な返金額は、システムの消費記録と会計審査の結果によって決まります。

## 3. 手数料

通常の返金では、追加の返金手数料は請求しません。

返金額は、実際の支払額、使用済み残高、チャージ時の割引、返金可能な元本残高に基づいて計算します。

以下の特別な事情で追加手数料が発生した場合、実費に基づき処理し、返金前に確認します。

1. 元の支払い経路で返金できない場合。
2. 別の支払いアカウントへの返金を希望する場合。
3. 銀行振込、国際送金、第三者アカウントへの送金で実費が発生する場合。
4. 誤った受取情報や送金の返却・再送などで追加費用が発生する場合。

上記以外の通常の返金で、追加手数料は差し引きません。

## 4. 申請手順

1. 管理画面にログインし、オンラインサポートに連絡します。
2. サポートの指示に従って申請情報を提出します。
3. 24 時間以内に受け付け、審査に入ったことを通知します。
4. 審査と返金は通常 3～7 営業日で完了します。
5. 返金完了後、プラットフォームから通知します。

## 5. 返金申請に必要な情報

アカウントと資金の安全のため、次の情報を提出してください。

1. **本人確認情報**
   サポートの指示に従い、登録メール、UID、現在のログイン状態のスクリーンショット、登録メールからの指定確認メールなど、所有者本人であることを証明する情報を提出します。
2. **返金理由**
   返金を申請する理由を簡潔に記載します。
3. **受取アカウント情報**
   元の支払い経路での返金を優先します。できない場合は、サポートの指示に従い、Alipay、WeChat、銀行口座などの受取情報を提出します。

提出情報が真実、正確、完全であることを確認してください。誤った情報による返金失敗、遅延、追加費用の影響はユーザーが負担します。

## 6. 重要事項

1. 付与残高、キャンペーン報酬、紹介報酬、ポイント充当などの非現金部分は返金しません。
2. 使用済みの残高は返金しません。
3. 残高を使い切った、未払いがある、返金可能な現金元本がない場合は返金できません。
4. 同じアカウントで累計返金回数が 2 回超、または累計返金額が 2000 元超の場合、追加の手動審査が必要です。
5. 異常なチャージや消費、悪意ある返金、裁定取引が見つかった場合、プラットフォームは返金審査を停止する権利を有します。
6. 返金額に疑問がある場合、結果通知の受領から 7 日以内にサポートへ再審査を申請してください。

## 7. お問い合わせ

サポート対応時間：毎日 9\:00 - 21\:00

窓口：管理画面にログインし、オンラインサポートから返金を申請してください。

本説明は SimiRouter 中継サービスの返金処理に適用されます。規則が変更された場合、最新のお知らせまたはサポートの説明に従います。
