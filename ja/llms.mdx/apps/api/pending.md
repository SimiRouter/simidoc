# その他の機能と今後の接続参考

この節では、まだ SimiRouter の汎用機能として公開されていないインターフェースを収録します。埋め込み、ファイル、ファインチューニング、Realtime、モデレーション、再ランキングです。これらと有効化済みの機能との違いはプロトコルの難しさではなく、ゲートウェイがルーティング、認証、課金を提供しているかどうかにあります。

## 概要

まず状態を確認し、それからコードを書くかどうかを決めてください。この節に含まれていても、状態が同じとは限りません。

| 状態         | 意味                                   | 今できること                                     |
| ---------- | ------------------------------------ | ------------------------------------------ |
| 明確に未対応     | ゲートウェイはこの機能を提供せず、ドメインを変えても利用可能になりません | ベンダーへの直接接続の参考としてのみ、ベンダーのキーを使用できます          |
| 現在未対応      | 現在は公開されておらず、プロトコル自体は安定しています          | ベンダーへの直接接続として検証し、ゲートウェイ経由の呼び出しとして書かないでください |
| チャネルの確認が必要 | 利用可能かどうかはアカウントとチャネルの設定に依存します         | まずモデルとルートを確認し、それから依存するかどうかを決めてください         |

## 中核となる概念

* **直接接続の参考**：この節の例のアドレスと認証はベンダーに属します。`api.openai.com` をゲートウェイのドメインに変えても機能が利用可能になるわけではなく、パス、フィールドのマッピング、権限がすべてチャネルで明確にサポートされている必要があります。
* **キーの帰属**：ベンダーのキーと SimiRouter キーは相互に互換性がありません。直接接続の例では必ず対応するベンダーのキーを使用し、ゲートウェイのキーを入れてはいけません。
* **リソースの帰属**：ファイル ID、タスク ID、セッション ID は、それらを作成したプロジェクトまたは組織に属し、ベンダー間やプロジェクト間で直接再利用することはできません。
* **状態と課金**：非同期タスクはまず ID を返し、その後で状態を照会します。作成の成功は実行の成功を意味せず、タスクのキャンセルも既に発生した利用量が取り消されることを意味しません。

## 機能一覧

| 分類         | SimiRouter の状態 | プロトコルの性質                     | 参考                            |
| ---------- | -------------- | ---------------------------- | ----------------------------- |
| 埋め込み       | 現在未対応          | 同期ベクトル応答、独立したバッチタスク          | [埋め込み](/simidoc/ja/apps/api/pending/embeddings)          |
| ファイル管理     | 未対応            | アップロード、一覧、メタデータ、ダウンロード、削除    | [ファイル](/simidoc/ja/apps/api/pending/files)               |
| ファインチューニング | 未対応            | 非同期学習タスクの作成、状態、イベント          | [ファインチューニング](/simidoc/ja/apps/api/pending/fine-tuning)   |
| Realtime   | 専用チャネルの確認が必要   | WebRTC / WebSocket のステートフル会話 | [Realtime](/simidoc/ja/apps/api/pending/realtime)        |
| モデレーション    | モデルとルートの確認が必要  | 同期の安全性分類。チャットフィルタの保証ではありません  | [コンテンツモデレーション](/simidoc/ja/apps/api/pending/moderations) |
| 再ランキング     | モデルとルートの確認が必要  | 同期の文書関連度ランキング                | [再ランキング](/simidoc/ja/apps/api/pending/rerank)            |

音楽インターフェースについては [音楽（未対応）](/simidoc/ja/apps/api/music) も参照してください。リアルタイム会話、アップロードリソース、学習タスクは通常、追加の権限、ストレージ、費用を伴うため、アプリケーションに組み込む前にデータの保持と削除のポリシーを明確にしてください。
