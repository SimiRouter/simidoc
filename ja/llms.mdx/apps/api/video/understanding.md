# 動画理解

動画理解は既存の動画を入力とし、要約、画面の説明、イベントの順序、質問への回答を返します。プロンプトから新しい動画を生成する機能ではありません。Dots、Kimi、Gemini はいずれも動画入力を提供しますが、コンテンツ形式、ファイル参照方式、認証が異なります。

## メーカーとプロトコル

| 文書                      | 公式例のモデル            | 動画入力                                              | リクエストとレスポンス                                                   |
| ----------------------- | ------------------ | ------------------------------------------------- | ------------------------------------------------------------- |
| [Dots 動画理解](/simidoc/ja/apps/api/video/understanding/dots)     | `dots3-note-prev`  | モデルサービスがアクセス可能な `video_url.url`                   | Chat Completions のメッセージ配列。最終テキストは `choices[].message.content` |
| [Kimi 動画理解](/simidoc/ja/apps/api/video/understanding/kimi)     | `kimi-k3`          | Base64 の動画 data URL、または Moonshot の `ms://` ファイル参照 | Chat Completions のメッセージ配列。最終テキストは `choices[].message.content` |
| [Gemini 動画理解](/simidoc/ja/apps/api/video/understanding/gemini) | `gemini-3.8-flash` | インライン動画データまたは Google が対応するファイル URI                | 本ページでは Interactions を使用。テキストは `steps[].content[]`             |

Dots の動画リクエストは公式の `api-key` ヘッダー、Kimi は Bearer、Gemini は `x-goog-api-key` を使用します。Dots と Kimi の `video_url` は、メーカーが対応するマルチモーダル拡張であり、すべての OpenAI 互換サービスに対応する動画の共通規格ではありません。パスが同じ `/v1/chat/completions` であることだけを理由に、動画ペイロードを相互利用できるとは限りません。

## 同期、ストリーミング、ファイル参照

* **非ストリーミング**：1 回の HTTP リクエストでテキストレスポンス全体を待ちます。動画生成のタスク ID は返しません。
* **ストリーミング**：SSE でテキストの増分を返します。最初のイベントの前に動画のダウンロード、デコード、分析が必要な場合があります。ストリーミングはカメラの継続アップロードを意味せず、最初の文字がすぐに返る保証もありません。
* **ファイル参照**：先にメーカーのストレージへアップロードし、その後の分析リクエストで参照します。アップロード完了は分析完了を意味せず、メーカー間でファイル ID は共用できません。
* **並列リクエスト**：クライアントが複数の独立したリクエストを発行します。各リクエストのレート制限、コンテキスト、使用量は別々に計算され、本文内の「並列」パラメーターで制御するものではありません。

## 入力の準備

処理する権限のある動画を使用してください。公開動画の直接リンク、プラットフォームの共有ページ、ローカルパス、Base64 データは異なる入力であり、対応するプロトコルで渡す必要があります。小紅書などの共有ページは、ダウンロード可能な動画ファイル URL と同じではありません。ログインやホットリンク防止が必要な動画をモデルサービスが読み取れるとは限りません。

動画の長さ、解像度、サンプリングフレーム数、ファイルサイズは、所要時間、Token、料金に影響します。具体的な制限はメーカーのページを参照してください。時点とイベントの判断は元の動画と照合し、厳密なフレーム単位の証拠分析や強制アライメントの結果として扱わないでください。

## SimiRouter への接続

上記のサブページはメーカー公式への直接接続例であり、メーカーの Key を使用します。SimiRouter から呼び出す場合は、アカウントで利用可能な完全なモデル ID、チャネルの動画入力マッピング、ファイル参照の対応状況を確認してください。モデルが公式に対応していることを、そのまま当サイトでの結合テスト済みと記載してはいけません。メーカーの Key と SimiRouter Key は共用できません。
