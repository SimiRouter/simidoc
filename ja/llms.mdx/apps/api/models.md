# モデル一覧

モデル一覧は接続設定の入口です。まずモデル ID を取得し、次にベンダーの能力ドキュメントに従ってチャット、視覚、画像、音声、ツールの各インターフェースを選択します。参照できることは呼び出せることを意味せず、モデル一覧もリアルタイムのヘルスチェックではありません。

## 概要

| 確認したいこと          | どこで見るか                | 説明                                     |
| ---------------- | --------------------- | -------------------------------------- |
| どのようなモデル ID があるか | 本節の一覧インターフェース         | 現在の認証情報から参照できるモデルのみを返します               |
| 実際に呼び出せるか        | モデルと価格 + 1 回の実リクエスト   | 参照可能、ルーティング可能、クォータありは三つの異なる事柄です        |
| どのような入出力に対応するか   | モデル能力の説明              | 一覧のメタデータは通常不完全です                       |
| いつ提供終了になるか       | ベンダーによる非推奨化や提供終了の公式告知 | 非推奨は直ちに利用不可を意味しませんが、新規接続には使用すべきではありません |

## 中核となる概念

* **モデル ID**：リクエスト本文で使用する一意の識別子で、通常は大文字と小文字を区別します。完全にコピーする必要があり、独自に省略しないでください。表示名、エイリアス、実際のリクエスト ID は異なる場合があります。
* **参照可能とルーティング可能**：一覧は権限範囲内のモデルのみを反映し、チャネルが未設定、残高不足、またはレート制限の場合には依然として失敗します。
* **コンテキストウィンドウ**：入力と出力を合わせた Token の上限で、モデルごとに異なります。一覧インターフェースはこの値を返さないことがよくあります。
* **課金単位**：テキストモデルは主に Token 単位、画像モデルは画像単位または Token 単位、動画モデルは秒単位または回数単位が多く、同じモデルファミリー内でも異なる場合があります。
* **終了日**：ベンダーがサービス停止を予定している日を示します。移行は期限前に完了すべきで、期限が過ぎてから気づくべきではありません。

## 照会インターフェース

| ドキュメント                | リクエスト              | 返却構造                                       |
| --------------------- | ------------------ | ------------------------------------------ |
| [OpenAI 形式](/simidoc/ja/apps/api/models/openai) | GET /v1/models     | data\[].id。OpenAI 互換クライアントに適しています。         |
| [Gemini 形式](/simidoc/ja/apps/api/models/gemini) | GET /v1beta/models | models\[].name。Gemini プロトコルのクライアントに適しています。 |

## 呼び出し方法

一覧の照会は同期 JSON リクエストで、SSE には対応せず、非同期タスクでもありません。複数のアカウントはそれぞれ並列に照会できますが、認証情報と結果を混用することはできません。一覧のキャッシュには有効期限を設定し、モデルが利用できなくなったことに気づいたら再読み込みしてください。一覧の更新のために実際の生成リクエストを送信しないでください。

## シミュレーション呼び出し

リクエスト本文を付けずに GET を送信します。以下は SimiRouter ゲートウェイの応答例です。

```bash
curl "https://api.dwchainless.com/v1/models" \
  -H "Authorization: Bearer $SIMIROUTER_API_KEY"
```

```json
{
  "object": "list",
  "success": true,
  "data": [
    {
      "id": "MODEL_ID",
      "object": "model",
      "created": 1626777600,
      "owned_by": "custom",
      "context_length": 1048576,
      "supported_endpoint_types": ["openai"]
    }
  ]
}
```

ゲートウェイはコンテキスト長とエンドポイントの種類を返します。コンテキスト長にはプラットフォームの既定値が使われる場合があります。料金、入出力のモダリティ、ツールの対応状況はモデルのドキュメントで確認してください。一覧が空の場合、通常は現在の認証情報で参照できるモデルがありません。

## メタデータの境界

OpenAI のモデルオブジェクトには id、object、created、owned\_by が含まれます。Google のネイティブなモデルオブジェクトにはメソッドと Token 制限が含まれる場合があります。ゲートウェイは簡略化したメタデータのみを返すことがあるため、欠落したフィールドからコンテキスト上限、モダリティ、ツール対応を推測してはいけません。
