# Codex デスクトップ版のインストール

## ダウンロードとインストール

1. 開くページは [OpenAI Codex 公式ページ](https\://chatgpt.com/codex)から OS に合うインストーラーを選択します。
2. インストール後にアプリを開きます。システム要件とインストーラーの提供状況は公式ページに従います。
3. [Codex デスクトップ版の設定](/simidoc/ja/apps/codex-desktop)に従い、モデルプロバイダーと Key 設定をマージします。

インストールと設定の完了後、低リスクのタスクを依頼し、SimiRouter の使用ログで実際のモデルと使用量を確認します。アプリやログイン画面が開くだけでは、ゲートウェイ接続の成功は確認できません。
