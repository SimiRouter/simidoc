# Gemini CLI のインストール

## **前提条件：Gemini CLI のインストール**

Node.js（v20 以降）がインストールされていることを確認し、npm でグローバルにインストールします。

```bash
npm install -g @google/gemini-cli
```

完了後、成功を確認します。

```bash
gemini --version
```

最新版への更新：

```bash
npm upgrade -g @google/gemini-cli
```

## モデルサービスを設定

インストール後は [Gemini CLI の設定](/simidoc/ja/apps/gemini-config)に従って SimiRouter アドレスと API Key を設定します。
