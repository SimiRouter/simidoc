# LangBot の設定

LangBot は接続情報をプロバイダーに保存し、個々のモデルが参照します。OpenAI 互換プロバイダーで SimiRouter のチャットモデルを設定できます。

## プロバイダーとモデルを作成

1. [LangBot 公式ドキュメント](https\://docs.langbot.app/)に従ってインストールし、起動します。
2. SimiRouter の [API Key 管理](https://api.dwchainless.com/keys)から Key をコピーします。
3. LangBot のモデルページでチャットモデルを追加し、OpenAI 互換プロバイダーを選ぶか、対応するプロバイダーを作成します。
4. 接続情報を設定します。

| フィールド                | 内容                               |
| -------------------- | -------------------------------- |
| Base URL / リクエスト URL | `https://api.dwchainless.com/v1` |
| API Key              | SimiRouter API Key               |
| モデル名                 | アカウントで利用可能な完全なモデル ID             |

モデルは所属するプロバイダーのアドレスと Key を継承します。実際のモデル機能に応じて視覚やツール利用を有効にしてください。これらのスイッチは、モデルに本来ない機能を付与するものではありません。

## パイプラインに紐づけ

パイプラインで追加したモデルを選び、保存後にデバッグ対話または紐づけ済みボットからメッセージを送信します。SimiRouter の [使用ログ](https://api.dwchainless.com/usage-logs/common)で時刻、モデル、消費量を確認します。

## ナレッジベースと埋め込み（未対応）

LangBot のナレッジベースには埋め込みモデルが必要です。SimiRouter は現在、埋め込み連携に未対応であり、当サイトのチャットモデル設定をナレッジベースのベクトルサービスとして使用できません。必要な場合は LangBot が対応する埋め込みプロバイダーを別途設定するか、公式の説明に従って組み込み方式を選択してください。

## 公式資料

[LangBot モデル設定](https\://docs.langbot.app/zh/usage/models/readme)に、プロバイダー、チャットモデル、埋め込みモデル、パイプラインの関係が説明されています。
