# WorkBuddy チュートリアル

<Callout type="info" title="適用範囲">
  このチュートリアルは「カスタムモデルの設定」に対応する WorkBuddy
  デスクトップクライアントが対象です。バージョンによって項目や設定が多少異なる場合があります。実際の画面に従ってください。
</Callout>

## 前提条件

設定前に以下を確認してください。

* WorkBuddy がインストール・起動済みで、「カスタムモデルの設定」が見つかること。
* SimiRouter に登録済みで、コンソールの「API Key」ページで Key を作成済みであること。
* 利用する完全なモデル ID を確認し、API Key に対応モデルの呼び出し権限と残高があること。

[API Key 管理を開く](https\://api.dwchainless.com/keys)

## 設定手順

### 1. 「カスタムモデルの設定」を開く

WorkBuddy の対話画面で入力欄右下のモデル名をクリックし、一覧から **「カスタムモデルの設定」**。

![モデル一覧から「カスタムモデルの設定」を開く](/simidoc/assets/workbuddy/open-custom-model.png)

モデル管理ページで **「モデルを追加」**&#x3092;クリックします。すでに「モデルを追加」ウィンドウが開いている場合は次へ進みます。

### 2. プロバイダーを「カスタム」に設定

「モデルを追加」ウィンドウで **「プロバイダー」**&#x306E;ドロップダウンを開き、下へスクロールして「その他」から **「カスタム」**。

![プロバイダー一覧の「その他」で「カスタム」を選択](/simidoc/assets/workbuddy/select-custom-provider.png)

選択後、「プロバイダー」フィールドが **「カスタム」**。

### 3. API アドレス、API Key、モデル名を入力

以下の表に従って基本情報を入力します。

| 設定項目     | 入力内容                                              |
| -------- | ------------------------------------------------- |
| プロバイダー   | カスタム                                              |
| API アドレス | `https://api.dwchainless.com/v1/chat/completions` |
| API Key  | SimiRouter で作成した API Key                          |
| モデル名     | 呼び出す完全なモデル ID                                     |

**API アドレス：** 上の表のアドレスを省略せずコピーし、末尾の `/v1/chat/completions` を保持してください。

**API Key：** Key 本体のみを貼り付け、`Bearer`、引用符、説明文を追加せず、前後の余分な空白も確認します。

**モデル名：** SimiRouter の現在利用可能なモデル情報から完全なモデル ID をコピーしてください。中国語の説明、独自の別名、不完全なシリーズ名は使用しないでください。API Key でそのモデルを呼び出せることを確認します。

### 4. 詳細オプションを設定

初回は入力と出力のデフォルト設定を維持し、その他の項目を選択モデルと現在のチャネルの機能に応じて設定することを推奨します。

| 設定項目          | 推奨設定                                                  |
| ------------- | ----------------------------------------------------- |
| ツール呼び出し       | ツールを使うタスクが必要な場合に選択し、モデルとチャネルがツール呼び出しに対応することを確認。       |
| 画像入力          | 画像処理が必要で、モデルとチャネルが対応する場合に選択。                          |
| 思考モード         | 選択モデルの対応説明に従って設定。初回は未選択のままでも構いません。                    |
| カスタムプロトコル     | 明確な設定要件がない場合は未選択。                                     |
| 思考強度（表示される場合） | まずデフォルトを維持し、明確な必要性がある場合に調整。                           |
| 入力／出力         | まず「プロバイダーのデフォルトを使用」を維持することを推奨。手動設定時はモデルとチャネルの長さ制限を確認。 |

![カスタムモデル設定フォーム：API アドレス、API Key、モデル名、詳細オプション](/simidoc/assets/workbuddy/custom-model-form.png)

*スクリーンショットは中国語 UI の設定項目の例です。上記の説明に従い、自分の API Key と実際のモデル ID を入力してください。*

### 5. 接続をテストし、保存してモデルを選択

入力後、**「接続テスト」**&#x3067;接続を確認し、次に **「保存」**&#x3092;クリックします。テストに失敗した場合は、以下の「よくある質問」を参照してください。

WorkBuddy の対話画面に戻り、入力欄右下のモデル一覧を開き、**追加したカスタムモデルを選択**して、短いメッセージを送信します。例：

```text
请只回复：连接成功。
```

正常な応答後、SimiRouter コンソールで対応時刻の呼び出し記録を確認し、使用したモデルを照合します。

基本的な対話が正常になってから、必要なツール呼び出し、画像入力、思考モードを個別にテストします。

## よくある質問

問題が発生したら、まずエラーメッセージ全体を読み、以下の表で調査します。

| 発生した問題              | 確認方法                                                |
| ------------------- | --------------------------------------------------- |
| 「カスタムモデルの設定」が見つからない | クライアントのバージョンが対応しているか確認し、対話画面右下のモデル一覧を開いていることを確認。    |
| 接続テストまたはメッセージ送信に失敗  | エラーに従い、API アドレス、API Key、モデル ID、呼び出し権限、利用可能な残高を順に確認。 |
| 保存したが対話は元のモデルのまま    | 対話画面に戻り、モデル一覧から保存したカスタムモデルを選択。                      |
| 画像入力や思考モードを有効にすると失敗 | 直前に正常だった設定へ戻し、モデルとチャネルがその機能に対応するか確認。                |
| 長い会話や出力でエラー         | モデルとチャネルの長さ制限を確認。エラーに応じて入力を短くするか出力上限を下げる。           |

調査の支援が必要な場合は、**WorkBuddy のバージョン、モデル ID、リクエスト時刻、エラーメッセージ全体**。

<Callout type="warn" title="Key の安全性に関する注意">
  API Key を厳重に管理してください。スクリーンショット、ログ、エラー情報を提出する前に Key 全体を非表示にし、公開の場で共有しないでください。
</Callout>
