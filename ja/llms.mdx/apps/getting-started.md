# SimiRouter Key の登録

このガイドは、SimiRouter の登録・ログイン、API Key の作成、最初の呼び出しを説明します。アカウントを持っている場合は直接ログインできます。具体的なクライアント操作と API パラメーターは、それぞれのドキュメントで説明します。

## 1. SimiRouter に登録またはログイン

移動先は [登録ページ](https://api.dwchainless.com/sign-up)です。アカウントを作成します。すでにお持ちの場合は直接 [ログイン](https://api.dwchainless.com/sign-in)できます。登録方式と新規登録の可否は、実際のページ表示に従います。

ログイン後に [ウォレット](https://api.dwchainless.com/wallet)を開き、利用可能な残高があり、選択モデルがアカウントグループと Key の権限に含まれることを確認します。チャージや引き換えコードはウォレットページの案内に従ってください。プラン、反映額、有効期間はそのページに表示されます。重複して支払わないでください。

## 2. API Key を作成

[API Key 管理](https://api.dwchainless.com/keys)を開き、「Key を作成」を選択します。必要に応じてグループ、モデル権限、残高上限、有効期限を設定します。不明な項目はページの説明を確認し、保存して Key をコピーします。

![API Key 管理ページと作成ボタン](/simidoc/assets/start/start5.png)

<Callout type="warn" title="Key の保護">
  API Key は呼び出し権限を表します。公開リポジトリ、スクリーンショット、ログに含めず、信頼できないアプリに渡さないでください。漏えいの疑いがある場合は、直ちに取り消して作り直してください。
</Callout>

## 3. 3 種類の接続情報を区別

| 情報                  | 用途           | 注意点                                                                  |
| ------------------- | ------------ | -------------------------------------------------------------------- |
| API アドレス / Base URL | リクエストの送信先を決定 | クライアントのチュートリアルに従います。`/v1` が必要なものとルートアドレスが必要なものがあります。パスを重複追加しないでください。 |
| API Key             | 呼び出し権限を認証    | 作成した Key を使用します。ログインパスワードではありません。                                    |
| モデル名                | 呼び出すモデルを選択   | 対象の [モデル一覧](https://api.dwchainless.com/ja/pricing/) から完全なモデル ID をコピーします。名前、グループ、権限を一致させてください。      |

API アドレス、Key、モデル名は独立した 3 つのフィールドです。Key をアドレスに組み込まないでください。

## 4. 使用するクライアントを選択

* [Codex デスクトップ版](/simidoc/ja/apps/codex-desktop)：デスクトップでのコーディングワークフロー。
* [Codex CLI](/simidoc/ja/apps/installation/codex-cli)：CLI のインストールと接続。
* [Claude Code](/simidoc/ja/apps/installation/claude-code)：インストール、環境設定、利用方法。
* [WorkBuddy](/simidoc/ja/apps/workbuddy)：デスクトップのカスタムモデル接続。
* [API スクリプト](/simidoc/ja/apps/api-script)：リクエスト例で自分のプログラムに組み込み。

クライアントごとにフィールドとプロトコルが異なります。対応するチュートリアルに従い、別のクライアントの設定ファイルを流用しないでください。

## 5. 小規模なテストを行い、記録を確認

設定を保存して短いリクエストを送信し、次に [使用ログ](https://api.dwchainless.com/usage-logs/common) を開きます。時刻、モデル、状態、消費量を確認します。スーパー管理者は全体のログ、管理者は自分のリクエスト・入金・管理操作・エラーログを確認できます。一般ユーザーは自分のリクエスト・入金・管理操作に関するログのみ確認でき、エラーログは表示されません。集計傾向を見る場合は [ダッシュボード](https://api.dwchainless.com/dashboard)を使用します。

モデルから応答があったことは、そのリクエストが結果を返したことのみを示します。内容だけで実際の経路は確認できません。失敗時はまずアドレス、Key、完全なモデル ID、グループ権限を確認し、具体的なエラーとリクエスト ID から調査します。サポートには機密情報を除いた内容を送り、Key を添付しないでください。
