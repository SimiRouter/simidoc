# Chatbox AI の設定

このチュートリアルは Chatbox AI 1.21.1 のデスクトップ画面を例に、組み込みの **OpenAI** モデルプロバイダーで SimiRouter に接続します。他のバージョンでは画面の名称や位置が異なる場合があります。以下のスクリーンショットは中国語 UI の例です。

<Callout type="warn" title="API Key の保護">
  API Key は呼び出し用の認証情報です。他人との共有や公開スクリーンショットへの表示を避けてください。接続チェックと実際の対話は課金される場合があるため、アカウントの残高とモデル料金を先に確認してください。
</Callout>

## 事前準備

1. ダウンロード先は [Chatbox AI 公式サイト](https\://chatboxai.app/)です。クライアントをインストールしてください。
2. SimiRouter にログインし、[API Key 管理](https://api.dwchainless.com/keys)ページで Key を作成またはコピーして、対象モデルの利用権限と残高があることを確認します。

![SimiRouter の API Key 管理ページ。Key 情報はマスク済み](/simidoc/assets/chatbox/03a-create-api-key.png)

## 接続の設定

### 1. 設定を開いてプロバイダーを選択

Chatbox のメイン画面左下の **設定** をクリックします。

![Chatbox の設定を開く](/simidoc/assets/chatbox/01-open-settings.png)

**モデルプロバイダー** を開き、**OpenAI** を選択します。このチュートリアルは API Key を使用するため、OAuth ログインは不要です。この操作は OpenAI プロバイダーの設定を変更します。すでに別のサービスに接続している場合は、意図しない上書きを避けるため、元の設定を記録してください。

![モデルプロバイダーで OpenAI を選択](/simidoc/assets/chatbox/02-select-openai.png)

### 2. API Key とホストを入力

| 設定項目             | 入力内容                                              |
| ---------------- | ------------------------------------------------- |
| API Key          | コピーした SimiRouter Key を貼り付け                        |
| API ホスト          | `https://api.dwchainless.com`                     |
| リクエスト URL のプレビュー | `https://api.dwchainless.com/v1/chat/completions` |

API ホストは上の表のとおりに入力し、デフォルトの API パスを維持してください。ホストの後ろに API パスを手動で追加しないでください。以前 API パスを変更した場合は、デフォルトに戻してプレビュー URL を確認します。

![OpenAI プロバイダーに API Key とホストを入力](/simidoc/assets/chatbox/03b-fill-api-fields.png)

### 3. モデルを取得して追加

モデル領域の **取得**をクリックし、検索してモデル右側の **+** で追加します。一覧を取得できない場合は、**新規作成**で、アカウントで利用可能な正確なモデル ID を手動入力できます。一覧内のすべてのモデルが現在の Key に開放されているとは限りません。アカウントの権限とモデル一覧に従ってください。

![モデルを検索して追加](/simidoc/assets/chatbox/04-add-models.png)

### 4. 接続を確認して対話を開始

使用するモデルの **チェック**をクリックします。テストが「接続成功」でも、短いメッセージを送信して実際の対話を確認することを推奨します。一部のモデルはテキストのみに対応します。画像やツール呼び出しのチェックに失敗しても、テキストが利用できないとは限りません。

![サンプルモデルの接続チェック結果](/simidoc/assets/chatbox/05-check-success.png)

設定を閉じ、**新しいチャット**をクリックします。入力欄横のモデル選択メニューで、追加した OpenAI グループのモデルを選び、短いメッセージを送信します。応答を受信したら、SimiRouter の使用ログでリクエストと実際のモデルを確認できます。

![新しいチャットを作成し、追加したモデルを選択](/simidoc/assets/chatbox/06-new-chat-select-model.png)

## よくある質問

* **モデルを取得できない：** ネットワーク、ホストアドレス、Key を確認します。正確なモデル ID を手動で追加することもできます。
* **401 または認証失敗：** Key が完全で有効か、前後に空白がないか確認します。必要に応じて Key を再作成してください。
* **404 またはパスのエラー：** リクエスト URL のプレビューを確認し、API パスをデフォルトに戻してパスの重複を避けます。
* **モデルが存在しない、または対話できない：** 実際のモデル ID、Key の権限、アカウント残高を確認し、対話で正しいモデルを選択していることを確認します。
* **画像やツール呼び出しに失敗する：** モデルと API が対応機能をサポートするか確認します。テキストのみが必要な場合は、テキストリクエストを個別に検証できます。
