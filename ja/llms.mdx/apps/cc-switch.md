# CC Switch の設定

## CC Switch のダウンロード

1. 開くページは [CC Switch ダウンロードページ](https\://github.com/farion1231/cc-switch/releases/latest)です。GitHub Releases から OS に合うインストーラーを選び、インストールします。

## モデルサイトのインポート機能を使用

### クイックインポート `Codex`

![SimiRouter の Key メニューにある CC Switch インポート項目](/simidoc/assets/cc_switch/cc1.png)

Codex モデルグループを使用するトークンを選び、インポート横の矢印から CC Switch を選択

プロバイダー名と Codex モデルを入力
![CC Switch のプロバイダー名とモデルの入力](/simidoc/assets/cc_switch/cc2.png)

表示された`此站点正在尝试打开 CC Switch。`確認画面で開くことを選択
![ブラウザーが CC Switch を開く許可を求める確認ウィンドウ](/simidoc/assets/cc_switch/cc3.png)

インポート予定のプロバイダー設定が正しいか確認
![CC Switch にインポートするプロバイダー設定のプレビュー](/simidoc/assets/cc_switch/cc4.png)

問題がなければインポートを選択
![CC Switch でプロバイダーのインポートを確認](/simidoc/assets/cc_switch/cc5.png)

インポート後は短いメッセージを送信してテストします。IDE に接続する場合は、[サードパーティープラグイン設定（VS Code Roo）](/simidoc/ja/apps/roo-code)のフィールド説明を参照し、現在のアカウントで利用可能なモデル名を使用してください。プラグインによって設定項目が異なる場合があります。
![CC Switch のインポート後のプロバイダー設定ページ](/simidoc/assets/cc_switch/cc6.png)

CC Switch から現在のアカウント残高を確認できます。残高不足によるタスク中断を避けるため、必要に応じてチャージしてください。
![CC Switch のアカウント残高照会ページ](/simidoc/assets/cc_switch/cc7.png)
