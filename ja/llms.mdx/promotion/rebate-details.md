# 紹介還元の説明

## 還元規則の説明

### 紹介関係の確認

* 紹介されたユーザーは登録時に紹介者のリンクを使用する必要があります。それ以外では紹介関係を確認できません。
* 紹介者はコンソールの[紹介情報](https://api.dwchainless.com/promotion)で、専用リンク経由の登録ユーザー、紐づけ、還元履歴を確認できます。

### 還元規則

* 紹介されたユーザーのチャージ成功後、紹介者はチャージ額の 10% を還元として受け取れます。

### 出金規則

* 紹介詳細で還元額を確認し、出金を申請できます。
  * 出金額は 1000 元以上である必要があります。
* 申請後はプラットフォームが審査し、承認後に出金を実行します。
  * 初回申請時は Alipay、WeChat、銀行口座などの受取情報が必要です。
* 新規紹介ユーザーの還元について：
  * 不正防止のため、新規ユーザーの初回チャージに伴う還元は審査対象です。利用行動が正常と確認された後、紹介者が報酬を受け取れます。詳細はリスク管理と処分の説明を参照してください。

### 還元率

* 通常の紹介者は、紹介されたユーザーのチャージ額の 10% を受け取れます。
* 「プラットフォームパートナー」に申請し、より高い還元率を得ることもできます。比率はユーザーレベルと紹介人数によって決まります。希望する場合はサポートなどから申請してください。

## リスク管理と処分

### 審査の目的

ユーザーの権利保護：悪意ある攻撃を防止し、正常な利用と合法的な権利を保護します。

公正性を守り、良好な利用環境を提供します。

プラットフォームの損失を防止し、経済的利益を保護します。

法令を順守し、適正な運営を確保します。

### 審査範囲

悪意ある攻撃：技術的手段や悪意ある行為でプラットフォームに損害を与える行為。

不正な裁定取引：技術や規則の欠陥を利用して報酬などを得る行為。

不正な宣伝：未許可でプラットフォームを騙り、虚偽の宣伝、追加還元の約束、登録の誘導を行う行為。

市場秩序の侵害：規則に違反して報酬を販売・取引する行為。

プラットフォームの製品を違法活動に利用する行為。

### 審査と処理の流れ

初回チャージ還元の凍結：紹介されたユーザーの初回チャージ後、報酬を「審査待ち」として 7 暦日間凍結します。その間、データ分析と手動確認で異常行為の有無を判断します。

結果通知：審査後、紹介者は詳細ページで結果を確認できます。正常なら自動解除し出金可能残高へ移します。異常なら報酬を取り消し、追加処分の対象となる場合があります。

再審査：結果に異議がある場合、通知から 7 営業日以内に、チャット履歴や実際の関係の証明などを提出できます。プラットフォームは 5 営業日以内に再確認し、最終結果を通知します。

### 処分措置

|    リスク行為    | リスクレベル |          処分措置          |
| :---------: | :----: | :--------------------: |
|    悪意ある攻撃   |    高   |  直ちにアカウントを停止し、永久に利用を禁止 |
|   不正な裁定取引   |    中   | 不正利益を控除し、重大な場合はアカウント停止 |
|    不正な宣伝    |    中   |      重大な場合はアカウント停止     |
|   市場秩序の侵害   |    中   | 金銭的処分を行い、重大な場合はアカウント停止 |
| 製品の違法活動への利用 |    高   |  直ちにアカウントを停止し、永久に利用を禁止 |

### 違反行為

* 同一主体によるアカウントの大量登録。
* 自分自身の招待、自己チャージによる自己還元。
* 虚偽の身元や支払い情報の使用。
* 取引の偽造、架空チャージ、悪意ある返金。
* スクリプトや自動化ツールによる報酬の大量取得。
* 脆弱性、設定ミス、API 異常を利用した報酬取得。
* 紹介関係の操作、売買、悪意ある移転。
* 代理チャージ、資金洗浄、不正決済、その他の違法な手段での参加。
* 悪意ある裁定取引の組織または支援。
* 公正・誠実の原則、ユーザー規約、法令へのその他の違反。
