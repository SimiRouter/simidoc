現在のプロジェクトでアクセス可能なファイルをページング照会します。

SimiRouter は現在この API に未対応です。以下は OpenAI 公式リファレンスで、接続先は api.openai.com。OpenAI プロジェクトのキーが必要で、SimiRouter Key は使用できません。

API の説明

  • メソッド：GET
  • API アドレス：/v1/files
  • 認証：Authorization: Bearer $OPENAI_API_KEY
  • リクエスト型：本文なし。

現在ページの JSON を同期返却。has_more=true の場合は次ページ要求が必要で、1回で全件は返りません。

リクエストパラメータ

パラメータ型必須説明
afterstring、クエリいいえ前ページ末尾のファイル ID。
limitinteger、クエリいいえ1ページ1～10000件、既定10000。例は20。
orderstring、クエリいいえ作成時刻順：asc または desc、既定は desc。
purposestring、クエリいいえ指定用途だけを返します。

戻り値

フィールド型説明
objectstring一覧型。通常 list。
dataFileObject[]現在ページのファイル。下記オブジェクト項目。
first_id / last_idstring現在ページ先頭・末尾のファイル ID。
has_moreboolean次ページがあるか。
フィールド型説明
idstring後続要求で参照するファイル ID。
objectstring固定値は file。
bytesinteger / nullファイルサイズ（バイト）。未取得時は null の場合があります。
created_atinteger作成時刻。Unix 秒。
filenamestringアップロード時のファイル名。
purposestringファイル用途。例：fine-tune、user_data。生成結果ファイルでは fine-tune-results などを使用する場合があります。
expires_atinteger / null、任意有効期限。Unix 秒。未設定時は空の場合があります。
statusstring、非推奨旧状態フィールド：uploaded、processed または error。利用先 API 自身の処理状態の代わりにしないでください。
status_detailsstring / null、任意、非推奨旧状態の説明。学習データ検証エラーはタスクの error を確認します。

コード例

実行環境：Python 3、Node.js 20+、curl、Go 1.20+。各言語の例をそれぞれ .py、.cjs、.sh、.go ファイルとして保存して実行します。

次を設定します：OPENAI_API_KEY を読みます。例は最初の20件を取得し、次ページには前ページの last_id を after クエリとして指定します。

エラーコード

以下は OpenAI 公式直接接続の一般的な HTTP エラーで、SimiRouter の対応状況ではありません。

HTTP ステータスコード意味対処
400パラメータ、ファイル用途、資源状態が要件不適合次を読み取り、error.message と error.param修正後に再送。
401キーがない、または無効OpenAI キーと所属プロジェクトを確認。
403プロジェクト・資源へのアクセス不可プロジェクト、組織、ロール権限を確認。
404ファイル、タスク、モデルが存在しないID を確認し、資源所属プロジェクトのキーを使用。
429レート制限または残高不足レートと残高を区別。前者はバックオフ、後者は再送しません。
500 / 503サーバー異常・一時利用不可ID を保持し、書き込みは作成済みか確認して重複アップロード・学習を防ぎます。

失敗応答には通常 error.message、error.type、error.param と error.code が含まれます。フィールドが空の場合もあります。
