Kling テキストから動画生成

Kling テキストから動画：テキストプロンプトから非同期タスクを送信します。

API の説明

POST https://api-singapore.klingai.com/text-to-video/kling-3.0。認証は Authorization: Bearer $KLING_API_KEY、本文は JSON です。例は Kling 公式新版を使用しており、SimiRouter の /kling/v1/videos/... の旧マッピングではありません。

リクエストパラメータ

フィールド型必須説明
promptstringはい最大 3072 文字。2500 文字以内を推奨。肯定的な内容と除外したい内容の両方を記述可能。
settings.resolutionstringいいえ720p（デフォルト）、1080p、4k。モデルの権限に応じて使用。
settings.durationintegerいいえデフォルトは 5 秒。現在の 3.0 の参考仕様では 3–15 秒。
settings.audiostringいいえoff（デフォルト）または native。ネイティブ音声トラックを生成。
settings.multi_shotbooleanいいえデフォルトは true。この例は false で単一ショットを使用。
settings.aspect_ratiostringいいえ16:9（デフォルト）、9:16、1:1。
options.callback_urlstringいいえタスク状態のコールバック。安全な受信と冪等処理は独自に実装が必要。
options.external_task_idstringいいえアカウント内で一意のカスタムタスク ID。照会に使用し、システム ID を置き換えません。
options.watermark_info.enabledbooleanいいえ透かし付きの結果も提供するかどうか。独自の透かしは未対応。

フィールドが存在するだけでは、異なるモデルの機能制限を判断できません。複数ショットのプロンプトは公式の shot 構文に従い、各ショットの長さの合計を総再生時間と一致させてください。画像から動画生成の先頭／末尾フレーム、エレメント数、素材形式の制限は、現在のモデル説明に従ってください。

戻り値

data.id は照会に使うシステムタスク ID です。data.status は submitted、processing、succeeded、failed のいずれかです。タイムスタンプの単位はミリ秒です。作成レスポンスに完成した動画は含まれません。旧版の data.task_id や task_status を読み取らないでください。

コード例

Python 例には python3 -m pip install requests が必要です。Node.js は 18 以降の内蔵 fetch、Go は標準ライブラリを使用。

Kling 公式の KLING_API_KEY を設定します。呼び出すと課金対象のタスクが作成されます。作成後は タスク照会 で状態を確認します。

エラーコード

HTTP / 業務コード説明
200 / 0リクエスト成功。生成が完了したかはタスクの status で判断。
400 / 1201パラメーターエラー。message を確認。
404 / 1202、1203メソッドが正しくないか、モデル／リソースが存在しません。
401API Key または旧版 JWT が無効です。
400 / 1300、1301プラットフォームポリシーまたはコンテンツの安全性制限。内容を修正し、確認せず繰り返さないでください。
429 / 1302、1303、1304レート、同時実行数、IP ポリシーの制限。
500 / 5000；503 / 5001；504 / 5002サービスエラーまたはタイムアウト。request_id を保存。

HTTP 200 は業務上の成功を意味しません。まず code=0 を確認してから data を読み取ってください。
