# 其他能力與待串接參考

本節收錄尚未作為 SimiRouter 通用能力開放的介面：嵌入、檔案、微調、Realtime、審核與重新排序。它們與已開通能力的差別不在通訊協定難度，而在是否由閘道提供路由、鑑權與計費。

## 概覽

先看狀態，再決定是否寫程式碼。同在本節，不代表狀態相同。

| 狀態    | 含義                    | 現在可以做什麼            |
| ----- | --------------------- | ------------------ |
| 明確不支援 | 閘道不提供該能力，也不會因為更換網域而可用 | 只能按廠商直連參考，使用廠商 Key |
| 暫不支援  | 目前未開放，通訊協定本身穩定        | 按廠商直連參考驗證，不要寫成閘道呼叫 |
| 需確認管道 | 是否可用取決於帳戶與管道設定        | 先確認模型與路由，再決定是否依賴   |

## 核心概念

* **直連參考**：本節範例的位址與鑑權屬於廠商。把 `api.openai.com` 換成閘道網域不等於能力可用，路徑、欄位對應和權限都需要管道明確支援。
* **Key 歸屬**：廠商 Key 與 SimiRouter Key 不互通。直連範例必須使用對應廠商的 Key，不能把閘道 Key 填入。
* **資源歸屬**：檔案 ID、任務 ID、工作階段 ID 都由建立它們的項目或組織持有，跨廠商、跨項目不能直接沿用。
* **狀態與計費**：非同步任務先回傳 ID，再查詢狀態；建立成功不等於執行成功，取消任務也不代表已發生的用量被撤銷。

## 能力清單

| 分類       | SimiRouter 狀態 | 通訊協定性質                     | 參考                     |
| -------- | ------------- | -------------------------- | ---------------------- |
| 嵌入       | 暫不支援          | 同步向量回傳、獨立批任務               | [嵌入](/simidoc/zh-Hant/apps/api/pending/embeddings)     |
| 檔案管理     | 不支援           | 上傳、清單、元資料、下載和刪除            | [檔案](/simidoc/zh-Hant/apps/api/pending/files)          |
| 微調       | 不支援           | 建立非同步訓練任務、狀態與事件            | [微調](/simidoc/zh-Hant/apps/api/pending/fine-tuning)    |
| Realtime | 需確認專用管道       | WebRTC / WebSocket 有狀態工作階段 | [Realtime](/simidoc/zh-Hant/apps/api/pending/realtime) |
| 審核       | 需確認模型與路由      | 同步安全分類，不是聊天過濾保證            | [內容審核](/simidoc/zh-Hant/apps/api/pending/moderations)  |
| 重新排序     | 需確認模型與路由      | 同步文件相關性排名                  | [重新排序](/simidoc/zh-Hant/apps/api/pending/rerank)       |

音樂介面另見 [音樂（不支援）](/simidoc/zh-Hant/apps/api/music)。即時工作階段、上傳資源和訓練任務通常涉及額外權限、儲存與費用，應用串接前應明確資料保留與刪除策略。
