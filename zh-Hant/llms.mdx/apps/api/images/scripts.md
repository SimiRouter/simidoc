# 圖片呼叫範例已按協議整理

圖片呼叫不再使用一份僅適用於 OpenAI Images 的通用指令碼教學。請先選擇實際使用的協議，每個協議頁均按“請求格式與參數 → 回傳參數 → 呼叫範例”整理，包含圖片規格、四語言程式碼入口、智慧代理任務與安全儲存流程：

* [OpenAI 格式](/simidoc/zh-Hant/apps/api/images/openai)：Images 生成與編輯、Responses 對話式生圖及圖片理解。
* [Gemini 原生格式](/simidoc/zh-Hant/apps/api/images/gemini)：GenerateContent 的文字與圖片 Part、Base64 圖片儲存。
* [Qwen 原生格式](/simidoc/zh-Hant/apps/api/images/qwen)：百煉官方區域端點、原生訊息結構及結果 URL 儲存。

比較介面、效果和 1K / 2K / 4K 規格，請看[圖片 API 總覽](/simidoc/zh-Hant/apps/api/images)。已有連結保留在此，具體呼叫以對應協議為準；不同協議的憑據、參數和回傳欄位不可混用。
