# CC Switch設定

## 下載 CC Switch

1. 打開 [CC Switch 下載頁面](https\://github.com/farion1231/cc-switch/releases/latest)，在 GitHub Releases 中選擇適合您作業系統的安裝套件並完成安裝。

## 使用模型站內的匯入功能

### 快捷匯入 `Codex`

![SimiRouter 金鑰選單中的 CC Switch 匯入入口](/simidoc/assets/cc_switch/cc1.png)

選擇使用 Codex 模型群組的權杖，點擊匯入旁的小箭頭，選擇 CC Switch

填入供應商名與 Codex 模型
![填寫 CC Switch 供應商名稱和模型](/simidoc/assets/cc_switch/cc2.png)

在彈出的`此站点正在尝试打开 CC Switch。`提示中選擇打開
![瀏覽器請求打開 CC Switch 的確認視窗](/simidoc/assets/cc_switch/cc3.png)

檢查即將匯入的供應商設定是否正確
![CC Switch 待匯入供應商的設定預覽](/simidoc/assets/cc_switch/cc4.png)

無誤後選擇匯入
![在 CC Switch 中確認匯入供應商](/simidoc/assets/cc_switch/cc5.png)

匯入完成後，傳送一條簡短訊息測試。若需在 IDE 中串接，可參考[第三方外掛程式設定（VS Code Roo）](/simidoc/zh-Hant/apps/roo-code)中的欄位說明，並使用目前帳戶可用的模型名稱；不同外掛程式的設定項可能不同。
![CC Switch 匯入後的供應商設定頁面](/simidoc/assets/cc_switch/cc6.png)

可在 CC Switch 中查看目前帳戶餘額，按需儲值，避免餘額不足導致任務中斷。
![CC Switch 的帳戶餘額查詢頁面](/simidoc/assets/cc_switch/cc7.png)
