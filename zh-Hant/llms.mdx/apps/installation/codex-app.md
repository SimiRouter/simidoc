# Codex 桌面版安裝

## 下載與安裝

1. 打開 [OpenAI Codex 官方頁面](https\://chatgpt.com/codex)，選擇適合作業系統的安裝套件。
2. 完成安裝並打開應用。系統要求與可用安裝套件以官方頁面為準。
3. 按 [Codex 桌面版設定](/simidoc/zh-Hant/apps/codex-desktop)合併模型提供者與金鑰設定。

安裝和設定完成後，先提交一個低風險任務，並到 SimiRouter 使用記錄核對實際模型和用量。只打開應用或看見登入介面不能確認閘道串接成功。

## 官方參考

[OpenAI 桌面應用文件](https\://learn.chatgpt.com/docs/app)。
