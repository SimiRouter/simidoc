# Gemini CLI 安裝

## **前置條件：安裝 Gemini CLI**

確保已安裝 Node.js（v20 或更高版本），然後透過 npm 全域安裝：

```bash
npm install -g @google/gemini-cli
```

安裝完成後，驗證是否成功：

```bash
gemini --version
```

如需升級到最新版本：

```bash
npm upgrade -g @google/gemini-cli
```

## 設定模型服務

安裝後按 [Gemini CLI 設定](/simidoc/zh-Hant/apps/gemini-config)設定 SimiRouter 位址與 API Key。
