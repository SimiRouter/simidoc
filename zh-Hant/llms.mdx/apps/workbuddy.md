# WorkBuddy 教學

<Callout type="info" title="適用範圍">
  本教學適用於支援“設定自訂模型”功能的 WorkBuddy
  桌面用戶端。不同版本的入口和設定項目可能略有差異，請以實際介面為準。
</Callout>

## 前置條件

開始設定前，請確認已完成以下準備：

* 已安裝並啟動 WorkBuddy，且用戶端中可以找到“設定自訂模型”入口。
* 已註冊 SimiRouter，並在控制台的“API 金鑰”頁面建立 API Key。
* 已確認準備使用的完整模型 ID，且該 API Key 具有對應模型的呼叫權限和可用額度。

[打開 API 金鑰管理](https\://api.dwchainless.com/keys)

## 設定步驟

### 1. 打開“設定自訂模型”

在 WorkBuddy 對話介面，點擊輸入框右下角的模型名稱，在展開的清單中選擇 **“設定自訂模型”**。

![在模型清單中打開“設定自訂模型”](/simidoc/assets/workbuddy/open-custom-model.png)

進入模型管理頁面後，點擊 **“新增模型”**。如果已直接打開“新增模型”視窗，可繼續下一步。

### 2. 將供應商設定為“自訂”

在“新增模型”視窗中，展開 **“供應商”** 下拉清單，向下滾動，在“其他”分類中選擇 **“自訂”**。

![在供應商清單的“其他”分類中選擇“自訂”](/simidoc/assets/workbuddy/select-custom-provider.png)

選擇完成後，確認“供應商”欄位顯示為 **“自訂”**。

### 3. 填寫介面位址、API Key 和模型名稱

按下表填寫基礎資訊：

| 設定項     | 填寫內容                                              |
| ------- | ------------------------------------------------- |
| 供應商     | 自訂                                                |
| 介面位址    | `https://api.dwchainless.com/v1/chat/completions` |
| API Key | 在 SimiRouter 建立的 API 金鑰                           |
| 模型名稱    | 準備呼叫的完整模型 ID                                      |

**介面位址：** 請完整複製上表中的位址，保留末尾的 `/v1/chat/completions`。

**API Key：** 僅貼上金鑰本身，不額外新增 `Bearer`、引號或說明文字，並檢查前後是否有多餘空格。

**模型名稱：** 請從 SimiRouter 目前可用的模型資訊中複製完整模型 ID，不要填寫中文介紹、自訂暱稱或不完整的系列名稱。請確認所用 API Key 可以呼叫該模型。

### 4. 設定高級選項

首次設定時，建議保留輸入、輸出的預設設定，其他選項按所選模型及目前通道支援的能力設定。

| 設定項      | 設定建議                                       |
| -------- | ------------------------------------------ |
| 工具呼叫     | 需要使用工具任務時勾選，並確認所選模型及目前通道支援工具呼叫。            |
| 圖片輸入     | 需要處理圖片，且所選模型及目前通道支援時勾選。                    |
| 思考模式     | 按所選模型的適配說明設定；首次設定可保持未勾選。                   |
| 自訂通訊協定   | 沒有明確設定要求時，保持未勾選。                           |
| 思考強度（如有） | 建議先保持預設，有明確需求時再調整。                         |
| 輸入 / 輸出  | 建議先保留“使用提供者預設值”；需要手動設定時，先核對具體模型及目前通道的長度限制。 |

![自訂模型設定表單：介面位址、API Key、模型名稱及高級選項](/simidoc/assets/workbuddy/custom-model-form.png)

*截圖為中文介面的設定欄位示意，請按前述說明填寫自己的 API Key 和實際模型 ID。*

### 5. 測試連接、儲存並選取模型

填寫完成後，點擊 **“測試連接”** 檢查連接情況，再點擊 **“儲存”**。如果連接測試失敗，請參考下方“常見問題”排查。

回傳 WorkBuddy 對話介面，打開輸入框右下角的模型清單，**選取剛剛新增的自訂模型**，然後傳送一條簡短訊息，例如：

```text
请只回复：连接成功。
```

收到正常回覆後，可在 SimiRouter 控制台查看對應時間的呼叫記錄，核對請求使用的模型。

基礎對話正常後，再分別測試需要使用的工具呼叫、圖片輸入或思考模式。

## 常見問題

出現問題時，請先查看完整錯誤提示，再按下表排查。

| 遇到的問題             | 排查方法                                     |
| ----------------- | ---------------------------------------- |
| 找不到“設定自訂模型”       | 檢查用戶端版本是否支援該功能，並確認已打開對話介面右下角的模型清單。       |
| 測試連接或傳送訊息失敗       | 根據錯誤提示，逐項核對介面位址、API Key、模型 ID、呼叫權限和可用額度。 |
| 已儲存，但對話仍使用原來的模型   | 回傳對話介面，在模型清單中選取剛儲存的自訂模型。                 |
| 開啟圖片輸入、思考模式等選項後失敗 | 恢復最近一次可以正常使用的設定，再核對所選模型及目前通道是否支援該功能。     |
| 長對話或較長輸出發生錯誤      | 核對具體模型及目前通道的長度限制；根據錯誤提示縮短輸入內容或調低輸出上限。    |

如需協助排查，請提供 **WorkBuddy 版本、模型 ID、請求時間和完整錯誤提示**。

<Callout type="warn" title="金鑰安全提示">
  請妥善保管 API Key。提交截圖、記錄或錯誤資訊前，請先隱藏完整金鑰，不要在公開管道分享。
</Callout>
