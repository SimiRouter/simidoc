# 推廣回饋說明

## 回饋規則說明

### 推廣關係確認

* 被推廣人必須在註冊時使用推廣人提供的推廣連結，否則推廣關係無法確認。
* 推廣人可在控制台的[推廣資訊](https://api.dwchainless.com/promotion)中查看透過專屬連結註冊的使用者、綁定關係及回饋記錄。

### 回饋規則

* 回饋規則：被推廣人在儲值成功後，推廣人可以獲得被推廣人儲值金額的10%作為回饋。

### 提現規則

* 提現規則：推廣人可以在推廣詳情中查看自己的回饋金額，並申請提現。
  * 提現金額必須大於等於1000元。
* 提現審核：提現申請提交後，需要經過平台審核，審核通過後才會進行提現。
  * 首次申請的使用者需要提供收款資訊（支付寶、微信、銀行卡等）。
* 關於新推廣使用者回饋的問題：
  * 為避免惡意作弊等行為，推廣後首次儲值的新使用者的回饋需要經過審查。在審查儲值使用者行為正常後，推廣人才能獲得回饋。詳情見風控和處罰說明。

### 返現比例

* 一般推廣人可以獲得被推廣人儲值金額的10%作為回饋。
* 使用者可以申請成為"平台合夥人"取得更高的返現比例，具體比例根據使用者等級和推廣人數而定。有意願成為平台合夥人的使用者，可以透過客服等管道向平台申請。

## 風控規則和處罰說明

### 風控審查目的

保護使用者權益：防止惡意攻擊、保障使用者在平台的正常使用和其他合法權益。

維護平台公平，給平台使用者創造良好的使用環境。

避免平台遭受損失，保障平台的經濟利益。

遵守法律法規，確保平台合規經營。

### 風控審查範圍

惡意攻擊：透過技術手段或惡意行為，對平台造成損害。

套利作弊：利用平台技術或規則漏洞，套取平台獎勵等。

違規宣傳：在未經授權的情況下，冒用平台名義進行虛假宣傳、承諾額外回饋、或誘導他人註冊。

擾亂市場秩序：違反平台規定出售、交易平台獎勵等行為。

利用平台產品從事違法活動。

### 審查與處理流程

新使用者首次儲值回饋凍結：被推廣人首次儲值成功後，該筆回饋將被標記為“待審查”狀態，凍結期為7個自然日。期間平台將透過資料分析與人工複核判斷是否存在上述異常行為。

審查結果通知：審查完成後，推廣人可在推廣詳情頁查看結果。若判定正常，回饋自動解凍進入可提現餘額；若判定異常，回饋將被取消，並可能觸發進一步處罰。

複查機制：推廣人對審查結果有異議的，可在收到通知後7個工作日內聯繫客服提交證明材料（如聊天記錄、真實關係證明等），平台將在5個工作日內複核並反饋最終結論。

### 處罰措施

|    使用者風險行為   | 風險等級 |        處罰措施       |
| :----------: | :--: | :---------------: |
|     惡意攻擊     |   高  | 立即封禁帳號，永久禁止使用平台服務 |
|     套利作弊     |   中  |   扣除套利所得，嚴重的封禁帳號  |
|     違規宣傳     |   中  |     情節嚴重的封禁帳號     |
|    擾亂市場秩序    |   中  |    懲罰金額，嚴重的封禁帳號   |
| 利用平台產品從事違法活動 |   高  | 立即封禁帳號，永久禁止使用平台服務 |

### 違規行為

* 同一主體批量註冊多個帳號；
* 自行邀請自己、自充自返；
* 使用虛假身分或虛假付款資訊；
* 偽造交易、虛假儲值或惡意退款；
* 使用指令碼、自動化工具批量刷取獎勵；
* 利用系統漏洞、活動設定錯誤或介面異常套取獎勵；
* 操縱、買賣或惡意轉移推廣關係；
* 借助代充、洗錢、盜刷或其他違法違規方式參與活動；
* 組織或協助他人實施惡意套利；
* 其他違反公平誠信原則、使用者協議或法律法規的行為。
