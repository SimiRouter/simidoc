# 使用記錄與稽核記錄權限

這篇指南說明使用記錄與稽核記錄在不同角色下的可見範圍，以及如何確認實際處理請求的管道。

## 使用記錄

### 超級管理員

超級管理員可以查看所有使用者的完整記錄。打開[使用記錄](https://api.dwchainless.com/usage-logs/common)，在類型篩選中選擇 **僅看錯誤**，即可顯示所有使用者的錯誤呼叫。即使最終請求成功，重試期間發生的錯誤仍會保留在篩選結果中。

管道欄表示這次請求實際使用的管道。排查路由時，應以記錄中的實際管道、模型、狀態和請求 ID 為準，不要只依據用戶端顯示的模型名稱。

### 管理員

管理員只能查看自己的請求、儲值、管理操作和錯誤呼叫記錄。使用者名稱、角色參數或 URL 不能擴大這個範圍。管理員沒有全域的 **僅看錯誤** 篩選，但自己的錯誤記錄仍會按權限顯示。

### 一般使用者

一般使用者只能查看自己的請求、儲值和管理員操作相關記錄，不能查看錯誤記錄或其他使用者的記錄。

## 稽核記錄

超級管理員可以查看所有使用者的稽核事件並按使用者名稱篩選。管理員和一般使用者只能查看目前已驗證帳戶自己的稽核事件；頁面參數不能擴大伺服器端權限範圍。

## 管道狀態更新

稽核事件 `channel.status_update` 表示一次手動的單一管道狀態操作。目前程式碼記錄的目標狀態為啟用或手動停用；`changed=false` 表示請求成功但管道狀態沒有變化。批次操作對應 `channel.status_update_batch`。需要確認具體操作時，請查看事件詳情、操作人和時間。

## 錯誤排查

1. 先確認時間範圍和請求 ID。
2. 超級管理員排查全域錯誤時，選擇 **僅看錯誤**。
3. 核對實際管道、模型和狀態，不要只依據用戶端標籤。
4. 對逾時、5xx 回應或串流中斷，先查看現有記錄和請求 ID，再決定是否重試，避免重複扣費。
