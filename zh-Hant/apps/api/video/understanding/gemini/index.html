Gemini 影片理解

Gemini 原生影片摘要、事件分析與時間點問答。

介面說明

影片理解接收已有影片，回傳文字分析，不生成新影片。下方使用 Google 官方 Interactions：POST https://generativelanguage.googleapis.com/v1beta/interactions，身分驗證為 x-goog-api-key: $GEMINI_API_KEY。不能把它當 Seedance/Kling 建立任務，也不意味著 SimiRouter 已對應 Google 全部媒體輸入能力。

請求參數

欄位型別必填說明
modelstring是支援影片輸入的模型，例如 gemini-3.8-flash。
inputarray是video 素材與 text 問題。
input[].typestring是video 或 text。
input[].datastring條件短影片 Base64 內容，與 uri 二選一。
input[].mime_typestring條件如 video/mp4，應匹配真實編碼。
input[].uristring條件已上傳並 ACTIVE 的 Google 檔案 URI，或模型支援的公開影片位址。
input[].textstring條件摘要、問答或帶具體時間範圍的問題。
stream / backgroundboolean否長分析可採用串流或背景模式，須使用對應事件/任務處理流程。

本範例保守選擇總請求小於 20 MB 的短 MP4。較大或重複使用的影片優先走 Google Files API；檔案完成上傳後還需等待 ACTIVE，FAILED 必須停止，不能無上限輪詢。公開影片 URL、Cloud Storage 與直接行內是不同輸入路徑，不能隨意互換。

回傳值

Interactions 的 steps[] 中包含 model_output，文字項為 content[].type=text 與 text。SDK 的 output_text 是便利屬性。時間點屬於模型理解結果，應按原影片複核，不能自動視為精確取證或逐影格標註。

程式碼範例

Python 範例需 python3 -m pip install requests；Node.js 範例使用 Node.js 18 或更新版本的內建 fetch；Go 使用標準函式庫。

準備短影片 video.mp4 並設定 Google 官方 GEMINI_API_KEY。範例沒有呼叫付費生成模型，也沒有發起檔案管理操作，但推理請求本身仍可能計費。

錯誤碼

HTTP 狀態含義與處理
400 / 422請求欄位、檔案格式或模型參數不合法，修正後再提交。
401API Key 缺失、無效或已過期。
403目前項目或模型沒有權限。
404模型、路由或輸入資源不存在，檢查位址、模型 ID 與檔案狀態。
413 / 415上傳過大或媒體型別不受支援。
429速率或配額限制，區分餘額不足與可退避重試的限流。
500 / 502 / 503 / 504服務或上游異常，保留請求 ID；同步請求逾時後先查看日誌或請求狀態，再決定是否重試，避免重複計費。

Google 錯誤物件使用 error.code、error.status、error.message；請求失敗時不要把錯誤正文當作正常分析結果。
