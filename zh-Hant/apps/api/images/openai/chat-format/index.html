對話式圖片生成

使用 Responses 的 image_generation 工具在對話上下文中生成與迭代圖片。

介面說明

POST /v1/responses 在 tools 中聲明 image_generation，讓支援工具呼叫的主模型結合輸入生成圖片。主 model 是對話模型；實際影像工具模型的選用設定須按官方目前支援範圍選擇。

串接位址為 https://api.dwchainless.com，請求標頭使用 Authorization: Bearer $API_KEY。OpenAI 官方直連為 https://api.openai.com，同樣使用 Bearer 身分驗證，但必須換成 OpenAI 的 Key。 模型名稱應選用帳戶可存取且支援目標能力的模型。

OpenAI 原生對話式生圖使用 Responses 的 image_generation 工具，不是普通 Chat Completions 回傳 Markdown 圖片連結的約定。相容廠商若透過 Chat 回傳圖片連結，屬於其擴展格式，不能寫成 OpenAI 標準。

請求參數

欄位型別必填說明
modelstring是支援 image_generation 工具的 Responses 主模型。
inputstring / array是文字提示；編輯時可包含 input_image。
tools[].typestring是image_generation。
tools[].output_formatstring否png、jpeg、webp，範例為 png。
tools[].size / quality / backgroundstring否工具支援時的尺寸、質量與背景設定。
tool_choicestring / object否auto 由模型決定是否生成；強制工具的格式須按該工具支援方式設定。
previous_response_idstring否延續保留的上游回應，需相同可存取的上下文；閘道不提供通用查詢介面。
streamboolean否true 使用 Responses 事件流。

請求範例

回傳值

欄位型別說明
id / statusstring回應 ID 和終態，completed 才表示完整回應完成。
output[].typestring影像工具結果為 image_generation_call；也可能同時有 message。
output[].id / statusstring影像呼叫 ID 與工具執行狀態。
output[].resultstring影像呼叫最終結果的 Base64；不是 data[].b64_json。
output[].revised_promptstring支援時回傳影像工具所用的改寫提示。
output[].content[].textstringmessage 項中可能附帶的說明。
usageobject主模型用量；影像工具費用不應被視為只含文字 Token。
error / incomplete_detailsobject / null失敗與不完整原因。

此處 Base64 僅為最小 PNG 的結構範例。後續編輯可把圖片作為 input_image 與新指令一同傳送，或在支援且保留上下文的服務中使用 previous_response_id。不要把任意回應 ID 當成跨管道通用檔案資源。

程式碼範例

在程式碼頂端填入 API_URL、API_KEY，範例主模型使用 gpt-5.5，圖像工具模型使用 gpt-image-2。API_URL 是完整請求位址，預設使用閘道 https://api.dwchainless.com。範例只用標準函式庫，送出一次請求並把回傳 JSON 印到標準輸出，不會自動儲存圖片。

錯誤碼

HTTP 狀態含義或廠商錯誤型別處理方式
400請求無效檢查必填欄位、JSON、模型參數和上下文長度。
401驗證失敗檢查 Key 是否存在、有效及歸屬正確。
403 / 404無權存取 / 資源不存在檢查模型權限、資源 ID 和 URL。
429速率或配額限制結合回應主體區分限流與額度不足，後者不能靠重試解決。
500 / 503服務錯誤 / 暫時不可用保留請求識別碼，對暫時故障做有限次數退避。

OpenAI 原生錯誤通常包含 error.message、error.type、error.param、error.code；param、code 可為 null，不能假定其始終存在或等於 HTTP 狀態碼。 閘道可能在請求到達廠商前回傳驗證、路由或額度錯誤；不得僅憑 HTTP 數字判定錯誤來自上游。 主回應 completed 但沒有 image_generation_call.result 時，可能只生成了文字；應檢查工具選擇與回傳項，不得偽造圖片結果。
