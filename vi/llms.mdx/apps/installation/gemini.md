# Cài đặt Gemini CLI

## **Điều kiện tiên quyết\: Cài Gemini CLI**

Bảo đảm đã cài Node.js (v20 trở lên), rồi cài toàn cục bằng npm\:

```bash
npm install -g @google/gemini-cli
```

Sau khi cài, kiểm tra\:

```bash
gemini --version
```

Để nâng cấp lên phiên bản mới nhất\:

```bash
npm upgrade -g @google/gemini-cli
```

## Cấu hình dịch vụ mô hình

Sau cài đặt, theo [Cấu hình Gemini CLI](/simidoc/vi/apps/gemini-config) để đặt địa chỉ SimiRouter và khóa.
