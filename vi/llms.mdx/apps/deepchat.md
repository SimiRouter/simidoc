# Cấu hình DeepChat

DeepChat là ứng dụng AI mã nguồn mở hỗ trợ mô hình đám mây và cục bộ. Gọi công cụ và mở rộng khác cần mô hình cùng nhà cung cấp hỗ trợ.

* Trang chính thức\: [https\://deepchat.thinkinai.xyz](https\://deepchat.thinkinai.xyz)
* Kho GitHub\: [https\://github.com/ThinkInAIXYZ/deepchat](https\://github.com/ThinkInAIXYZ/deepchat)
* Tải xuống\: [https\://deepchat.thinkinai.xyz/#/download](https\://deepchat.thinkinai.xyz/#/download)

## Kết nối DeepChat thủ công

1. Trong SimiRouter, mở [Quản lý khóa API](https://api.dwchainless.com/keys) để sao chép khóa muốn dùng.

2. Mở DeepChat **Cài đặt → Cài đặt nhà cung cấp** rồi chọn New API hoặc thêm nhà cung cấp tương thích. **Điền API URL `https://api.dwchainless.com`** và dán khóa vừa sao chép.

   ![Minh họa địa chỉ SimiRouter và khóa API trong DeepChat](/simidoc/assets/deepchat/simirouter-manual.png)

3. Xác minh khóa, làm mới hoặc thêm mô hình, bật nhà cung cấp và chọn mô hình khả dụng. Gửi tin nhắn ngắn rồi xác minh lệnh gọi trong nhật ký SimiRouter.

<Callout type="warn" title="Bảo vệ khóa">
  Không để khóa trong ảnh công khai hay chia sẻ với ứng dụng không đáng tin. Nhãn giao diện có thể thay đổi theo phiên bản.
</Callout>
