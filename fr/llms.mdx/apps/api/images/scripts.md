# Exemples d’images regroupés par protocole

Les appels d’image ne reposent plus sur un guide générique de scripts limité à OpenAI Images. Choisissez le protocole réellement utilisé. Chaque page suit « format et paramètres de requête → champs de réponse → exemples d’appel » et comprend spécifications, accès au code en quatre langages, tâches pour agents et enregistrement sûr \:

* [Format OpenAI](/simidoc/fr/apps/api/images/openai) \: génération et édition Images, génération conversationnelle Responses et compréhension d’image.
* [Format natif Gemini](/simidoc/fr/apps/api/images/gemini) \: Parts texte et image de GenerateContent, enregistrement des images Base64.
* [Format natif Qwen](/simidoc/fr/apps/api/images/qwen) \: points de terminaison régionaux officiels Model Studio, messages natifs et enregistrement des URL de résultat.

Pour comparer API, effets et spécifications 1K / 2K / 4K, consultez la [vue d’ensemble des API d’images](/simidoc/fr/apps/api/images). Cette page conserve les anciens liens ; suivez le protocole correspondant pour les appels. Ne mélangez pas identifiants, paramètres et champs de réponse de protocoles différents.
