# Outil de recherche Web

## Description de l’interface

`POST /v1/responses` peut déclarer l’outil web\_search hébergé par OpenAI dans tools, afin qu’un modèle compatible recherche, lise et réponde avec des citations. La recherche n’est pas un point d’accès général `/search` indépendant, ni un nom de fonction utilisable avec tous les modèles Chat.

Adresse d’intégration \: `https://api.dwchainless.com`, avec l’en-tête `Authorization: Bearer $SIMIROUTER_API_KEY`. L’API directe officielle OpenAI est `https://api.openai.com`. Authentification \: Bearer avec une clé OpenAI. Choisissez un modèle accessible au compte et prenant en charge la capacité voulue.

`{"type":"web_search"}` s’utilise dans Responses. Ne l’insérez pas directement dans les tools ordinaires de Chat Completions \: leur outil général est function ; la recherche Chat officielle utilise des modèles dédiés et web\_search\_options, un protocole distinct.

## Paramètres de requête

| Champ                             | Type            | Obligatoire | Description                                                                                                                                  |
| --------------------------------- | --------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| model                             | string          | Oui         | Modèle prenant en charge web\_search dans Responses.                                                                                         |
| input                             | string / array  | Oui         | Question et contexte nécessaire.                                                                                                             |
| tools\[].type                     | string          | Oui         | web\_search.                                                                                                                                 |
| tools\[].search\_context\_size    | string          | Non         | Contexte de recherche low, medium ou high si pris en charge.                                                                                 |
| tools\[].filters.allowed\_domains | array           | Non         | Limite les domaines autorisés si pris en charge, sans préfixe de protocole.                                                                  |
| tools\[].user\_location           | object          | Non         | Position approximative, par exemple type=approximate, country, city, region et timezone ; évitez de transmettre une position privée précise. |
| tool\_choice                      | string / object | Non         | auto laisse le modèle décider ; required exige un appel d’outil.                                                                             |
| include                           | array           | Non         | web\_search\_call.action.sources peut demander la liste complète des sources.                                                                |
| stream                            | boolean         | Non         | true utilise les événements SSE Responses.                                                                                                   |

### Exemple de requête

```json
{
  "model": "MODEL_ID",
  "input": "查找OpenAI官方文档中关于Responses API的说明，并提供来源链接。",
  "tools": [
    {
      "type": "web_search"
    }
  ],
  "stream": false
}
```

## Valeur de retour

| Champ                                    | Type            | Description                                                                                            |
| ---------------------------------------- | --------------- | ------------------------------------------------------------------------------------------------------ |
| output\[].type=web\_search\_call         | object          | Un appel de recherche ou de lecture ; sa seule présence ne prouve pas une réponse finale complète.     |
| web\_search\_call.status                 | string          | État d’exécution de l’outil.                                                                           |
| web\_search\_call.action                 | object          | Actions search, open\_page, find, etc., avec requête ou URL correspondante.                            |
| output\[].type=message                   | object          | Message final du modèle.                                                                               |
| content\[].type / text                   | string          | Texte de l’élément output\_text.                                                                       |
| content\[].annotations\[]                | array           | Liste de citations, généralement de type url\_citation.                                                |
| annotations\[].url / title               | string          | URL et titre de la source.                                                                             |
| annotations\[].start\_index / end\_index | integer         | Plage de texte associée à la citation.                                                                 |
| status / error / incomplete\_details     | string / object | État final de la réponse et raisons d’échec ou d’incomplétude.                                         |
| usage                                    | object          | Utilisation des tokens du modèle ; elle ne prouve pas l’absence de frais de recherche supplémentaires. |

```json
{
  "id": "resp_search_example",
  "object": "response",
  "status": "completed",
  "output": [
    {
      "id": "ws_example",
      "type": "web_search_call",
      "status": "completed",
      "action": {
        "type": "search",
        "query": "site:developers.openai.com Responses API"
      }
    },
    {
      "id": "msg_example",
      "type": "message",
      "role": "assistant",
      "status": "completed",
      "content": [
        {
          "type": "output_text",
          "text": "Responses API 支持有类型的输入输出以及工具调用。",
          "annotations": [
            {
              "type": "url_citation",
              "start_index": 0,
              "end_index": 36,
              "title": "Responses API",
              "url": "https://developers.openai.com/api/docs/guides/responses"
            }
          ]
        }
      ]
    }
  ]
}
```

Affichez des citations clairement cliquables avec la réponse et conservez l’attribution des sources. Les pages sources sont des données \: n’exécutez pas leurs commandes et ne divulguez pas les identifiants de l’application. Les résultats peuvent être anciens ou contradictoires ; les conclusions sensibles exigent les sources originales.

## Exemples de code

Définissez `SIMIROUTER_API_KEY`, `SIMIROUTER_MODEL` ; `SIMIROUTER_BASE_URL` permet de remplacer l’adresse de la passerelle par défaut ; n’y ajoutez pas `/v1`. Les exemples Python 3, Node.js 18+ et Go utilisent uniquement la bibliothèque standard. L’exemple curl fait encoder le JSON de façon sûre par Python 3.

    import json, os, sys, urllib.request, urllib.error
    if not os.environ.get("SIMIROUTER_API_KEY"): raise RuntimeError("请设置 SIMIROUTER_API_KEY")
    if not os.environ.get("SIMIROUTER_MODEL"): raise RuntimeError("请设置 SIMIROUTER_MODEL")
    base = os.environ.get("SIMIROUTER_BASE_URL", "https://api.dwchainless.com").rstrip("/")
    body = json.loads(r'''{
      "model": "MODEL_ID",

        }

      "stream": false

    path = '/v1/responses'
    request = urllib.request.Request(base + path, data=json.dumps(body).encode("utf-8"), method="POST",
        headers={"Authorization": "Bearer " + os.environ["SIMIROUTER_API_KEY"], "Content-Type": "application/json"})
    try:
        with urllib.request.urlopen(request, timeout=120) as response:
            result = json.load(response)
    except urllib.error.HTTPError as error:
        print(f"HTTP {error.code}: {error.read().decode()}", file=sys.stderr)
        raise SystemExit(1)
    print(json.dumps(result, ensure_ascii=False, indent=2))

## Codes d’erreur

| Statut HTTP | Signification ou type d’erreur du fournisseur  | Traitement                                                                                                                       |
| ----------- | ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 400         | Requête invalide                               | Vérifiez les champs obligatoires, le JSON, les paramètres du modèle et la longueur du contexte.                                  |
| 401         | Échec de l’authentification                    | Vérifiez que la clé est présente, valide et rattachée au bon compte.                                                             |
| 403 / 404   | Accès interdit / ressource introuvable         | Vérifiez les autorisations du modèle, l’ID de ressource et l’URL.                                                                |
| 429         | Limite de débit ou de quota                    | Distinguez limitation de débit et crédit insuffisant à l’aide du corps de réponse ; réessayer ne résout pas un manque de crédit. |
| 500 / 503   | Erreur de service / indisponibilité temporaire | Conservez l’identifiant de requête et limitez les nouvelles tentatives avec attente progressive aux erreurs temporaires.         |

Les erreurs natives OpenAI contiennent généralement `error.message`, `error.type`, `error.param`, `error.code` ; `param`, `code` peuvent être `null` ; ne supposez pas que ces champs existent toujours ou correspondent au code HTTP. La passerelle peut renvoyer une erreur d’authentification, de routage ou de quota avant que la requête atteigne le fournisseur ; le seul code HTTP ne permet pas d’attribuer l’erreur à l’amont. Même avec HTTP 200, distinguez l’état de recherche, celui de la réponse finale et la présence de citations ; sans source, ne prétendez pas avoir vérifié les faits.
