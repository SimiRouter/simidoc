# Installer Gemini CLI

## **Prérequis \: installer Gemini CLI**

Vérifiez que Node.js est installé (v20 ou version ultérieure), puis installez Gemini CLI globalement avec npm \:

```bash
npm install -g @google/gemini-cli
```

Vérifiez ensuite que l’installation a réussi \:

```bash
gemini --version
```

Pour passer à la dernière version \:

```bash
npm upgrade -g @google/gemini-cli
```

## Configurer le service de modèles

Après l’installation, suivez [Configuration de Gemini CLI](/simidoc/fr/apps/gemini-config) pour définir l’adresse et la clé API SimiRouter.
