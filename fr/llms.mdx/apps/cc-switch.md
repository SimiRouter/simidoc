# Configuration de CC Switch

## Télécharger CC Switch

1. Ouvrez [Téléchargements CC Switch](https\://github.com/farion1231/cc-switch/releases/latest), choisissez sur GitHub Releases le paquet adapté à votre système et installez-le.

## Utiliser l’import proposé par la plateforme

### Import rapide de `Codex`

![Entrée d’import CC Switch dans le menu d’une clé SimiRouter](/simidoc/assets/cc_switch/cc1.png)

Sélectionnez un jeton du groupe de modèles Codex, cliquez sur la flèche près d’Importer, puis choisissez CC Switch.

Saisissez le nom du fournisseur et le modèle Codex.
![Saisie du fournisseur et du modèle dans CC Switch](/simidoc/assets/cc_switch/cc2.png)

Dans l’invite `此站点正在尝试打开 CC Switch。`, choisissez Ouvrir.
![Confirmation du navigateur pour ouvrir CC Switch](/simidoc/assets/cc_switch/cc3.png)

Vérifiez la configuration du fournisseur à importer.
![Aperçu du fournisseur à importer dans CC Switch](/simidoc/assets/cc_switch/cc4.png)

Si tout est correct, choisissez Importer.
![Confirmation de l’import dans CC Switch](/simidoc/assets/cc_switch/cc5.png)

Après l’import, envoyez un bref message de test. Pour une intégration IDE, consultez les champs de [Configuration d’une extension tierce (VS Code Roo)](/simidoc/fr/apps/roo-code) et utilisez un nom de modèle accessible au compte ; les champs varient selon les extensions.
![Fournisseur CC Switch après l’import](/simidoc/assets/cc_switch/cc6.png)

Vous pouvez consulter le solde du compte dans CC Switch et recharger au besoin afin d’éviter une interruption faute de crédit.
![Consultation du solde dans CC Switch](/simidoc/assets/cc_switch/cc7.png)
