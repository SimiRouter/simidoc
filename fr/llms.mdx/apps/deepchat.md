# Configuration de DeepChat

DeepChat est un client IA open source pour modèles cloud ou locaux. Les fonctions supplémentaires, comme les outils, dépendent du modèle et du fournisseur.

* Site officiel \: [https\://deepchat.thinkinai.xyz](https\://deepchat.thinkinai.xyz)
* Dépôt GitHub \: [https\://github.com/ThinkInAIXYZ/deepchat](https\://github.com/ThinkInAIXYZ/deepchat)
* Téléchargement \: [https\://deepchat.thinkinai.xyz/#/download](https\://deepchat.thinkinai.xyz/#/download)

## Connexion manuelle à SimiRouter

1. Dans SimiRouter, ouvrez [Gestion des clés API](https://api.dwchainless.com/keys) pour copier la clé API souhaitée.

2. Dans DeepChat, ouvrez **Paramètres → Fournisseurs de services**, puis choisissez New API ou ajoutez un fournisseur compatible. **Renseignez l’URL API `https://api.dwchainless.com`** et collez la clé API copiée précédemment.

   ![Saisie de l’adresse SimiRouter et de la clé dans DeepChat](/simidoc/assets/deepchat/simirouter-manual.png)

3. Vérifiez la clé, actualisez ou ajoutez les modèles, activez le fournisseur et sélectionnez un modèle disponible. Après un bref message, vérifiez l’appel dans les journaux SimiRouter.

<Callout type="warn" title="Protéger la clé">
  Ne publiez pas la clé et ne la donnez pas à une application non fiable. L’interface change selon la version ; fiez-vous aux champs réellement affichés.
</Callout>
