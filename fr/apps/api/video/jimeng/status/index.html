Consulter le résultat vidéo Jimeng (intégration prévue)

Interroger une tâche vidéo Jimeng : état, code de résultat et URL de téléchargement.

Description de l’interface

POST https://visual.volcengineapi.com/?Action=CVSync2AsyncGetResult&Version=2022-08-31, corps JSON. L’API officielle exige une signature V4 AK/SK, Region=cn-north-1, Service=cv, pas un simple Bearer.

Cette page est une référence fournisseur pour Jimeng 3.0 Pro, indiqué officiellement « en cours de retrait ». Applicable uniquement si le compte est autorisé et le service encore ouvert ; ce n’est pas le mappage public /jimeng/ de SimiRouter. La signature ci-dessous n’appelle aucun proxy et n’omet aucune signature obligatoire.

Paramètres de requête

ChampTypeObligatoireDescription
Action (query)stringOuiCVSync2AsyncGetResult.
Version (query)stringOui2022-08-31.
req_keystringOuiCe produit utilise jimeng_ti2v_v30_pro, pas jimeng_video_generation.
task_idstringOuiID de tâche reçu après soumission réussie.
req_jsonstringNonChaîne JSON sérialisée, par exemple une configuration aigc_meta ; pas un objet non prévu.

Les en-têtes signés comprennent Content-Type, Host, X-Date (UTC) et X-Content-Sha256. Corps et query envoyés doivent être strictement identiques aux données signées ; changer Action exige une nouvelle signature.

Valeur de retour

ChampDescription
code / messageSuccès métier : 10000 ; ne vérifiez pas seulement le code HTTP.
request_idID de suivi serveur.
data.statusin_queue : en attente ; generating : génération ; done : terminé ; not_found : absent/expiré ; expired : expiré.
data.video_urlLien vidéo réussi, valable environ 1 heure ; enregistrez rapidement.
data.aigc_meta_taggedRésultat du marquage d’identification implicite.

La tâche reste disponible environ 12 heures. Téléchargez seulement avec code=10000, status=done et video_url non vide. done sans sortie n’est pas une réussite ; arrêtez l’interrogation pour not_found / expired.

Exemples de code

Définissez VOLC_ACCESS_KEY, VOLC_SECRET_KEY et TASK_ID ; utilisez l’ID réel de création. Python 3, Node.js 18+ et Go utilisent leurs bibliothèques standard ; curl nécessite aussi Python 3 pour encoder le JSON de manière sûre et signer localement. Ne placez pas AK/SK dans le code ou les journaux.

Codes d’erreur

Vérifiez d’abord HTTP puis code métier ; HTTP 200 ne dispense pas de ce contrôle.

Code métierSens et traitement
10000Appel réussi ; la consultation exige encore data.status et video_url.
50411 / 50412 / 50413Image, texte ou vérification de termes sensibles/droits d’auteur refusés ; modifiez l’entrée au lieu de la répéter.
50511 / 50516Image/vidéo de sortie refusée par la modération.
Erreur de signature / 401 / 403Vérifiez AK/SK, heure UTC, région, Service, hachage du corps et autorisations.
429 / 5xxLimitation ou erreur de service ; ne répétez pas aveuglément une création expirée pour éviter les doublons.

Conservez request_id, code et message. Si code n’est pas 10000, data peut être null ; n’accédez pas ensuite à data.status.
