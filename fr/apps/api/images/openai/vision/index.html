Compréhension d’images

Décrire, questionner et extraire des informations d’images avec image_url de Chat Completions.

Description de l’interface

POST /v1/chat/completions associe une question textuelle et une image dans un message user et renvoie une analyse textuelle. La compréhension d’images n’est ni génération ni édition.

Adresse d’intégration : https://api.dwchainless.com, avec l’en-tête Authorization: Bearer $API_KEY. L’API directe officielle OpenAI est https://api.openai.com. Authentification : Bearer avec une clé OpenAI. Choisissez un modèle accessible au compte et prenant en charge la capacité voulue.

Une image peut être une URL HTTPS accessible ou une data URL contenant ses vrais octets ; cette page utilise une URL HTTPS accessible.

Paramètres de requête

ChampTypeObligatoireDescription
modelstringOuiModèle de conversation acceptant les entrées visuelles.
messages[].rolestringOuiUtilisez user pour le message contenant l’image.
messages[].contentarrayOuiAu moins une question et un élément d’image.
content[].type=text / textstringConditionnelÉlément de question textuelle.
content[].type=image_urlstringConditionnelDéclare un élément d’image.
image_url.urlstringOuiURL HTTPS ou data:image/{format};base64,... ; pas un chemin local.
image_url.detailstringNonRéglage de détail accepté par le modèle, par exemple auto, low ou high.
max_completion_tokensintegerNonNombre maximal de tokens de sortie.
streambooleanNontrue renvoie les SSE Chat.

PNG, JPEG, WebP, etc. doivent porter leur MIME correspondant ; respectez les limites de nombre, pixels et taille de requête du modèle choisi. Ne renommez pas simplement un GIF animé, une vidéo ou un binaire quelconque en image/png.

Structure de la requête

Valeur de retour

ChampTypeDescription
id / objectstringID de réponse ; object=chat.completion.
created / modelinteger / stringHeure de création (secondes Unix) et modèle de réponse.
choices[]arrayListe des réponses candidates ; index indique la position de chacune.
choices[].message.rolestringassistant.
choices[].message.contentstring / nullRéponse textuelle ; peut être vide en cas d’appel d’outil ou de refus, sans signifier un échec de la requête.
choices[].message.tool_callsarrayAppels de fonctions à exécuter par l’application. arguments est une chaîne JSON à analyser et valider.
choices[].message.refusalstring / nullInformations de refus, le cas échéant.
choices[].finish_reasonstringstop : fin normale ; length : limite atteinte ; tool_calls : passage aux outils ; content_filter : contenu filtré.
usage.prompt_tokensintegerTokens d’entrée.
usage.completion_tokensintegerTokens générés, pouvant inclure les tokens de raisonnement.
usage.total_tokensintegerTotal des tokens d’entrée et générés.
usage.*_tokens_detailsobjectDétails facultatifs de l’utilisation, par exemple cached_tokens et reasoning_tokens.

Ajoutez des éléments image_url pour plusieurs images ; précisez ordre et objectif dans le texte pour les comparer. En streaming, assemblez Chat delta.content. Ne vous fiez pas uniquement à la vision du modèle pour les petits textes, comptages exacts, identités ou décisions sensibles.

Exemples de code

Renseignez API_URL et API_KEY en tête du code; les exemples utilisent gpt-5.5. API_URL est l’URL complète de la requête et pointe par défaut vers la passerelle https://api.dwchainless.com. IMAGE_URL doit être une URL HTTPS d’image accessible au serveur. Les exemples n’utilisent que les bibliothèques standard, envoient une requête et affichent le JSON reçu ; ils n’enregistrent pas l’image automatiquement.

Codes d’erreur

Statut HTTPSignification ou type d’erreur du fournisseurTraitement
400Requête invalideVérifiez les champs obligatoires, le JSON, les paramètres du modèle et la longueur du contexte.
401Échec de l’authentificationVérifiez que la clé est présente, valide et rattachée au bon compte.
403 / 404Accès interdit / ressource introuvableVérifiez les autorisations du modèle, l’ID de ressource et l’URL.
429Limite de débit ou de quotaDistinguez limitation de débit et crédit insuffisant à l’aide du corps de réponse ; réessayer ne résout pas un manque de crédit.
500 / 503Erreur de service / indisponibilité temporaireConservez l’identifiant de requête et limitez les nouvelles tentatives avec attente progressive aux erreurs temporaires.

Les erreurs natives OpenAI contiennent généralement error.message, error.type, error.param, error.code ; param, code peuvent être null ; ne supposez pas que ces champs existent toujours ou correspondent au code HTTP. La passerelle peut renvoyer une erreur d’authentification, de routage ou de quota avant que la requête atteigne le fournisseur ; le seul code HTTP ne permet pas d’attribuer l’erreur à l’amont.
