Configuration d’Hermes

Configurer le fournisseur SimiRouter d’Hermes avec CC Switch.

Prérequis

  1. Hermes est installé et peut démarrer normalement.
  2. Une clé API valide a été créée dans la console SimiRouter.
  3. CC Switch est installé.

Si CC Switch n’est pas installé, consultez d’abord Installation et import CC Switch.

Configurer Hermes dans CC Switch

  1. Dans CC Switch, choisissez dans la liste des applications à gauche Hermes ; les anciennes versions utilisent les onglets supérieurs.

  1. Cliquez sur Ajouter, ajoutez un fournisseur personnalisé, puis revenez à l’onglet Hermes et activez-le.

  1. Ouvrez le terminal et saisissez hermes desktop pour démarrer l’application, puis envoyez un bref message de test.--skip-build convient uniquement à un environnement de développement ayant déjà produit une compilation de bureau, pas au premier lancement.

  1. Vous pouvez également exécuter dans le terminal hermes --tui pour le mode TUI. Envoyez un bref message et vérifiez l’appel dans SimiRouter ; l’affichage du TUI ne prouve pas la connexion du modèle.

Questions fréquentes

  • baseUrl sans /v1 : cause fréquente d’absence de liste des modèles.
  • ID de modèle différent : utilisez exactement le nom exposé par le service.
  • Authentification ou disponibilité toujours en échec : vérifiez que la clé et le fournisseur utilisent le même environnement.
