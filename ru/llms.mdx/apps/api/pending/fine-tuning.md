# Дообучение (не поддерживается)

Дообучение настраивает поведение базовой модели с помощью обучающих данных и создаёт новую модель, пригодную для инференса. OpenAI предлагает обучение с учителем, прямую оптимизацию предпочтений (DPO), обучение с подкреплением и другие методы; доступные методы зависят от выбранной базовой модели.

**SimiRouter пока не поддерживает дообучение. Следующие страницы сохраняют официальные описания и прямые примеры с ключом проекта OpenAI. Обучение может оплачиваться.**

OpenAI постепенно прекращает самообслуживание дообучения\: новые пользователи не могут создавать задачи, а соответствующие требованиям действующие пользователи смогут создавать их до **6 января 2027 года**, если базовая модель не будет отключена раньше. Уже созданные модели доступны для инференса только до вывода из эксплуатации базовой модели. Условия, модели и даты могут измениться; перед использованием сверяйтесь с [официальным графиком устаревания](https\://developers.openai.com/api/docs/deprecations).

## Обзор

Дообучение изменяет веса модели, а не промпт. Оно подходит для стабильных ограничений формата, фиксированного тона и предметной лексики; оно не подходит для внедрения знаний, которые постоянно меняются — для таких задач дешевле использовать поиск или более длинный системный промпт. Для проверки результата обязательно нужны независимые образцы, не участвовавшие в обучении.

| Что вы хотите сделать             | Ввод                                   | Вывод                              | Способ выполнения                    |
| --------------------------------- | -------------------------------------- | ---------------------------------- | ------------------------------------ |
| Обучить специализированную модель | Обучающий набор JSONL + базовая модель | Объект задачи и `fine_tuned_model` | Асинхронно в фоне, с опросом статуса |
| Наблюдать за процессом обучения   | ID задачи                              | Журнал событий и метрики           | Постраничный запрос, а не SSE        |
| Остановить обучение               | ID задачи                              | Объект отменённой задачи           | Синхронный запрос                    |

## Ключевые понятия

* **Базовая модель**\: определяет доступные методы и цену. Разные базовые модели поддерживают разные методы и параметры; при неверном выборе метода задача будет отклонена при создании.
* **Обучающий и валидационный наборы**\: JSONL, по одному образцу диалога в строке; официальный минимум — 10 штук, обычно начинают с 50, и при 50–100 часто уже видно заметное улучшение. Валидационный набор нужно готовить отдельно, он не должен пересекаться с обучающим.
* **Статус задачи**\: `queued`, `running`, `succeeded`, `failed`, `cancelled`. Только `succeeded` создаёт новую модель, пригодную для инференса; при `failed` нужно прочитать `error`, чтобы понять, проблема в данных или в параметрах.
* **Созданная модель**\: после успеха возвращается идентификатор `fine_tuned_model`, который используется вместо базовой модели для инференса. У модели собственный жизненный цикл, при необходимости её нужно удалить самостоятельно.
* **Стоимость**\: обучение тарифицируется по токенам, созданная модель может оплачиваться за хранение в течение срока хранения; пробный запуск на небольшом образце с последующим расширением управляемее, чем однократная отправка всех данных.

## Основной процесс

1. Подготовьте обучающий набор JSONL в соответствии с выбранным методом дообучения и отдельно подготовьте валидационный набор.
2. Через [официальный интерфейс загрузки файлов](/simidoc/ru/apps/api/pending/files/upload) загрузите данные с `purpose=fine-tune`.
3. Выберите модель, поддерживающую этот метод, создайте задачу и сохраните ID задачи.
4. Проверяйте статус и события задачи; `succeeded` означает успех, при `failed` нужно прочитать `error`, `cancelled` означает отмену.
5. После успешного обучения используйте возвращённый `fine_tuned_model` для инференса и проверьте качество на независимом оценочном наборе.

Успешное создание запроса не означает успешного обучения; отмена задачи также не означает, что уже понесённые расходы отменены. Не создавайте повторно одну и ту же задачу обучения только из-за сетевого тайм-аута.
