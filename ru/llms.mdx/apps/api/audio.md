# Аудио

Аудио API превращает текст в речь, записи в текст и помогает понимать аудиосодержимое. Синтез речи, генерация музыки и звуковые дорожки видео — разные возможности; не смешивайте модели и эндпоинты.

## Обзор

| Что вы хотите сделать                     | Направление                | Типичный результат                              | Единица оплаты                                |
| ----------------------------------------- | -------------------------- | ----------------------------------------------- | --------------------------------------------- |
| Озвучить текст, сделать дубляж            | Текст → Речь               | Аудиофайлы MP3, WAV и др.                       | Число входных символов или длительность аудио |
| Превратить запись в текст                 | Речь → Текст               | Текст на исходном языке, временные метки        | Секунды или минуты аудио                      |
| Перевести иноязычную запись на английский | Речь → Английский текст    | Английский текст без сохранения исходного языка | Длительность аудио                            |
| Понять содержание записи                  | Речь → Аналитический текст | Резюме, говорящие, выводы                       | Token, соответствующие входному аудио         |
| Общаться в реальном времени               | Двусторонний аудиопоток    | Непрерывное аудио и события                     | Длительность сеанса или Token                 |

## Ключевые понятия

* **Частота дискретизации**\: число отсчётов в секунду; обычно 16 кГц (достаточно для распознавания речи), 24 кГц и 44,1 кГц (выше качество). Несоответствие частоты вызывает изменение тона при воспроизведении или ухудшение транскрипции.
* **Битовая глубина и каналы**\: 16 бит, моно — обычный выбор для речи; стерео и большая глубина увеличивают размер файла, но модель не обязательно их использует.
* **Контейнер и кодек**\: MP3 — сжатие с потерями и небольшой размер; WAV обычно без сжатия и крупный; PCM — исходные отсчёты без контейнера, для воспроизведения нужно вручную указать параметры дискретизации.
* **Длительность и размер**\: ограничения загрузки часто задаются одновременно размером файла и длительностью; повышение частоты не улучшает распознавание, а только увеличивает риск превышения лимита.
* **Синхронность и поток**\: TTS возвращает аудиобайты, ASR — JSON. Поток сокращает ожидание первого слова или фрагмента, не меняя общий объём оплаты.

Конкретные значения (максимальная длительность, поддерживаемые форматы, диапазон частот) определяются моделью; смотрите таблицу параметров запроса на странице каждого интерфейса.

## Синхронность, асинхронность и потоковая передача

* **Синхронный HTTP**\: один запрос возвращает аудиофайл или полную транскрипцию, без ID задачи и этапов опроса.
* **Потоковый HTTP**\: один ответ по частям возвращает аудио или события SSE; это не двусторонний сеанс реального времени. Не применяйте JSON-разбор к бинарному потоку.
* **Асинхронная задача**\: сначала получают ID задачи, затем запрашивают состояние; генерация видео обычно работает так, а обычные TTS/ASR — нет.
* **Realtime**\: сеанс удерживает соединение, клиент может непрерывно передавать аудио, прерывать воспроизведение и обрабатывать события; загрузка файла его не заменяет.

## Имитация вызова

Тело запроса синтеза речи — JSON, а ответ содержит аудиобайты, а не JSON\:

```json
{
  "model": "gpt-4o-mini-tts",
  "voice": "alloy",
  "input": "欢迎使用 SimiRouter。",
  "response_format": "mp3"
}
```

Заголовки ответа определяют, как сохранить файл; тело записывается напрямую в `.mp3`\:

```text
HTTP/1.1 200 OK
Content-Type: audio/mpeg
Content-Length: 24576

<二进制音频数据>
```

Транскрипция выполняется через multipart-загрузку и возвращает JSON\:

```json
{"text":"欢迎使用 SimiRouter。"}
```

В одной категории «аудио» синтез возвращает двоичные данные, а транскрипция — JSON; парсеры нельзя смешивать. Пример модели `gpt-4o-mini-tts` помечен поставщиком как устаревший; замена и порядок миграции — в разделе [Текст в речь](/simidoc/ru/apps/api/audio/speech).

## Условия использования

OpenAI-совместимые страницы используют адрес и ключ SimiRouter; нативные справочники провайдера — его адрес и соответствующий ключ. Доступность модели определяется списком моделей учётной записи и правами канала; нельзя считать, что шлюз уже предоставляет все возможности провайдера. Перед загрузкой записи получите необходимые разрешения; для клонирования голоса нужны права на его использование и уведомление слушателей о синтезированной речи.
