# Генерация видео DashScope (Wan / HappyHorse)

## Обзор

Wan и HappyHorse — семейства моделей генерации видео на платформе Alibaba Cloud Bailian, использующие один и тот же асинхронный протокол DashScope\: эндпоинт отправки, заголовок `X-DashScope-Async`, путь запроса задачи, строки статуса и поля результата совпадают. Различия только в трёх местах — ID модели, структура ввода, параметры кадра.

| Что нужно сделать                                                | Ввод                                                    | Вывод                      | Эндпоинт                                                      |
| ---------------------------------------------------------------- | ------------------------------------------------------- | -------------------------- | ------------------------------------------------------------- |
| Видео по тексту (Wan)                                            | Промпт, `parameters.size`, `duration`                   | `task_id`                  | `POST /api/v1/services/aigc/video-generation/video-synthesis` |
| Видео по первому кадру (Wan)                                     | Промпт, `input.img_url`, `parameters.resolution`        | `task_id`                  | Тот же эндпоинт отправки                                      |
| Видео по тексту (HappyHorse)                                     | Промпт, `resolution`, `ratio`, `duration`               | `task_id`                  | Тот же эндпоинт отправки                                      |
| Видео по первому кадру или референсному изображению (HappyHorse) | `input.media` с `first_frame` или 1–9 `reference_image` | `task_id`                  | Тот же эндпоинт отправки                                      |
| Запрос задачи                                                    | `task_id`                                               | `task_status`, `video_url` | `GET /api/v1/tasks/{task_id}`                                 |

## Ключевые понятия

* **Жизненный цикл задачи**\: `PENDING → RUNNING → SUCCEEDED`, неуспешное конечное состояние — `FAILED`, также есть `CANCELED` и `UNKNOWN`. Только при `SUCCEEDED` читается `output.video_url`.
* **Два ID имеют разное назначение**\: `output.task_id` используется для запроса задачи; `request_id` — только для трассировки одного HTTP-запроса. При диагностике сохраняйте оба.
* **Ритм опроса**\: официально рекомендуется запрашивать каждые 15 секунд. ID задачи и URL результата действительны 24 часа; после истечения срока запрос вернёт `UNKNOWN`.
* **Структура ввода зависит от семейства моделей**\: в Wan для видео по изображению используется `input.img_url`; в HappyHorse — массив `input.media`, элементы которого содержат `type` (`first_frame` или `reference_image`) и `url`. Эти структуры не взаимозаменяемы.
* **Параметры кадра зависят от семейства моделей**\: в Wan для видео по тексту используется `parameters.size` (`宽*高`, например `1280*720`), в Wan для видео по изображению — `parameters.resolution` (`480P`, `720P`, `1080P`); в HappyHorse для видео по тексту и по референсным изображениям используется `parameters.ratio` (например `16:9`), а видео по первому кадру следует за первым кадром.
* **Аудио только в некоторых поколениях Wan**\: Wan2.6 и Wan2.5 по умолчанию генерируют музыку или звуковые эффекты, соответствующие изображению; также можно передать WAV, MP3 через `input.audio_url`; Wan2.2 и Wan2.1 по умолчанию выдают видео без звука. В документации HappyHorse нет параметров ввода или вывода аудио.
* **Тарификация по секундам вывода**\: `usage.duration` в ответе запроса — длительность выходного видео. Цена за единицу, расчёт по неуспешным задачам и правила возврата определяются страницей цен провайдера и счётом.

## Характеристики и возможности

Значения Wan\:

| Показатель                  | Подтверждённые значения                                                                                                                                                                                                                           |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Модель видео по тексту      | `wan2.6-t2v`, `wan2.5-t2v-preview`, `wan2.2-t2v-plus`, `wan2.1-t2v-turbo`, `wan2.1-t2v-plus`                                                                                                                                                      |
| Модель видео по изображению | `wan2.6-i2v`, `wan2.6-i2v-flash`, `wan2.5-i2v-preview`, `wan2.2-i2v-plus`, `wan2.2-i2v-flash`, `wan2.1-i2v-turbo`, `wan2.1-i2v-plus`                                                                                                              |
| Разрешение                  | Видео по тексту `size`\: `832*480`, `480*832`, `624*624`, `1280*720`, `720*1280`, `960*960`, `1088*832`, `832*1088`, `1920*1080`, `1080*1920`, `1440*1440`, `1632*1248`, `1248*1632`; видео по изображению `resolution`\: `480P`, `720P`, `1080P` |
| Длительность                | `wan2.6-t2v` — 2–15 секунд; `wan2.5-t2v-preview` — 5 или 10 секунд; `wan2.2`, `wan2.1` видео по тексту фиксировано 5 секунд; `wan2.1-i2v-turbo` поддерживает 3, 4, 5 секунд                                                                       |
| Аудио                       | Wan2.6, Wan2.5 автоматически генерируют музыку или звуковые эффекты; `audio_url` поддерживает WAV, MP3, 3–30 секунд, максимум 15 MB; Wan2.2, Wan2.1 по умолчанию без звука                                                                        |
| Референсные материалы       | Для видео по изображению используется `input.img_url`, поддерживается публичный URL или Base64; ширина и высота изображения 240–8000 пикселей, Wan2.6/2.5 — максимум 20 MB                                                                        |

Значения HappyHorse\:

| Показатель              | Подтверждённые значения                                                                                                                                                                                                      |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ID модели               | `happyhorse-1.1-t2v`, `happyhorse-1.0-t2v`, `happyhorse-1.1-i2v`, `happyhorse-1.1-r2v`                                                                                                                                       |
| Разрешение              | `480P`, `720P`, `1080P`, по умолчанию `1080P`                                                                                                                                                                                |
| Соотношение сторон      | Видео по тексту и по референсным изображениям\: `16:9` (по умолчанию), `9:16`, `1:1`, `4:3`, `3:4`, `4:5`, `5:4`, `9:21`, `21:9`; видео по первому кадру следует за первым кадром, допускается от 1\:2.5 до 2.5\:1           |
| Длительность            | 3–15 секунд, по умолчанию 5 секунд; этот диапазон явно указан в документации `happyhorse-1.0-t2v`, видео по изображению и видео по референсным изображениям, в документации `happyhorse-1.1-t2v` диапазон не указан          |
| Референсные изображения | Видео по изображению — 1 первый кадр, короткая сторона не менее 300 пикселей; видео по референсным изображениям — 1–9, короткая сторона не менее 400 пикселей; одно изображение максимум 20 MB; форматы JPEG, JPG, PNG, WEBP |
| Прочие параметры        | `watermark` по умолчанию `true`, при включении в правом нижнем углу отображается HappyHorse; `seed` в диапазоне 0–2147483647                                                                                                 |

`size` в Wan — конкретные пиксели, `resolution` — уровень, они обслуживают разные эндпоинты\: для вертикального видео по тексту в 1080P нужно писать `1080*1920`, нельзя писать `1080P`; для видео по изображению наоборот, принимаются только `480P`, `720P`, `1080P`. Видео по первому кадру HappyHorse не читает `ratio`, соотношение вывода определяется изображением. Видео по тексту Wan2.2 и Wan2.1 фиксировано на 5 секундах, увеличение `duration` не даст более длинного фрагмента. Wan2.6 и Wan2.5 автоматически генерируют звуковую дорожку; если на выходе аудио не нужно, его следует удалить при постобработке или сначала проверить, предоставляет ли модель параметр отключения. Когда референсных изображений 1–9, `[Image N]` в промпте должен соответствовать порядку `media`; при ошибке порядка будет ссылка не на то изображение.

## Процесс вызова

1. Создайте ключ API в Alibaba Cloud Bailian. Модель, адрес запроса и ключ должны принадлежать одному региону; вызов из другого региона завершится ошибкой.
2. Выберите семейство моделей и режим\: Wan — видео по тексту или изображению, либо HappyHorse — видео по тексту, по первому кадру или по референсным изображениям. Структура ввода различается, нельзя переиспользовать одно и то же тело запроса.
3. Отправьте JSON на `POST /api/v1/services/aigc/video-generation/video-synthesis` с `Authorization: Bearer`, `Content-Type: application/json` и `X-DashScope-Async: enable`.
4. Сохраните `output.task_id` и `request_id`. Возврат `PENDING` при создании означает только успешную постановку в очередь.
5. Каждые 15 секунд вызывайте `GET /api/v1/tasks/{task_id}`. После `SUCCEEDED` читайте `output.video_url`; при `FAILED` читайте `output.code` и `output.message`.
6. Скачайте и пересохраните видео в течение 24 часов. После истечения срока задачи запрос невозможен, и на URL результата больше нельзя полагаться.

## Имитация вызова

Приведённые ниже сообщения иллюстрируют структуру полей; ID задачи, ID запроса, URL и использование не являются реальными данными аккаунта.

Запрос создания видео Wan по тексту\:

```json
{
  "model": "wan2.5-t2v-preview",
  "input": {
    "prompt": "示例：清晨的竹林，薄雾缓慢流动，镜头横移。"
  },
  "parameters": {
    "size": "1280*720",
    "duration": 5,
    "prompt_extend": true,
    "watermark": false,
    "seed": 20260804
  }
}
```

Запрос создания видео HappyHorse по первому кадру\:

```json
{
  "model": "happyhorse-1.1-i2v",
  "input": {
    "prompt": "示例：让画面中的帆船缓慢向前移动。",
    "media": [
      {
        "type": "first_frame",
        "url": "https://example.com/demo-first-frame.png"
      }
    ]
  },
  "parameters": {
    "resolution": "720P",
    "duration": 5,
    "watermark": false,
    "seed": 20260804
  }
}
```

Структура успешного ответа на создание у обоих семейств моделей одинакова, возвращается только статус очереди\:

```json
{
  "output": {
    "task_id": "demo-task-0001",
    "task_status": "PENDING"
  },
  "request_id": "demo-request-0001"
}
```

Запрос достиг успешного конечного состояния\:

```json
{
  "request_id": "demo-request-0001",
  "output": {
    "task_id": "demo-task-0001",
    "task_status": "SUCCEEDED",
    "video_url": "https://example.com/demo-video.mp4",
    "orig_prompt": "示例：清晨的竹林，薄雾缓慢流动，镜头横移。"
  },
  "usage": {
    "duration": 5,
    "output_video_duration": 5,
    "video_count": 1,
    "SR": 720
  }
}
```

`PENDING`, `RUNNING` — продолжайте ждать; `FAILED`, `CANCELED` — немедленно остановитесь и сохраните `output.code` и `output.message`; `UNKNOWN` — сначала проверьте, не прошло ли 24 часа с момента создания задачи.

## Подключение и сеансы

* **Базовый адрес**\: `https://{WorkspaceId}.{region}.maas.aliyuncs.com`. Сингапур, США, Пекин, Франкфурт и Токио используют разные региональные хосты; пути отправки и запроса одинаковы.
* **Заголовок аутентификации**\: `Authorization: Bearer PASTE_API_KEY_HERE`; при создании задачи обязательно добавляйте `X-DashScope-Async: enable`, без этого заголовка будет получена ошибка синхронного вызова.
* **Два набора адресов**\: для прямого подключения используйте `https://{WorkspaceId}.{region}.maas.aliyuncs.com`; используйте `https://api.dwchainless.com` и `Authorization: Bearer` с ключом сайта только при явном подтверждении сопоставления с этим шлюзом; одной замены адреса и аутентификации недостаточно. Если канал SimiRouter выполняет единую обёртку, `task_id`, строки статуса и поля результата могут быть переписаны; ориентируйтесь на документацию канала.
* **Таймаут и идемпотентность**\: после таймаута отправки сначала сохраните и запросите возможно уже созданный `task_id`, не повторяйте отправку сразу. Запросы опроса можно повторять, но задайте общий предел ожидания.
* **Сохранение результата**\: `video_url` — адрес загрузки с ограниченным сроком действия. Для долгосрочного использования скачайте и перекодируйте или пересохраните видео; не записывайте URL провайдера напрямую в базу данных продукта как постоянный ресурс.
