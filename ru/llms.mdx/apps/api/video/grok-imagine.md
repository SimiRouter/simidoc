# Видео Grok Imagine

## Обзор

Grok Imagine использует асинхронный видеоинтерфейс xAI\: `POST /v1/videos/generations` отправляет задачу и возвращает `request_id`, затем `GET /v1/videos/{request_id}` выполняет опрос. Текстовый промпт генерирует видео напрямую; при передаче `image` включается режим изображение в видео, при передаче референсных изображений или ключевых кадров — режим генерации по референсам.

| Что нужно сделать       | Ввод                                             | Вывод                     | Эндпоинт                      |
| ----------------------- | ------------------------------------------------ | ------------------------- | ----------------------------- |
| Текст в видео           | `prompt`, длительность, формат кадра, разрешение | `request_id`              | `POST /v1/videos/generations` |
| Изображение в видео     | `image` + необязательный `prompt`                | `request_id`              | Тот же эндпоинт               |
| Генерация по референсам | `prompt` + `reference_images` или `keyframes`    | `request_id`              | Тот же эндпоинт               |
| Запросить задачу        | `request_id`                                     | Статус, URL видео, расход | `GET /v1/videos/{request_id}` |

## Ключевые понятия

* **Жизненный цикл задачи**\: у статуса запроса есть только `pending`, `done`, `failed`. При `pending` значение `progress` находится в диапазоне 0–99, при `done` равно 100, при `failed` может отсутствовать.
* **`request_id` — идентификатор для опроса**\: это не ключ идемпотентности. После таймаута отправки нельзя по отсутствию ответа заключать, что задача не создана; сначала сохраните и запросите возможно существующий `request_id`.
* **Ритм опроса**\: официальная документация не задаёт фиксированный интервал. Клиент может использовать интервал 5–10 секунд и задать общий предел ожидания; после `failed` немедленно останавливайтесь.
* **Длительность и формат кадра**\: `duration` — от 1 до 15 секунд, по умолчанию 8 секунд; генерация по изображению игнорирует `aspect_ratio`, и формат кадра следует за входным изображением. `resolution` по умолчанию `480p`, `grok-imagine-video-1.5` поддерживает нативный 1080p.
* **Переключатель аудио**\: страница возможностей упоминает `generate_audio` со значением по умолчанию `true`; установка `false` запрашивает беззвучный результат; в REST-справке это поле отдельно не описано, фактическая доступность определяется ответом интерфейса.
* **Единица тарификации**\: `usage.cost_in_usd_ticks` в ответе запроса — счётчик стоимости этой задачи; конкретное преобразование, цена за единицу и расчёт неуспешных задач определяются страницей цен провайдера.

## Характеристики и возможности

| Показатель            | Подтверждённые значения                                                                                                          |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| ID модели             | `grok-imagine-video-1.5`, `grok-imagine-video-1.5-lite`, `grok-imagine-video`                                                    |
| Разрешение            | `480p` (по умолчанию), `720p`, `1080p`; `grok-imagine-video-1.5` — нативный 1080p                                                |
| Соотношение сторон    | `1:1`, `16:9` (по умолчанию), `9:16`, `4:3`, `3:4`, `3:2`, `2:3`, `21:9`, `5:2`; генерация по изображению игнорирует это поле    |
| Длительность          | 1–15 секунд, по умолчанию 8 секунд; при редактировании существующего видео произвольная длительность не принимается              |
| Аудио                 | `generate_audio` по умолчанию `true`; `false` запрашивает беззвучный результат; ориентируйтесь на описание страницы возможностей |
| Референсные материалы | `image` — первый кадр, `reference_images` — референсные изображения, `keyframes` — до 4, `last_frame` — последний кадр (1.5)     |
| Ввод изображения      | Публичный URL, Base64 data URI или `file_id` xAI Files API; JPEG, PNG, WebP                                                      |
| Учёт тарификации      | `usage.cost_in_usd_ticks`; цена за единицу — по странице цен провайдера                                                          |

Значение по умолчанию `480p` подходит для превью, а `720p` и `1080p` увеличивают время генерации и стоимость. Генерация по изображению игнорирует `aspect_ratio`, и формат кадра определяется `image`; чтобы управлять горизонтальным или вертикальным кадром, подготовьте входное изображение заранее. `duration` по умолчанию — 8 секунд, но фактическое время также зависит от очереди, поэтому оценивать только по длительности нельзя. `generate_audio` описан на странице возможностей, но не указан отдельно в REST-справке; перед интеграцией проверьте коротким запросом, принимает ли текущая модель это поле.

## Процесс вызова

1. Создайте API Key в консоли xAI; последующие запросы используют `Authorization: Bearer`.
2. Выберите способ генерации\: только `prompt` — текст в видео; добавление `image` — изображение в видео; добавление `reference_images`, `keyframes` или `last_frame` — генерация по референсам.
3. Вызовите `POST https://api.x.ai/v1/videos/generations` и задайте `duration`, `aspect_ratio`, `resolution` и переключатель аудио для целевой модели.
4. Сохраните `request_id` из ответа. Успешное создание означает только приём задачи.
5. Опрашивайте `GET https://api.x.ai/v1/videos/{request_id}`, пока `status` не станет `done` или `failed`.
6. После `done` скачайте `video.url`; если нужно записать в собственное объектное хранилище, в запросе можно использовать `output.upload_url` или `storage_options`. При `failed` читайте `error.code` и `error.message`.

## Имитация вызова

Ниже приведены примерные сообщения; `request_id`, URL и расход не являются реальными данными аккаунта.

Запрос создания\:

```json
{
  "model": "grok-imagine-video-1.5",
  "prompt": "示例：夜晚的霓虹街道，镜头缓慢前推。",
  "duration": 6,
  "aspect_ratio": "16:9",
  "resolution": "720p",
  "generate_audio": true
}
```

Успешное создание возвращает идентификатор для опроса\:

```json
{
  "request_id": "demo-request-0001"
}
```

Запрос до успешного конечного состояния\:

```json
{
  "status": "done",
  "progress": 100,
  "model": "grok-imagine-video-1.5",
  "video": {
    "url": "https://example.com/demo-grok-imagine.mp4",
    "duration": 6,
    "respect_moderation": true
  }
}
```

При `pending` продолжайте опрос; при `failed` остановитесь и прочитайте `error`. Если `video.respect_moderation` равно `false`, URL может быть пустым, и такой результат нельзя считать воспроизводимым.

## Подключение и сеансы

* **Базовый адрес**\: `https://api.x.ai`. Создание, запрос, редактирование и продление выполняются через `/v1/videos/generations`, `/v1/videos/{request_id}`, `/v1/videos/edits`, `/v1/videos/extensions`.
* **Заголовок аутентификации**\: `Authorization: Bearer PASTE_API_KEY_HERE`, тело запроса — JSON.
* **Два набора адресов**\: для прямого подключения используйте `https://api.x.ai`; используйте `https://api.dwchainless.com` и `Authorization: Bearer` с ключом сайта только при явном подтверждении сопоставления с этим шлюзом; одной замены адреса и аутентификации недостаточно. То, предоставляет ли канал SimiRouter `/v1/videos/*` и сохраняет ли `request_id` и поля статуса, определяется сопоставлением канала.
* **Таймаут и идемпотентность**\: публичного ключа идемпотентности нет. После таймаута отправки сначала запросите известный `request_id` и повторяйте только после подтверждения, что задачи нет; не отправляйте одинаковые промпты параллельно, чтобы обойти ожидание.
* **Сохранение результата**\: `video.url` — временный адрес; документация также приводит поля вывода файла и времени истечения. Продукт должен сначала скачать или сохранить файл, а затем предоставлять долговременную ссылку.
