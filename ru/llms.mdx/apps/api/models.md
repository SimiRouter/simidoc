# Список моделей

Список моделей — точка входа в настройку подключения\: сначала получите ID модели, затем по документации возможностей провайдера выберите интерфейс чата, зрения, изображений, аудио или инструментов. Видимость не означает доступность вызова, а список не является проверкой работоспособности в реальном времени.

## Обзор

| Что нужно проверить                 | Где смотреть                                                             | Пояснение                                                                                          |
| ----------------------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| Какие ID моделей существуют         | Интерфейс списка в этом разделе                                          | Возвращает только модели, видимые текущим учетным данным                                           |
| Можно ли действительно вызвать      | Модели и цены + реальный запрос                                          | Видимость, маршрутизация и наличие квоты — три разные вещи                                         |
| Какие входы и выходы поддерживаются | Описание возможностей модели                                             | Метаданные списка обычно неполны                                                                   |
| Когда модель будет отключена        | Официальное объявление провайдера о прекращении поддержки или отключении | Прекращение поддержки не означает немедленную недоступность, но новое подключение не рекомендуется |

## Ключевые понятия

* **ID модели**\: уникальный идентификатор в теле запроса, обычно зависит от регистра; копируйте его полностью, не сокращайте самостоятельно. Отображаемое имя, псевдонимы и фактический ID запроса могут различаться.
* **Видимость и возможность вызова**\: список отражает только модели в пределах прав; ненастроенный канал, недостаточный баланс или ограничение частоты всё равно приводят к ошибке.
* **Окно контекста**\: предел Token на вход плюс выход, различается по моделям; интерфейс списка часто не возвращает это значение.
* **Единица оплаты**\: текстовые модели чаще оплачиваются за Token, графические — за изображение или Token, видеомодели — часто за секунду или вызов; внутри одного семейства правила тоже могут различаться.
* **Дата отключения**\: дата, на которую провайдер планирует прекратить обслуживание; миграцию следует завершить до неё, а не обнаруживать проблему после.

## Интерфейс запроса

| Документация              | Запрос             | Структура ответа                                        |
| ------------------------- | ------------------ | ------------------------------------------------------- |
| [Формат OpenAI](/simidoc/ru/apps/api/models/openai) | GET /v1/models     | data\[].id, подходит для OpenAI-совместимых клиентов.   |
| [Формат Gemini](/simidoc/ru/apps/api/models/gemini) | GET /v1beta/models | models\[].name, подходит для клиентов протокола Gemini. |

## Способ вызова

Запрос списка — синхронный JSON-запрос, без SSE и асинхронных задач. Несколько учетных записей можно опрашивать параллельно, но их ключи и результаты нельзя смешивать. Для кеша списка задавайте срок действия и перечитывайте его, когда модель становится недоступной; не отправляйте реальный запрос генерации ради обновления списка.

## Имитация вызова

Отправьте GET-запрос без тела. Ниже приведён пример ответа шлюза SimiRouter.

```bash
curl "https://api.dwchainless.com/v1/models" \
  -H "Authorization: Bearer $SIMIROUTER_API_KEY"
```

```json
{
  "object": "list",
  "success": true,
  "data": [
    {
      "id": "MODEL_ID",
      "object": "model",
      "created": 1626777600,
      "owned_by": "custom",
      "context_length": 1048576,
      "supported_endpoint_types": ["openai"]
    }
  ]
}
```

Шлюз возвращает размер контекста и типы эндпоинтов. Размер контекста может быть значением по умолчанию. Цены, поддерживаемые форматы ввода и вывода и доступность инструментов проверяйте в документации модели. Пустой список обычно означает, что текущим учётным данным не доступны модели.

## Границы метаданных

Объект модели OpenAI содержит id, object, created и owned\_by; нативный объект Google может включать методы и лимиты Token. Шлюз может возвращать только сокращённые метаданные, поэтому нельзя выводить предел контекста, модальность или поддержку инструментов из отсутствующих полей.
