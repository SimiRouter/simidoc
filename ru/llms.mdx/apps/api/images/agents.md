# Вызовы изображений агентом перенесены в протоколы

Задания агенту распределены между тремя протоколами. В каждом есть шаблоны генерации и редактирования, подготовка, сохранение и обработка ошибок. Отдельное руководство с уклоном в OpenAI Images больше не поддерживается\:

* [Вызовы агентом в формате OpenAI](/simidoc/ru/apps/api/images/openai)\: генерация Images, редактирование JSON и проверка финальных событий.
* [Вызовы агентом в собственном формате Gemini](/simidoc/ru/apps/api/images/gemini)\: графические Part GenerateContent, MIME и контекст нескольких шагов.
* [Вызовы агентом в собственном формате Qwen](/simidoc/ru/apps/api/images/qwen)\: региональные настройки Model Studio, собственные синхронные вызовы и загрузка изображений по URL.

Агенту по-прежнему нужны локальное выполнение и проверка ответа; документы не устанавливают удалённые Skill. Реальные запросы могут оплачиваться\: до вызова подтвердите модель, параметры, количество и вывод. Не раскрывайте ключи, не перезаписывайте файлы и не повторяйте запросы автоматически. Сравнение API, эффектов и параметров — в [обзоре API изображений](/simidoc/ru/apps/api/images).
