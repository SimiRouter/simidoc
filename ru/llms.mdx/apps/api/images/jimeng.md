# Jimeng / генерация изображений Volcano Ark

## Обзор

Интерфейс генерации изображений Volcano Ark использует модели серии Seedream (`doubao-seedream-*`) и создаёт изображения по тексту или референсным изображениям. Запрос отправляется один раз и синхронно возвращает `data[]`; некоторые модели также поддерживают потоковую или пакетную генерацию.

| Что нужно сделать                     | Ввод                                    | Вывод                 | Эндпоинт                                                           |
| ------------------------------------- | --------------------------------------- | --------------------- | ------------------------------------------------------------------ |
| Создать изображение по тексту         | `prompt`                                | Новое изображение     | `POST https://ark.cn-beijing.volces.com/api/v3/images/generations` |
| Создать или изменить по референсу     | `prompt` + `image`                      | Новое изображение     | Тот же адрес                                                       |
| Пакетно создать несколько изображений | `prompt` + параметры пакетной генерации | Несколько изображений | Тот же адрес                                                       |

## Ключевые понятия

* **У `size` есть две формы записи**\: уровень разрешения (например, `2K`) или явные пиксели (например, `2048x2048`). Уровень — это пресет модели, а не фиксированная ширина и высота; фактические размеры в рамках одного уровня зависят от модели и описания кадра в промпте.
* **Референсное изображение помещается в `image`**\: это может быть HTTP(S) URL или `data:image/...;base64,...`. Передача массива означает несколько референсов, а максимальное количество зависит от модели.
* **`watermark` включён по умолчанию**\: при `true` на изображение добавляется метка «Сгенерировано ИИ»; для вывода без водяного знака явно передайте `false` и убедитесь, что использование соответствует применимым требованиям к маркировке синтетического контента.
* **Синхронный ответ**\: обычный запрос просто ожидает `data[]`. `stream` доступен только некоторым моделям, включая Seedream 5.0 lite, 4.5 и 4.0; добавить потоковый параметр недостаточно, чтобы превратить другую модель в асинхронную задачу.
* **Оплата за изображение**\: тарификация зависит от количества созданных изображений. Пакетный вывод `sequential_image_generation` суммируется по фактически созданным изображениям, а неуспешные элементы отдельно возвращаются в `data[].error`.

## Характеристики и возможности

| ID модели                         | Уровни `size` и ограничения                                             | Референсные изображения | Формат вывода                                                       |
| --------------------------------- | ----------------------------------------------------------------------- | ----------------------- | ------------------------------------------------------------------- |
| `doubao-seedream-5-5-261028`      | `1K`, `1.5K`, `2K` или `WxH`; пиксели 921600–4624220, пропорции 1/16–16 | До 10 изображений       | `url` / `b64_json`; `png` по умолчанию, также поддерживается `jpeg` |
| `doubao-seedream-5-0-lite-260128` | `2K`, `3K`, `4K` или `WxH`; пиксели 3686400–16777216, пропорции 1/16–16 | До 14 изображений       | `url` / `b64_json`; `png` / `jpeg`                                  |
| `doubao-seedream-4-5-251128`      | `2K`, `4K` или `WxH`; пиксели 3686400–16777216, пропорции 1/16–16       | До 14 изображений       | `url` / `b64_json`; `png` / `jpeg`                                  |
| `doubao-seedream-4-0-250828`      | `1K`, `2K`, `4K` или `WxH`; пиксели 921600–16777216, пропорции 1/16–16  | До 14 изображений       | `url` / `b64_json`; `png` / `jpeg`                                  |

Ограничение пикселей считается по общему числу пикселей, например 16777216 пикселей соответствует 4096×4096. ID моделей обновляются вместе с версиями; перед вызовом сверяйтесь с каталогом моделей Volcano Ark и разделом [Модели и цены](https://api.dwchainless.com/ru/pricing/); в `model` также можно указать ID точки вывода (`ep-...`).

## Процесс вызова

1. **Подготовьте ключ**\: создайте API Key в консоли Volcano Ark и используйте в заголовке запроса `Authorization: Bearer $ARK_API_KEY`.
2. **Выберите модель и размер**\: проверьте поддерживаемые моделью уровни `size` или диапазон пикселей и решите, нужно ли референсное изображение.
3. **Отправьте JSON-запрос**\: на `/api/v3/images/generations` передайте `model`, `prompt`, при необходимости добавьте `image`, `size`, `response_format` и `watermark`.
4. **Прочитайте `data[]`**\: при `response_format` равном `url` берите `data[].url` (срок действия 24 часа), при `b64_json` декодируйте `data[].b64_json`.
5. **Сохраните и проверьте**\: убедитесь, что файл открывается, проверьте фактические размеры и содержимое; при пакетной генерации проверяйте `data[].error` для каждого элемента, а не только HTTP-статус.
6. **Сверьте стоимость**\: в журнале использования проверьте модель, количество изображений и списание; пакетный вывод считается по фактически успешно созданным изображениям.

## Имитация вызова

Приведённые ниже сообщения являются примером, а не реальным ответом аккаунта; URL и Base64 обрезаны, а значения не отражают текущие цены.

Запрос\:

```json
{
  "model": "doubao-seedream-5-5-261028",
  "prompt": "一只小机器人在图书馆阅读，水彩插画，不要文字。",
  "size": "2K",
  "response_format": "url",
  "watermark": true
}
```

Успешный ответ (синхронный)\:

```json
{
  "created": 1763366400,
  "model": "doubao-seedream-5-5-261028",
  "data": [
    {
      "url": "https://example.com/generated-image.png",
      "size": "2048x2048",
      "output_format": "png"
    }
  ]
}
```

Если изображение не создано, возвращается `error` верхнего уровня; при пакетной генерации неуспешный элемент в `data[].error` содержит `code` и `message`.

## Подключение и сеансы

* **Базовый URL**\: `https://ark.cn-beijing.volces.com/api/v3`.
* **Аутентификация**\: `Authorization: Bearer $ARK_API_KEY`. Ключ передаётся только в заголовке запроса; не записывайте его в промпт или исходный код.
* **Отличия от OpenAI Images**\: путь — `/api/v3/images/generations`, а не `/v1/images/generations`; параметра `quality` нет; в `size` можно сразу указывать уровни `1K`, `2K`; возвращается `data[].url` или `data[].b64_json`.
* **Вызов через шлюз сайта**\: адрес запроса меняется на `https://api.dwchainless.com/v1/images/generations`, а для аутентификации используется ключ сайта; передаётся ли тело запроса без изменений и доступен ли ID модели, определяется каналом и разделом [Модели и цены](https://api.dwchainless.com/ru/pricing/).
* **Таймаут**\: синхронная генерация может длиться десятки секунд, поэтому клиентский таймаут должен быть заметно больше, чем для обычных текстовых запросов; после таймаута сначала проверьте журнал вызовов, убедитесь, были ли созданы изображения и списание, и только потом решайте, повторять ли запрос.
* **Пакетность и поток**\: `sequential_image_generation` и `stream` поддерживаются только частью моделей; при одновременном включении проверяйте результат по финальному событию завершения или полному `data[]`, промежуточные результаты не считаются готовыми изображениями.
