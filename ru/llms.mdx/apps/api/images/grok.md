# Генерация изображений xAI Grok

## Обзор

Интерфейс генерации изображений xAI Grok использует путь и конверт ответа OpenAI Images, но параметры запроса являются нативными полями xAI\: формат кадра задаётся через `aspect_ratio` и `resolution`, а не через `size`. По умолчанию ответ синхронный, но можно включить `deferred` и опрашивать задачу.

| Что нужно сделать                          | Ввод                        | Вывод                         | Эндпоинт                                          |
| ------------------------------------------ | --------------------------- | ----------------------------- | ------------------------------------------------- |
| Создать изображение по тексту              | `prompt`                    | Новое изображение             | `POST https://api.x.ai/v1/images/generations`     |
| Создать несколько изображений за раз       | `prompt` + `n` (1–10)       | Несколько изображений         | Тот же адрес                                      |
| Получить результат после фоновой генерации | `prompt` + `deferred: true` | `request_id`, затем опрос     | Тот же адрес, опрос `GET /v1/images/{request_id}` |
| Отредактировать существующее изображение   | `prompt` + изображение      | Отредактированное изображение | `POST https://api.x.ai/v1/images/edits`           |

## Ключевые понятия

* **`aspect_ratio` заменяет `size`**\: интерфейс не принимает OpenAI `size` и `style`. Формат кадра управляется `aspect_ratio`; распространённые значения включают `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `2:3`, `3:2`, `21:9` и `auto`.
* **`resolution` управляет уровнем разрешения**\: принимает `1k` или `2k`, по умолчанию `1k`. Это уровень, а не значение в пикселях; фактические ширина и высота в рамках одного уровня определяются `aspect_ratio`.
* **`quality` действует только для модели 2.0**\: доступны `low`, `medium`, `auto`; `auto` при генерации сейчас обрабатывается как `low`, а при редактировании — как `medium`.
* **По умолчанию синхронно, `deferred` включает асинхронность**\: синхронный запрос напрямую возвращает `data[]`; при `deferred: true` сразу возвращается `request_id`, затем выполняется опрос `GET /v1/images/{request_id}`. Отложенные задачи поддерживают только `response_format: "url"`, результат хранится 24 часа.
* **URL временный**\: при `response_format` равном `url` (по умолчанию) возвращённый адрес изображения истекает; для долговременного хранения вовремя скачайте файл или используйте `b64_json`.
* **Оплата за изображение**\: `n` задаёт количество изображений в одном запросе в диапазоне 1–10. `usage.cost_in_usd_ticks` в ответе содержит сведения о стоимости этого запроса; фактический расчёт определяется счётом сайта.

## Характеристики и возможности

| ID модели                | Уровень разрешения | Соотношение сторон                                                                                                         | Референсное изображение                                                                                       | Формат ответа        |
| ------------------------ | ------------------ | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | -------------------- |
| `grok-imagine-image-2.0` | `1k`, `2k`         | `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`, `2:1`, `1:2`, `19.5:9`, `9:19.5`, `20:9`, `9:20`, `21:9`, `5:2`, `auto` | Интерфейс генерации не принимает референсные изображения; редактирование выполняется через `/v1/images/edits` | `url` или `b64_json` |

`grok-2-image` — старое имя модели; текущая официальная документация интерфейса использует `grok-imagine-image-2.0`. Перед вызовом уточните в разделе [Модели и цены](https://api.dwchainless.com/ru/pricing/) фактический ID модели, предоставляемый каналом сайта, и не копируйте имена из старых руководств.

## Процесс вызова

1. **Подготовьте ключ**\: создайте ключ в консоли xAI и используйте в заголовке запроса `Authorization: Bearer $XAI_API_KEY`.
2. **Уточните модель**\: сверьте в разделе [Модели и цены](https://api.dwchainless.com/ru/pricing/) `grok-imagine-image-2.0` или эквивалентную модель канала.
3. **Выберите формат кадра**\: задайте `aspect_ratio` и `resolution`; не отправляйте `size`.
4. **Отправьте запрос**\: передайте JSON на `/v1/images/generations`. Если ожидается долгая генерация, добавьте `deferred: true`.
5. **Прочитайте результат**\: в синхронном ответе берите `data[].url` или `data[].b64_json`; для отложенной задачи сначала дождитесь состояния `done`, затем читайте `data[]`.
6. **Сохраните и проверьте**\: скачайте изображение до истечения URL, убедитесь, что файл открывается, проверьте размеры и содержимое, затем сверьте журнал использования.

## Имитация вызова

Приведённые ниже сообщения являются примером, а не реальным ответом аккаунта; URL и значения стоимости обрезаны или приведены только для иллюстрации.

Синхронный запрос\:

```json
{
  "model": "grok-imagine-image-2.0",
  "prompt": "一只小机器人在图书馆阅读，水彩插画，不要文字。",
  "n": 1,
  "aspect_ratio": "1:1",
  "resolution": "1k",
  "response_format": "url"
}
```

Успешный синхронный ответ\:

```json
{
  "data": [
    {
      "url": "https://imgen.x.ai/example/image.jpeg",
      "mime_type": "image/jpeg"
    }
  ],
  "usage": {
    "cost_in_usd_ticks": 40000
  }
}
```

Запрос отложенной задачи\:

```json
{
  "model": "grok-imagine-image-2.0",
  "prompt": "一只小机器人在图书馆阅读，水彩插画，不要文字。",
  "n": 1,
  "aspect_ratio": "1:1",
  "resolution": "1k",
  "deferred": true
}
```

Примерный ответ после отправки\:

```json
{
  "request_id": "req_example_01"
}
```

Примерный ответ после завершения опроса (HTTP 200; во время обработки — 202, при ошибке возвращаются `error.code` и `error.message`)\:

```json
{
  "data": [
    {
      "url": "https://imgen.x.ai/example/image.jpeg",
      "mime_type": "image/jpeg"
    }
  ],
  "usage": {
    "cost_in_usd_ticks": 40000
  }
}
```

## Подключение и сеансы

* **Базовый URL**\: `https://api.x.ai/v1`. Эндпоинт генерации — `/v1/images/generations`, эндпоинт редактирования — `/v1/images/edits`.
* **Аутентификация**\: `Authorization: Bearer $XAI_API_KEY`. OpenAI SDK можно переиспользовать, указав `base_url` равным `https://api.x.ai/v1`, но поля запроса всё равно заполняются по документации xAI.
* **Отличия от OpenAI**\: путь и конверт `data[]` похожи, но `size` и `style` не поддерживаются; вместо них используются `aspect_ratio`, `resolution`, `quality`. Максимум `n` — 10.
* **Отложенные задачи**\: `deferred` поддерживает только вывод URL; после отправки опрашивайте `GET /v1/images/{request_id}`; результат хранится 24 часа, после истечения нужно генерировать заново.
* **Вызов через шлюз сайта**\: адрес запроса меняется на `https://api.dwchainless.com/v1/images/generations`, а для аутентификации используется ключ сайта; передача ID модели и параметров определяется каналом.
* **Таймаут**\: синхронная генерация обычно завершается в одном запросе, но клиент всё равно должен оставлять достаточный таймаут; при непредсказуемом времени или пакетной генерации предпочитайте `deferred` и не отправляйте запрос вслепую после таймаута.
