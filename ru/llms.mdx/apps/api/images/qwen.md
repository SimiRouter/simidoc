# Нативный интерфейс изображений Qwen

Раздел использует нативное тело запроса Qwen, но единообразно вызывает его через шлюз сайта\: `API_URL` — `https://api.dwchainless.com/v1/images/...`, авторизация — `API_KEY` сайта. Параметры запроса сохраняют `model`, `input.messages`, `parameters`, ответ унифицирован как `data[]`; сначала выполните один вызов для одной картинки, затем увеличивайте количество или подключайте агента.

## Формат и параметры запроса

| API                                        | Формат запроса                      | Основные параметры                                       | Подробная документация                                       |
| ------------------------------------------ | ----------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------ |
| Текст в изображение                        | `POST /v1/images/generations`, JSON | `model`, `input.messages[].content[].text`, `parameters` | [Параметры генерации и код на четырёх языках](/simidoc/ru/apps/api/images/qwen/generations) |
| Редактирование / изображение в изображение | `POST /v1/images/edits`, JSON       | `content[]` с `image` и одним `text`, плюс `parameters`  | [Параметры редактирования и код на четырёх языках](/simidoc/ru/apps/api/images/qwen/edits)  |

Примеры серии 2.0 на этой странице помещают в `input.messages` одно сообщение `user`; текст описывает объект, композицию, стиль и надписи, которые нужно отрисовать; при редактировании добавляется разрешённый URL изображения или поддерживаемый моделью data URL. Замена фона, смена стиля, правка надписей на изображении и объединение нескольких изображений относятся к целям редактирования; отдельные multipart-поля OpenAI не вводятся, и сохранение деталей пиксель в пиксель не гарантируется.

### Параметры изображения

Размер указывается в `parameters.size` в формате `width*height`, например `"2048*2048"`; не `"2048x2048"` и не `"2K"`. Серия 2.0 ограничивает размеры диапазоном общего числа пикселей; конкретные входные изображения, ширину и высоту, а также ограничения вывода нужно проверять по модели; ограничение общего числа пикселей не равно ограничению длинной стороны.

| Три поштучных тарифа сайта | Длинная сторона запроса  | Пример в пикселях |
| -------------------------- | ------------------------ | ----------------- |
| 1K                         | ≤ 1024 пикселей          | 1024×1024         |
| 2K                         | > 1024 и ≤ 2048 пикселей | 1536×1024         |
| 4K                         | > 2048 пикселей          | 2560×1440         |

Эта таблица объясняет только тарифные уровни конкретных моделей сайта и не означает, что модель принимает параметры `1K` / `2K` / `4K`. Вызовы через сайт тарифицируются по разделу [Модели и цены](https://api.dwchainless.com/ru/pricing/), см. также [обзор характеристик и тарификации](/simidoc/ru/apps/api/images). Большее число пикселей не гарантирует правильность надписей и деталей; при неподдерживаемом целевом размере должна возвращаться ошибка, а не молчаливая замена.

## Поля ответа

| Поле                    | Значение и обработка                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------ |
| `created`               | Временная метка создания ответа.                                                                 |
| `data[].url`            | URL финального изображения; срок действия определяется каналом, скачивайте и сохраняйте вовремя. |
| `data[].b64_json`       | Некоторые каналы возвращают чистый Base64; при наличии можно сразу декодировать и сохранить.     |
| `data[].revised_prompt` | Переписанный каналом промпт; может отсутствовать.                                                |
| `error` / `message`     | Код и описание ошибки; даже при успешном HTTP проверяйте бизнес-ошибку и наличие изображения.    |

Тело запроса — нативная структура Qwen, ответ — унифицированный `data[]`. Не копируйте протоколы других каналов с `prompt`, multipart или асинхронным `task_id`; ID модели должен совпадать с именем, которое фактически предоставляет канал сайта.

## Примеры вызова

### Подготовка конфигурации

Проверьте доступные модели и баланс в разделе [Модели и цены](https://api.dwchainless.com/ru/pricing/) и используйте ключ, созданный на сайте. `API_URL` всегда указывает на шлюз сайта; ID рабочего пространства, региональные домены или официальный ключ Bailian не нужны.

| Настройка   | Назначение                                                                                                               |
| ----------- | ------------------------------------------------------------------------------------------------------------------------ |
| `API_KEY`   | Ключ сайта; укажите прямо в примере, не вставляйте в промпты, код, скриншоты или Git.                                    |
| `API_URL`   | Полный адрес запроса шлюза сайта, например `https://api.dwchainless.com/v1/images/generations`.                          |
| `model`     | В примерах — `qwen-image-2.0-pro`; сначала убедитесь, что канал сайта поддерживает эту модель и нужные возможности.      |
| `IMAGE_URL` | Разрешённый, доступный из облака HTTP(S)-адрес изображения для примера редактирования; не локальный путь и не localhost. |

[Пример генерации](/simidoc/ru/apps/api/images/qwen/generations) и [пример редактирования](/simidoc/ru/apps/api/images/qwen/edits) содержат Python, Node.js, curl и Go. Текущий код отправляет один запрос и печатает JSON, но **не скачивает изображения автоматически**. Сохраните код Python как `generate.py` / `edit.py` и запустите `python3 generate.py` / `python3 edit.py`; код Node.js — как `generate.mjs` / `edit.mjs` и запустите `node generate.mjs` / `node edit.mjs`. Настройте среду выполнения и переменные по требованиям соответствующей страницы\: сначала запросите только одно изображение, затем сохраните реальный файл по URL, как описано в следующем разделе.

### Демо генерации с агентом

Агенту нужны локальные скрипты, сетевые запросы и проверка возвращённых результатов; эта страница не является инструкцией по установке Skill и не добавляет таких возможностей чисто текстовому клиенту.

```text
Read this Qwen image protocol page and its generation reference first. Use the
existing API_KEY and API_URL from this site's gateway; never print, paste, commit,
or store the key in source files. Use the documented qwen-image-2.0-pro model only
after checking availability and pricing. For this one approved request, POST once
to /v1/images/generations with the native Qwen body: one user message, one text
content item, parameters.n=1 and size=1024*1024 if supported. Image brief: a calm
blue library with a small robot reading, watercolor illustration, no lettering.
Print the returned JSON and inspect data[].url or data[].b64_json; report the final
image URL without forwarding the API key. JSON or a URL alone is not a saved image.
Do not switch model/provider, increase size/count, write files, install remote
skills, or automatically retry an error or timeout. Ask before another paid request.
```

### Демо редактирования с агентом

Используйте только изображения, на обработку и загрузку которых есть разрешение; сначала проверьте персональные данные и коммерческие секреты. Текущий пример читает URL и не загружает локальные файлы автоматически на другие сервисы.

```text
Read this Qwen image protocol page and its editing reference first. Use the existing
API_KEY and API_URL from this site's gateway; never reveal the key or switch the
existing connection. Verify qwen-image-2.0-pro supports the edit. Use only the
authorized cloud-readable image in IMAGE_URL; do not upload unrelated local files or
publish a file. POST once to /v1/images/edits with the native Qwen body: one user
message containing that image item and one text instruction: keep the subject and
layout; change only the background to pale blue. Set parameters.n=1 and size=1024*1024
only if supported. Do not use OpenAI multipart or mask fields. Check the completed
business result, inspect data[].url or data[].b64_json without forwarding the API key,
and report it. Do not write files, change model/size/count/provider, install remote
skills, or retry automatically. If any step fails or the requested edit is not met,
report a redacted error instead of claiming success.
```

## Сохранение и критерии завершения

* Синхронный ответ — не задача для опроса; в этом разделе не используются `task_id` или `X-DashScope-Async`. Не смешивайте асинхронные протоколы других моделей и не считайте потоковые события критерием завершения.
* Проверьте HTTP- и бизнес-ошибки, причину завершения и фактические элементы изображений, затем обойдите URL изображений. Срок действия URL ограничен — скачивайте как можно скорее; JSON, адрес или устный вывод агента не означают, что файл сохранён.
* При скачивании проверяйте статус ответа, содержимое и заголовок файла; не переименовывайте страницу ошибки в PNG; не отправляйте ключ сайта домену хранения результатов. Сохраняйте исходные файлы; при ошибке удаляйте только некорректный вывод, созданный этой операцией.
* Убедитесь, что файл существует, открывается, а его размер и содержимое соответствуют требованиям, и сверьте запрос и стоимость в счёте или журнале использования сайта. Для нескольких изображений проверяйте каждое по отдельности и не вызывайте API автоматически ради восполнения количества.

## Ошибки, повторы и стоимость

При ошибке параметров сначала проверьте `model`, структуру сообщений, `size` и входное изображение; при ошибке авторизации — ключ сайта и права на модель; при ошибке квоты или лимита — состояние аккаунта. При тайм-ауте, 5xx или неоднозначном результате сначала проверьте журнал вызовов и существующие файлы, не повторяйте запрос автоматически, чтобы избежать повторной генерации или списания. Сообщайте только обезличенные ошибки, не выводите ключи, полный Base64 или приватные изображения.

Реальные генерация и редактирование могут оплачиваться. До вызова уточните модель, размер, количество и место вывода; приращение, повышение уровня параметров или повтор требуют нового подтверждения. Для параллельных запросов отдельно контролируйте лимиты, тайм-ауты и стоимость; `n` — количество в одном запросе. Итоговая тарификация определяется правилами и счётом сайта.
