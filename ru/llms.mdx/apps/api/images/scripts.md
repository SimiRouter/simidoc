# Примеры изображений сгруппированы по протоколам

Общее руководство по скриптам, подходящее только для OpenAI Images, больше не используется. Выберите фактический протокол. Каждая страница построена по схеме «формат и параметры запроса → поля ответа → примеры вызова» и содержит параметры изображения, ссылки на код на четырёх языках, задания агенту и безопасное сохранение\:

* [Формат OpenAI](/simidoc/ru/apps/api/images/openai)\: генерация и редактирование Images, генерация в диалоге Responses и понимание изображения.
* [Собственный формат Gemini](/simidoc/ru/apps/api/images/gemini)\: текстовые и графические Part в GenerateContent, сохранение Base64-изображений.
* [Собственный формат Qwen](/simidoc/ru/apps/api/images/qwen)\: официальные региональные эндпоинты Model Studio, собственная структура сообщений и сохранение результата по URL.

Сравнение API, эффектов и параметров 1K / 2K / 4K — в [обзоре API изображений](/simidoc/ru/apps/api/images). Страница сохранена для прежних ссылок; при вызове следуйте нужному протоколу. Учётные данные, параметры и поля ответов разных протоколов нельзя смешивать.
