# Музыка (не поддерживается)

В этом разделе описан публичный протокол генерации Google Lyria. SimiRouter пока не открыл эту возможность; все примеры напрямую подключаются к Gemini API Google AI Studio через `https://generativelanguage.googleapis.com` с ключом Google API. Для Vertex AI требуется отдельный протокол, не проверенный на этой странице; не подменяйте адрес напрямую.

## Обзор

| Возможность                      | Входные данные                                                         | Результат                                                            | Характер раздела               |
| -------------------------------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------- | ------------------------------ |
| Генерация музыкального фрагмента | Текстовое описание или изображение                                     | Около 30 секунд аудио, по умолчанию MP3                              | Справочник по официальному API |
| Генерация полной песни           | Запрос с описанием куплетов и припевов                                 | Песня длительностью несколько минут, возможно с текстом и структурой | Справочник по официальному API |
| Исполнение в реальном времени    | Непрерывно передаваемые запросы и элементы управления воспроизведением | Непрерывные блоки PCM-аудио                                          | Справочник по официальному API |

## Ключевые понятия

* **Фрагмент и песня**\: фрагмент имеет фиксированную длительность 30 секунд и подходит для прослушивания и зацикливания; длительность и структура песни определяются запросом, поэтому точная продолжительность не гарантируется.
* **Сеанс в реальном времени**\: двунаправленный WebSocket, через который во время соединения непрерывно передаются запросы и команды PLAY и PAUSE; это не однократный запрос с включенным stream.
* **Аудиоформат**\: по умолчанию MP3, по запросу WAV; интерфейс реального времени возвращает необработанные блоки PCM, которые приложение должно буферизовать и упаковывать самостоятельно.
* **Ключи и адреса**\: примеры на этой странице используют только адрес Gemini API Google AI Studio и ключ Google API; SimiRouter пока не проксирует музыкальные модели, а отдельный протокол Vertex AI здесь не проверен.

Ограничения длительности, частота дискретизации и битрейт зависят от модели; см. таблицы параметров [Lyria](/simidoc/ru/apps/api/music/lyria) и [RealTime](/simidoc/ru/apps/api/music/realtime).

## Описание интерфейса

| Режим                        | Официальный протокол        | Возможность                                                             | Документация                      |
| ---------------------------- | --------------------------- | ----------------------------------------------------------------------- | --------------------------------- |
| Однократная генерация музыки | `POST /v1beta/interactions` | Создание фрагмента или полной песни по тексту либо изображению          | [Генерация музыки Lyria](/simidoc/ru/apps/api/music/lyria) |
| Музыка в реальном времени    | Двунаправленный WebSocket   | Непрерывная генерация инструментальной музыки с динамической настройкой | [Lyria RealTime](/simidoc/ru/apps/api/music/realtime)      |

Lyria Clip создает 30-секундные фрагменты; Lyria 3.5 предназначена для более полных песен. Экспериментальный RealTime использует постоянное соединение и не равнозначен флагу stream в Interactions. Музыкальные модели не предназначены для озвучивания текста; для этого используйте [Аудио](/simidoc/ru/apps/api/audio).

## Имитация вызова

Официальная однократная генерация Google использует Interactions; запрос описывает стиль и структуру\:

```json
{
  "model": "lyria-3-clip-preview",
  "input": "温暖的钢琴与弦乐，节奏舒缓，适合纪录片开场"
}
```

Аудио в ответе — Base64, а не ссылка для скачивания\:

```json
{
  "steps": [
    {
      "type": "model_output",
      "content": [
        { "type": "text", "text": "[Instrumental]" },
        { "type": "audio", "data": "<Base64音频>" }
      ]
    }
  ]
}
```

Аудио- и текстовые элементы могут чередоваться; нужно пройти по `content[]` и выбирать их по `type`; если взять только последний элемент, можно пропустить текст песни или описание структуры.

## Аутентификация и права

Официальный Google Interactions использует `x-goog-api-key: $GEMINI_API_KEY`. Для реального времени применяются официальный SDK или WebSocket-протокол. Необходимо соблюдать условия Google, авторские права и права на голос. Доступность моделей, регионов и квот определяется учетной записью Google.
