# Установка Gemini CLI

## **Установка Gemini CLI**

Убедитесь, что установлен Node.js v20 или новее, затем установите Gemini CLI глобально через npm\:

```bash
npm install -g @google/gemini-cli
```

После установки проверьте результат\:

```bash
gemini --version
```

Для обновления до последней версии\:

```bash
npm upgrade -g @google/gemini-cli
```

## Настройка сервиса моделей

После установки по инструкции [Настройка Gemini CLI](/simidoc/ru/apps/gemini-config) задайте адрес SimiRouter и ключ API.
