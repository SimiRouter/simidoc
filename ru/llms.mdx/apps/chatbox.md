# Настройка Chatbox AI

Руководство основано на настольном Chatbox AI 1.21.1\: подключение SimiRouter через встроенного провайдера **OpenAI**. В других версиях названия и расположение элементов могут отличаться; снимки показывают китайский интерфейс.

<Callout type="warn" title="Защита ключа API">
  Ключ API дает право на вызовы. Не передавайте его другим и не показывайте на публичных снимках экрана. Проверка подключения и диалог могут тарифицироваться\: сначала проверьте квоту и цены моделей.
</Callout>

## Подготовка

1. С [официального сайта Chatbox AI](https\://chatboxai.app/) скачайте и установите приложение.
2. Войдите в SimiRouter; на странице [Ключи API](https://api.dwchainless.com/keys) создайте или скопируйте ключ и убедитесь, что для модели достаточно прав и квоты.

![Страница ключей API SimiRouter со скрытыми данными ключа](/simidoc/assets/chatbox/03a-create-api-key.png)

## Настройка подключения

### 1. Открытие настроек и выбор провайдера

В левом нижнем углу Chatbox нажмите **Настройки**.

![Открытие настроек Chatbox](/simidoc/assets/chatbox/01-open-settings.png)

Откройте **Провайдеры моделей** и выберите **OpenAI**. Используется ключ API, а не OAuth. Это изменит настройки провайдера OpenAI; если он уже подключен к другому сервису, предварительно сохраните прежние значения.

![Выбор OpenAI среди провайдеров моделей](/simidoc/assets/chatbox/02-select-openai.png)

### 2. Ключ API и адрес сервера

| Параметр                    | Значение                                          |
| --------------------------- | ------------------------------------------------- |
| Ключ API                    | Вставьте скопированный ключ SimiRouter            |
| Хост API                    | `https://api.dwchainless.com`                     |
| Предпросмотр адреса запроса | `https://api.dwchainless.com/v1/chat/completions` |

Укажите хост из таблицы и сохраните путь API по умолчанию; не добавляйте путь к адресу хоста вручную. Если путь ранее меняли, восстановите его и проверьте предпросмотр адреса.

![Ввод ключа API и хоста провайдера OpenAI](/simidoc/assets/chatbox/03b-fill-api-fields.png)

### 3. Получение и добавление моделей

В области моделей нажмите **Получить**; найдите модель и нажмите рядом **+** для добавления. Если список недоступен, выберите **Создать** и укажите точный ID доступной модели вручную. Не все модели списка обязательно разрешены данному ключу\: учитывайте права и доступный список моделей.

![Поиск и добавление модели](/simidoc/assets/chatbox/04-add-models.png)

### 4. Проверка подключения и начало диалога

Для нужной модели нажмите **Проверить**. Даже после сообщения об успешном подключении отправьте короткий запрос для проверки диалога. Некоторые модели поддерживают только текст; неудачная проверка изображений или инструментов не обязательно исключает текстовые запросы.

![Пример результата проверки подключения модели](/simidoc/assets/chatbox/05-check-success.png)

Закройте настройки и нажмите **Новый диалог**; в меню у поля ввода выберите добавленную модель группы OpenAI и отправьте короткое сообщение. Получив ответ, проверьте запрос и реальную модель в журнале использования SimiRouter.

![Создание диалога и выбор добавленной модели](/simidoc/assets/chatbox/06-new-chat-select-model.png)

## Частые вопросы

* **Не удалось получить модели\:** проверьте сеть, хост и ключ; можно добавить модель по точному ID вручную.
* **401 или ошибка аутентификации\:** проверьте полноту и действительность ключа, удалите пробелы; при необходимости создайте новый ключ.
* **404 или неверный путь\:** проверьте предпросмотр адреса, восстановите путь по умолчанию и исключите повторное добавление пути.
* **Модель не найдена или диалог не работает\:** проверьте реальный ID модели, права ключа, квоту и выбранную в диалоге модель.
* **Ошибка изображений или инструментов\:** проверьте поддержку нужной возможности моделью и API; если нужен только текст, проверьте текстовый запрос отдельно.
