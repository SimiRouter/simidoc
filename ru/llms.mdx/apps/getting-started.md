# Создание ключа SimiRouter

Руководство описывает регистрацию или вход, создание ключа API и первый вызов SimiRouter. При наличии учетной записи сразу войдите; инструкции клиентов и параметры API находятся на отдельных страницах.

## 1. Регистрация или вход

Откройте [страницу регистрации](https://api.dwchainless.com/sign-up) и создайте учетную запись; существующие пользователи могут [войти](https://api.dwchainless.com/sign-in). Способы и доступность регистрации указаны в интерфейсе.

После входа откройте [Кошелёк](https://api.dwchainless.com/wallet) и проверьте квоту и доступ модели для группы учетной записи и ключа. Для пополнения или использования кода следуйте подсказкам на странице кошелька; тариф, зачисление и срок действия указаны там. Не платите повторно.

## 2. Создание ключа API

Откройте [Ключи API](https://api.dwchainless.com/keys) и выберите создание ключа. Укажите группу, права моделей, квоту и срок действия; сначала изучите незнакомые поля, затем сохраните и скопируйте ключ.

![Управление ключами API и кнопка создания](/simidoc/assets/start/start5.png)

<Callout type="warn" title="Защита ключа">
  Ключ API дает право выполнять запросы. Не помещайте его в публичные репозитории, снимки и журналы и не передавайте ненадежным приложениям. При подозрении на утечку немедленно отзовите ключ и создайте новый.
</Callout>

## 3. Три независимых настройки подключения

| Настройка            | Назначение               | Важно                                                                                                      |
| -------------------- | ------------------------ | ---------------------------------------------------------------------------------------------------------- |
| Адрес API / Base URL | Куда отправляется запрос | Следуйте инструкции клиента\: некоторым нужен `/v1`, другим — корневой адрес. Не дублируйте пути.          |
| API Key              | Проверка прав вызова     | Используйте новый ключ, а не пароль входа.                                                                 |
| Имя модели           | Выбор модели запроса     | Откройте [Каталог моделей](https://api.dwchainless.com/ru/pricing/) и скопируйте полный ID модели\: имя, группа и права должны совпадать. |

Адрес API, ключ и имя модели — независимые поля. Не добавляйте ключ в URL.

## 4. Выбор клиента

* [Настольный Codex](/simidoc/ru/apps/codex-desktop)\: настольная среда разработки.
* [Codex CLI](/simidoc/ru/apps/installation/codex-cli)\: установка и подключение CLI.
* [Claude Code](/simidoc/ru/apps/installation/claude-code)\: установка, окружение и использование.
* [WorkBuddy](/simidoc/ru/apps/workbuddy)\: пользовательские модели настольного клиента.
* [Скрипты API](/simidoc/ru/apps/api-script)\: интеграция собственной программы через примеры запросов.

У клиентов разные поля и протоколы. Следуйте соответствующей инструкции, не переносите конфигурационный файл другого клиента целиком.

## 5. Небольшой тест и проверка записей

После сохранения отправьте короткий запрос. Откройте [Журнал использования](https://api.dwchainless.com/usage-logs/common) и проверьте время, модель, статус и расход. Супер-администраторы видят глобальные журналы; администраторы — собственные запросы, пополнения, административные действия и ошибки; обычные пользователи — собственные запросы, пополнения и административные действия, но не журналы ошибок. Сводная статистика доступна в [панели данных](https://api.dwchainless.com/dashboard).

Ответ модели подтверждает только получение результата этого запроса, но не реальный маршрут. При ошибке проверьте адрес, ключ, полный ID и права группы; используйте текст ошибки и ID запроса. Поддержке передавайте обезличенные сведения, без ключа.
