# Настройка LunaTranslator

<Callout type="info" title="">
  LunaTranslator — бесплатный открытый переводчик визуальных новелл (GalGame), предназначенный для удобного чтения игр на родном языке.
</Callout>

* Проект\: [https\://github.com/HIllya51/LunaTranslator](https\://github.com/HIllya51/LunaTranslator)
* Документация проекта\: [https\://docs.lunatranslator.org](https\://docs.lunatranslator.org/zh/README.html)

## Возможности

* **HOOK** извлекает текст из поддерживаемых визуальных новелл через HOOK; совместимость уточняйте в официальной документации

* **Встроенный перевод**\: в некоторых играх перевод можно выводить непосредственно в игре

* **HOOK для эмуляторов** читает текст через HOOK в поддерживаемых эмуляторах и играх

* **OCR**\: встроена OCR-модель и доступны разные онлайн- и офлайн-движки для извлечения текста

* **Интерфейсы перевода**\: поддерживается настройку разных языковых моделей и офлайн-переводчиков

* **Изучение языков**\: поддерживаются японскую токенизацию и фуригану, AnkiConnect и Yomitan

* **Синтез речи**\: доступны разные онлайн- и офлайн-движки синтеза речи

* **Распознавание речи**\: можно использовать распознавание Windows 10 и Windows 11.

## Способ установки

Следуйте инструкции [LunaTranslator\: загрузка, запуск и обновление](https\://docs.lunatranslator.org/zh/README.html) для установки приложения

## Ручное подключение SimiRouter в LunaTranslator

1. В разделе SimiRouter [Ключи API](https://api.dwchainless.com/keys) скопируйте нужный ключ API.
2. В LunaTranslator откройте **Настройки → Перевод → Большие модели**, добавьте интерфейс, скопировав универсальный шаблон большой модели.
3. Откройте настройки нового интерфейса и в поле **Адрес API** укажите `https://api.dwchainless.com`, в поле **API Key** вставьте ключ; обновите список либо введите полный ID доступной модели.
4. Сохраните и включите интерфейс. Переведите небольшой неконфиденциальный текст и проверьте вызов в журнале SimiRouter.

Не публикуйте ключ на снимках. Названия параметров могут отличаться между версиями; подробнее см. [официальную документацию LunaTranslator](https\://docs.lunatranslator.org/zh/guochandamoxing.html).
