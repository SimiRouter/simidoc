# Руководство WorkBuddy

<Callout type="info" title="Применимость">
  Руководство предназначено для настольного WorkBuddy с функцией пользовательских моделей. Расположение и названия полей зависят от версии\: ориентируйтесь на текущий интерфейс.
</Callout>

## Предварительные условия

Перед настройкой убедитесь\:

* WorkBuddy установлен и запущен, доступен пункт настройки пользовательской модели.
* Вы зарегистрированы в SimiRouter и создали ключ в разделе API-ключей консоли.
* Известен полный ID модели, ключу разрешены ее вызовы и доступна квота.

[Открыть управление API-ключами](https\://api.dwchainless.com/keys)

## Настройка

### 1. Настройка пользовательской модели

В окне диалога WorkBuddy нажмите имя модели внизу справа у поля ввода и выберите **«Настроить пользовательскую модель»**.

![Пункт пользовательских моделей в списке моделей](/simidoc/assets/workbuddy/open-custom-model.png)

На странице управления моделями нажмите **«Добавить модель»**. Если окно добавления уже открыто, переходите дальше.

### 2. Провайдер «Пользовательский»

В окне добавления разверните список **«Провайдер»**, прокрутите к категории «Другие» и выберите **«Пользовательский»**.

![Пользовательский провайдер в категории «Другие»](/simidoc/assets/workbuddy/select-custom-provider.png)

Убедитесь, что поле провайдера показывает **«Пользовательский»**.

### 3. Адрес API, ключ и имя модели

Заполните основные поля\:

| Параметр   | Значение                                          |
| ---------- | ------------------------------------------------- |
| Провайдер  | Пользовательский                                  |
| Адрес API  | `https://api.dwchainless.com/v1/chat/completions` |
| API Key    | Ключ API, созданный в SimiRouter                  |
| Имя модели | Полный ID вызываемой модели                       |

**Адрес API\:** скопируйте адрес из таблицы целиком с конечным `/v1/chat/completions`.

\*\*API Key\: \*\* вставьте только ключ без дополнительного `Bearer`, кавычек и пояснений; проверьте отсутствие пробелов по краям.

**Имя модели\:** скопируйте полный ID из актуального списка SimiRouter, а не китайское описание, псевдоним или неполное семейство. Убедитесь, что ключ может вызвать модель.

### 4. Дополнительные настройки

При первой настройке оставьте стандартные параметры ввода и вывода. Другие возможности включайте только при поддержке модели и канала.

| Параметр                           | Рекомендация                                                                                             |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Вызов инструментов                 | Включайте для задач с инструментами, только если их поддерживают модель и канал.                         |
| Изображения на входе               | Включайте при необходимости обработки изображений и поддержке моделью и каналом.                         |
| Режим рассуждений                  | Следуйте инструкции модели; при первой настройке можно оставить выключенным.                             |
| Пользовательский протокол          | Без явных требований оставьте выключенным.                                                               |
| Глубина рассуждений, если доступна | Сначала оставьте значение по умолчанию и меняйте при необходимости.                                      |
| Ввод / вывод                       | Сначала используйте значения провайдера; перед ручной настройкой проверьте лимиты длины модели и канала. |

![Форма модели\: адрес API, ключ, ID и дополнительные параметры](/simidoc/assets/workbuddy/custom-model-form.png)

*Снимок показывает китайские названия полей. Введите собственный ключ и реальный ID модели по инструкции выше.*

### 5. Проверка, сохранение и выбор

После заполнения нажмите **«Проверить подключение»** для проверки, затем **«Сохранить»**. При ошибке используйте таблицу диагностики ниже.

Вернитесь к диалогу и откройте список моделей у поля ввода; **выберите добавленную пользовательскую модель** и отправьте короткое сообщение, например\:

```text
请只回复：连接成功。
```

После ответа найдите запись по времени в консоли SimiRouter и проверьте модель запроса.

После успешного текстового диалога отдельно проверьте необходимые инструменты, изображения и рассуждения.

## Частые вопросы

Сначала прочитайте полную ошибку, затем используйте таблицу.

| Проблема                                           | Диагностика                                                                               |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Нет пункта настройки пользовательской модели       | Проверьте поддержку функции вашей версией и откройте список моделей внизу справа.         |
| Ошибка проверки или отправки сообщения             | По ошибке последовательно проверьте адрес, ключ, ID модели, права и квоту.                |
| После сохранения используется прежняя модель       | Вернитесь к диалогу и выберите сохраненную пользовательскую модель.                       |
| Ошибка после включения изображений или рассуждений | Восстановите последнюю рабочую настройку и проверьте поддержку функции моделью и каналом. |
| Ошибка длинного диалога или вывода                 | Проверьте лимиты модели и канала; сократите вход или выход согласно ошибке.               |

Для диагностики предоставьте **версию WorkBuddy, ID модели, время запроса и полную ошибку**.

<Callout type="warn" title="Безопасность ключа">
  Храните ключ безопасно. Перед отправкой снимков, журналов и ошибок скрывайте весь ключ, не публикуйте его.
</Callout>
