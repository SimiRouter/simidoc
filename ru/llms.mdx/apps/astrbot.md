# Настройка AstrBot

AstrBot — открытый ИИ-помощник для разных мессенджеров. В этом руководстве SimiRouter подключается по OpenAI-совместимому протоколу.

## Добавление провайдера

1. Установите и запустите AstrBot; инструкции см. в [официальной документации AstrBot](https\://docs.astrbot.app/).
2. В разделе SimiRouter [Ключи API](https://api.dwchainless.com/keys) создайте ключ.
3. В панели AstrBot откройте **Providers → Chat Completion**, нажмите **Add** и выберите **OpenAI Compatible**. В старых версиях путь может называться «Провайдеры моделей → Добавить → OpenAI».
4. Заполните следующие поля и сохраните\:

| Поле           | Значение                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------ |
| Имя провайдера | `SimiRouter`                                                                               |
| API Base URL   | `https://api.dwchainless.com/v1`                                                           |
| API Key        | SimiRouter API Key                                                                         |
| Model          | В разделе [Каталог моделей](https://api.dwchainless.com/ru/pricing/) скопируйте полный ID доступной учетной записи модели |

Нажмите **Save and Fetch Models** для загрузки моделей; кнопкой `+` рядом с моделью добавьте и включите ее. Также через **Custom Model** можно вручную указать ID модели.

## Выбор модели чата по умолчанию

Откройте **Config → AI → Model** и установите **Chat Model** в только что добавленную модель, затем сохраните настройки. Используйте **Test Model** либо отправьте короткое тестовое сообщение, затем проверьте вызов в разделе [Журнал использования](https://api.dwchainless.com/usage-logs/common).

Понимание изображений и вызовы инструментов требуют одновременной поддержки AstrBot, выбранной модели и канала. Успешный текстовый диалог не подтверждает доступность всех дополнительных функций.
