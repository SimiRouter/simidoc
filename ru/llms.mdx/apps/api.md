# Справочник API

SimiRouter проверяет ключ API и направляет запросы по модели, группе и каналу. Совместимые и собственные API могут различаться адресом, аутентификацией и структурой параметров\: нельзя смешивать их, заменив только домен.

## Обзор

Интерфейсы организованы в три уровня\: сначала возможность (текст, изображения, видео, аудио, инструменты, обнаружение моделей), затем протокол (совместимый с OpenAI, нативный Gemini, Claude Messages), и наконец параметры на странице интерфейса. Форма вызова определяет, как писать запрос\:

| Форма              | Особенности                                  | Типичные интерфейсы                                        |
| ------------------ | -------------------------------------------- | ---------------------------------------------------------- |
| Синхронная         | Одно соединение возвращает полный результат  | Списки моделей, генерация изображений, транскрибация аудио |
| Потоковая (SSE)    | Одно соединение передаёт события по частям   | Чат, понимание изображений, вызов инструментов             |
| Асинхронная задача | Возвращает ID задачи, затем запрос состояния | Генерация видео, официальное дообучение                    |

Тайм-аут или разрыв соединения на клиенте не обязательно отменяет выполнение на стороне провайдера. Перед повторной отправкой генерации проверьте задачу и историю использования.

## Подготовка подключения

1. По инструкции [Создание ключа SimiRouter](/simidoc/ru/apps/getting-started) создайте ключ.
2. Выберите полный ID модели, доступной вашей учётной записи, в [каталоге моделей](https://api.dwchainless.com/ru/pricing/).
3. На странице интерфейса проверьте адрес, формат и требования модели. Корневой адрес API SimiRouter — `https://api.dwchainless.com`; `/v1` или `/v1beta` определяются путем интерфейса.
4. Храните ключ в окружении или серверном хранилище секретов. Реальные запросы могут тарифицироваться; не раскрывайте ключ во фронтенде и публичном коде.

Раздел [Скрипты API](/simidoc/ru/apps/api-script) содержит полноценные текстовые запросы на Python, Node.js, curl и Go.

## Адреса сервисов

Перед прямым подключением к API провайдера проверьте путь, способ аутентификации, ID модели и поля запроса. Сохраняйте структуру запроса только в том случае, если оба сервиса используют один протокол и документация эндпоинта подтверждает совместимость.

| Сервис                             | Адрес                                        | Аутентификация                            |
| ---------------------------------- | -------------------------------------------- | ----------------------------------------- |
| Шлюз SimiRouter                    | `https://api.dwchainless.com`                | `Authorization: Bearer` и ключ SimiRouter |
| Google Gemini API (ключ AI Studio) | `https://generativelanguage.googleapis.com`  | `x-goog-api-key`                          |
| Google Vertex AI                   | `https://{region}-aiplatform.googleapis.com` | токен доступа OAuth                       |
| OpenAI                             | `https://api.openai.com`                     | `Authorization: Bearer` и ключ OpenAI     |
| Anthropic                          | `https://api.anthropic.com`                  | `x-api-key`                               |
| xAI                                | `https://api.x.ai`                           | `Authorization: Bearer`                   |
| Volcano Ark                        | `https://ark.cn-beijing.volces.com/api/v3`   | `Authorization: Bearer`                   |
| Alibaba Cloud DashScope            | `https://dashscope.aliyuncs.com`             | `Authorization: Bearer` и ключ DashScope  |

Для локальной отладки используйте `http://127.0.0.1:3001` в качестве адреса шлюза. Ключи провайдеров и ключи SimiRouter не взаимозаменяемы; при замене адреса заменяйте и аутентификацию.

## Как читать справочник

На страницах эндпоинтов описаны методы, параметры, поля ответа, примеры кода и ошибки, а также приведены официальные источники. В примерах для шлюза используется ключ SimiRouter, а при прямом подключении используются учётные данные провайдера. Для функций с пометкой «не поддерживается» приведена только документация по прямому подключению.
