# Настройка FluentRead

<Callout type="info" title="">
  🌊 FluentRead — открытое браузерное расширение для перевода, создающее ощущение чтения на родном языке.
</Callout>

* Проект\: [https\://github.com/FluentRead/FluentRead](https\://github.com/FluentRead/FluentRead)

## Основные возможности

### Интеллектуальный перевод

* **Несколько движков**\: выбор различных сервисов перевода
* **Традиционный перевод**\: Microsoft Translator, Google Translate, DeepL и другие.
* **Модели ИИ**\: OpenAI, DeepSeek, Kimi, Ollama и другие.
* **Собственный движок**\: настройка пользовательского сервиса перевода.

### Удобное чтение

* **Два языка**\: оригинал и перевод отображаются рядом.
* **Перевод выделения**\: мгновенный перевод выбранного текста.
* **Копирование одним нажатием**\: быстрое копирование перевода.
* **Перевод всей страницы**\: плавающая кнопка переводит страницу без перезагрузки.

### Конфиденциальность и персонализация

* **Данные и конфиденциальность**\: при онлайн-переводе и использовании облачных моделей текст отправляется настроенному сервису. Изучите его правила обработки данных и не отправляйте конфиденциальную информацию ненадёжному поставщику.
* **Гибкая настройка**\: параметры для разных сценариев.
* **Полностью бесплатно**\: открытый некоммерческий проект.

## Настройка

### Ручное заполнение в FluentRead

В разделе [Ключи API](https://api.dwchainless.com/keys) скопируйте ключ, откройте настройки FluentRead и заполните\:

| Параметр        | Значение                                        |
| --------------- | ----------------------------------------------- |
| Сервис перевода | New API                                         |
| Токен доступа   | Скопированный ключ API SimiRouter               |
| API NewAPI      | `https://api.dwchainless.com` (без `/v1`)       |
| Модель          | Выберите или введите полный ID доступной модели |

После сохранения переведите короткий неконфиденциальный текст и проверьте вызов в журнале SimiRouter. Онлайн-перевод отправляет исходный текст настроенному сервису.
