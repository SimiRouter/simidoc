# Настройка CC Switch

## Скачать CC Switch

1. Откройте [страницу загрузки CC Switch](https\://github.com/farion1231/cc-switch/releases/latest), выберите в GitHub Releases установщик для своей ОС и установите приложение.

## Импорт из интерфейса платформы

### Быстрый импорт `Codex`

![Пункт импорта CC Switch в меню ключа SimiRouter](/simidoc/assets/cc_switch/cc1.png)

Выберите ключ группы моделей Codex, нажмите стрелку рядом с импортом и выберите CC Switch

Укажите имя провайдера и модель Codex
![Ввод имени провайдера и модели в CC Switch](/simidoc/assets/cc_switch/cc2.png)

В открывшемся окне `此站点正在尝试打开 CC Switch。` выберите открытие приложения
![Подтверждение открытия CC Switch в браузере](/simidoc/assets/cc_switch/cc3.png)

Проверьте настройки импортируемого провайдера
![Предварительный просмотр конфигурации импорта CC Switch](/simidoc/assets/cc_switch/cc4.png)

Если все верно, подтвердите импорт
![Подтверждение импорта провайдера в CC Switch](/simidoc/assets/cc_switch/cc5.png)

После импорта отправьте короткое тестовое сообщение. Для подключения IDE см. описание полей в руководстве [Настройка стороннего расширения (VS Code Roo)](/simidoc/ru/apps/roo-code) и используйте модель, доступную вашей учетной записи; названия полей у расширений различаются.
![Настройки провайдера после импорта в CC Switch](/simidoc/assets/cc_switch/cc6.png)

В CC Switch можно проверить баланс учетной записи и при необходимости пополнить его, чтобы нехватка средств не прервала работу.
![Просмотр баланса в CC Switch](/simidoc/assets/cc_switch/cc7.png)
