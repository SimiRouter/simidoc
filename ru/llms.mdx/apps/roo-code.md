# Настройка стороннего расширения (VS Code Roo)

Roo Code поддерживает пользовательские OpenAI-совместимые провайдеры. Для SimiRouter задайте адрес, ключ API и ID модели; локально разворачивать модель не требуется.

## Настройка Roo Code

1. Установите Roo Code и откройте настройки расширения.
2. В поле **API Provider** выберите **OpenAI Compatible**.
3. Укажите\:

| Поле     | Значение                                                                            |
| -------- | ----------------------------------------------------------------------------------- |
| Base URL | `https://api.dwchainless.com/v1`                                                    |
| API Key  | Ключ, созданный в разделе SimiRouter [Ключи API](https://api.dwchainless.com/keys)                             |
| Model ID | В разделе [Каталог моделей](https://api.dwchainless.com/ru/pricing/) скопируйте полный ID модели с учетом регистра |

4. Задайте окно контекста, лимит вывода и поддержку изображений по реальным возможностям модели. Не копируйте фиксированные лимиты других моделей. Roo Code всегда использует нативный вызов инструментов, отдельного переключателя нет.
5. После сохранения отправьте короткое сообщение и проверьте вызов в разделе SimiRouter [Журнал использования](https://api.dwchainless.com/usage-logs/common).

## Проверка API

Полные тестовые примеры Python, Node.js, curl и Go без клиента см. в разделе [Скрипты API](/simidoc/ru/apps/api-script). Тест и расширение должны использовать один ID модели и одинаковые права ключа. Успех одного текстового запроса не подтверждает работу инструментов и изображений.

## Частые ошибки

* **401**\: проверьте полноту и действительность ключа, удалите лишние пробелы.
* **404**\: проверьте отсутствие повторного `/v1` и точность ID модели.
* **Модель недоступна**\: проверьте модель, группу и права ключа по телу ошибки.
* **Неподдерживаемые параметры**\: отключите неподходящие модели параметры, особенно сэмплирование, глубину рассуждений и длину вывода.

Сохраните стандартное подтверждение инструментов. Не разрешайте автоматическое выполнение в недоверенных проектах и не публикуйте настройки с ключом.
