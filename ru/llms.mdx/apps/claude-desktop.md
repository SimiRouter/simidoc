# Настройка Claude Desktop

Функция **сопоставления моделей** в CC Switch позволяет выбрать название в меню Claude Desktop, а CC Switch направит запрос к соответствующей реальной модели SimiRouter. Далее показан интерфейс macOS; названия в других ОС и версиях могут отличаться.

## Подготовка

1. Установите и откройте актуальную версию Claude Desktop.
2. Установите [CC Switch](https\://github.com/farion1231/cc-switch/releases/latest) с поддержкой **Claude Desktop** и откройте приложение.
3. Войдите в SimiRouter; на странице [Ключи API](https://api.dwchainless.com/keys) создайте или скопируйте рабочий ключ API. Убедитесь, что ему разрешена нужная модель.

<Callout type="info" title="">
  Ключ API является учетными данными для вызовов\: храните его безопасно, не публикуйте снимки и не передавайте другим. Доступные модели и разрешения указаны в консоли SimiRouter.
</Callout>

## Сопоставление моделей через CC Switch

### 1. Пользовательский провайдер Claude Desktop

Слева в CC Switch выберите **Claude Desktop**, нажмите **Добавление поставщика**, затем **Пользовательская конфигурация**. Выбирайте именно Claude Desktop, а не Claude Code.

![Добавление пользовательского провайдера Claude Desktop в CC Switch](/simidoc/assets/claude-desktop/cc-switch-add-provider.png)

### 2. Подключение и сопоставление моделей

В форме пользовательского провайдера заполните\:

| Поле                      | Значение                                                  |
| ------------------------- | --------------------------------------------------------- |
| Имя                       | `SimiRouter` или другое удобное имя                       |
| API Key                   | Скопированный ключ API SimiRouter                         |
| Адрес запроса             | `https://api.dwchainless.com` без конечного `/` или `/v1` |
| Способ подключения        | Выберите **сопоставление моделей**                        |
| Протокол вышестоящего API | Выберите **Anthropic Messages (собственный формат)**      |

В разделе **сопоставления моделей** задайте для нужных ролей «Название в меню» и «Реальную модель запроса». Например\:

| Роль модели | Название в меню     | Реальная модель запроса |
| ----------- | ------------------- | ----------------------- |
| Sonnet      | `claude-sonnet-5-5` | `gpt-6-astra`           |
| Opus        | `claude-opus-5-5`   | `gpt-6-astra`           |
| Haiku       | `claude-haiku-5-5`  | `gpt-6.1-sol`           |

**Название в меню — лишь подпись Claude Desktop; реально вызывается модель из правого столбца.** Например, при выборе `claude-sonnet-5-5` в этом примере запрашивается `gpt-6-astra`, а не Claude Sonnet. Замените модель точным ID, доступным вашей учетной записи SimiRouter; подпись меню можно сделать более понятной. Список ролей зависит от версии приложения.

На снимке параметр `1M` лишь сообщает клиенту о поддерживаемом контексте; **не копируйте отмеченный флажок автоматически**. Включайте его, только если модель и API действительно поддерживают такую возможность. Закончив, нажмите **Добавить**.

![Два столбца сопоставления\: название в меню и реальная модель](/simidoc/assets/claude-desktop/cc-switch-model-mapping.png)

Ключ API на снимке скрыт; при настройке укажите собственный ключ.

### 3. Проверка и включение маршрута

1. Вернитесь к списку провайдеров и в карточке SimiRouter нажмите **… → Проверка подключения** и проверьте результат.
2. Если проверка прошла, нажмите кнопку включения (▶) справа в карточке и следуйте подсказкам. Статус **Маршрутизация** означает, что провайдер выбран.
3. Оставьте CC Switch и локальный маршрутизатор запущенными. После смены маршрута или сопоставления полностью закройте и снова откройте Claude Desktop для загрузки настроек.

![Проверка подключения в меню провайдера](/simidoc/assets/claude-desktop/cc-switch-test-connection.png)

![Карточка SimiRouter со включенной маршрутизацией](/simidoc/assets/claude-desktop/cc-switch-routing.png)

### 4. Режим разработчика Claude Desktop

Откройте **настольный Claude Desktop**; в верхнем меню выберите **Help → Troubleshooting → Enable Developer Mode**. Если режим уже включен, пропустите шаг.

![Включение режима разработчика через меню Help Claude Desktop](/simidoc/assets/claude-desktop/claude-enable-developer-mode.png)

### 5. Конфигурация вывода CC Switch

1. В левом нижнем углу Claude Desktop откройте меню учетной записи, выберите **Inference configuration** и откройте **Configure third-party inference**.
2. В списке конфигураций справа вверху убедитесь, что выбран **CC Switch**. Если конфигураций несколько, выберите CC Switch. Статус **applied** означает, что настройки применены; при несохраненных изменениях нажмите **Apply Changes**.
3. В разделе **Connection** нажмите **Test Connection**. При зеленом сообщении об успехе закройте настройки.

![Открытие Inference configuration через меню учетной записи](/simidoc/assets/claude-desktop/claude-inference-menu.png)

![Выбрана и применена конфигурация CC Switch](/simidoc/assets/claude-desktop/claude-cc-switch-profile.png)

Ключ шлюза на снимке скрыт. Сохраните значение, автоматически установленное CC Switch, не очищайте поле.

<Callout type="info" title="">
  Адрес шлюза в конфигурации CC Switch указывает на локальный маршрутизатор, а не на адрес SimiRouter из шага 2. Обычно адрес и ключ локального шлюза менять не нужно. Успешная проверка подключения не заменяет реальный вызов модели.
</Callout>

### 6. Выбор модели и проверка

1. Создайте диалог и в меню у поля ввода выберите настроенное **Название в меню**, затем отправьте короткое сообщение. Реальный вызов может тарифицироваться.
2. После ответа в журнале консоли SimiRouter проверьте время запроса, **реальную модель** и расход. Самоописание модели и подпись Claude Desktop не доказывают, какая модель была вызвана.

## Частые вопросы

### Нет Claude Desktop или режима разработчика

* Используйте актуальный CC Switch с поддержкой Claude Desktop и выберите слева **Claude Desktop**.
* В Claude Desktop откройте **Help → Troubleshooting → Enable Developer Mode**. Если пункта нет, обновите клиент.

### Нет конфигурации CC Switch или список моделей не обновился

* Убедитесь, что карточка SimiRouter имеет статус **Маршрутизация** и CC Switch с локальным маршрутизатором запущены.
* Полностью перезапустите Claude Desktop и проверьте конфигурацию в нижнем левом меню **Inference configuration**. В некоторых версиях страница доступна через **Developer → Configure third-party inference**.
* Заполните «Название в меню» и выберите конфигурацию **CC Switch**. После смены сопоставления или провайдера перезапустите Claude Desktop.

### Проверка или диалог завершились ошибкой

* Проверьте полноту и действительность ключа в CC Switch и адрес запроса `https://api.dwchainless.com`.
* Убедитесь, что выбран **Anthropic Messages (собственный формат)**; проверьте сеть и локальный маршрутизатор.
* Проверьте ID реальной модели, группу ключа и разрешения, а не только подпись меню.
* По ошибке проверьте квоту и совместимость модели. Успешная проверка подключения не гарантирует доступность всех моделей и функций.

## Другие способы настройки

### Дополнительно\: прежнее прямое подключение

Ниже сохранены прежние шаги прямого подключения, не перепроверенные в текущей версии клиента. Поля и интерфейс могли измениться. После настройки CC Switch повторять их не нужно; доступность моделей при прямом подключении зависит от клиента.

Сначала в **Help → Troubleshooting** включите режим разработчика, затем\:

1. Выберите **Developer → Configure third-party inference**.
2. Заполните поля\:

| Поле                  | Значение                                                                                          |
| --------------------- | ------------------------------------------------------------------------------------------------- |
| Base URL              | `https://api.dwchainless.com`                                                                     |
| API Key               | Ваш API-ключ SimiRouter, например `sk-...`                                                        |
| Authentication method | Выберите `x-api-key`                                                                              |
| Provider / API format | Если поле присутствует, выберите `Anthropic-compatible`, `custom gateway` или аналогичный вариант |

<Callout type="warn" title="">
  В Base URL Claude Desktop укажите `https://api.dwchainless.com`. Это адрес для настройки стороннего инференса в настольном приложении. Не копируйте сюда запись переменной `ANTHROPIC_BASE_URL` из инструкции Claude CLI.
</Callout>

3. Нажмите **Apply locally**, чтобы сохранить настройки на текущем компьютере.
4. Продолжите вход или запуск Claude Desktop согласно подсказкам приложения.
