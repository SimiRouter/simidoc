DeepChat — открытый клиент для облачных и локальных моделей. Расширения, включая инструменты, требуют поддержки модели и провайдера.

## Ручное подключение SimiRouter

1. В разделе SimiRouter [Ключи API](https://api.dwchainless.com/keys) скопируйте нужный ключ API.

2. Откройте в DeepChat **Настройки → Провайдеры**; выберите New API или добавьте совместимого провайдера. **В поле API URL укажите `https://api.dwchainless.com`**, а в API Key вставьте скопированный ключ.

   ![Ввод адреса SimiRouter и ключа API в DeepChat](/simidoc/assets/deepchat/simirouter-manual.png)

3. Проверьте ключ, обновите или добавьте модели, включите провайдера и выберите доступную модель. Отправьте короткое сообщение и проверьте соответствующий вызов в журнале SimiRouter.

<Callout type="warn" title="Защита ключа">
  Не показывайте ключ на публичных снимках и не передавайте ненадежным приложениям. Интерфейс меняется с версиями\: ориентируйтесь на реальные поля.
</Callout>
