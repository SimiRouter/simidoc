# Настройка LangBot

LangBot хранит соединение в провайдере, на который ссылаются модели. OpenAI-совместимый провайдер позволяет подключить модели чата SimiRouter.

## Создание провайдера и модели

1. По [официальной документации LangBot](https\://docs.langbot.app/) установите и запустите приложение.
2. В разделе SimiRouter [Ключи API](https://api.dwchainless.com/keys) скопируйте ключ.
3. На странице моделей LangBot добавьте модель диалога, выберите или создайте OpenAI-совместимого провайдера.
4. Настройте подключение\:

| Поле                   | Значение                         |
| ---------------------- | -------------------------------- |
| Base URL / URL запроса | `https://api.dwchainless.com/v1` |
| API Key                | SimiRouter API Key               |
| Имя модели             | Полный ID доступной модели       |

Модель наследует адрес и ключ провайдера. Включайте зрение и инструменты по реальным возможностям модели\: флажки не добавляют отсутствующие способности.

## Привязка конвейера

В конвейере выберите новую модель, сохраните и отправьте сообщение через отладку или подключенного бота. В SimiRouter [Журнал использования](https://api.dwchainless.com/usage-logs/common) проверьте время, модель и расход запроса.

## База знаний и эмбеддинги (не поддерживаются)

Базе знаний LangBot нужна модель эмбеддингов. SimiRouter пока не поддерживает эту интеграцию; конфигурация модели чата не является векторным сервисом. Для базы знаний настройте отдельного поддерживаемого провайдера эмбеддингов либо встроенное решение по документации LangBot.
