# Настройка Memoh

Memoh — открытая мультиагентная платформа с отдельными рабочими средами и долговременной памятью. Чат, синтез и транскрипция используют разные типы клиентов, а не единый протокол настройки.

## Установка Memoh

По [официальной инструкции установки Memoh](https\://docs.memoh.ai/self-hosted/docker) установите текущую версию. После первого входа настройте безопасность учетной записи; не используйте пароли по умолчанию из старых руководств.

## Добавление провайдера

1. В разделе SimiRouter [Ключи API](https://api.dwchainless.com/keys) создайте ключ.
2. В боковой панели настроек Memoh откройте **Models** и выберите **Add Provider**.
3. Используйте шаблон OpenAI Chat Completions либо пользовательского провайдера\:

| Поле        | Значение                         |
| ----------- | -------------------------------- |
| Name        | `SimiRouter`                     |
| Client Type | `openai-completions`             |
| Base URL    | `https://api.dwchainless.com/v1` |
| API Key     | SimiRouter API Key               |

`openai-responses` соответствует протоколу Responses, а `openai-completions` — Chat Completions, а не устаревшему текстовому дополнению. Типы с OAuth не заменяют провайдера с ключом API SimiRouter.

## Добавление и включение модели

В карточке провайдера нажмите **Import Models** для импорта либо введите доступный ID вручную. Модели после массового импорта могут быть выключены\: включите их и выберите модель чата в настройках бота.

Отправьте короткое сообщение, затем в разделе SimiRouter [Журнал использования](https://api.dwchainless.com/usage-logs/common) проверьте запрос. Для памяти и поиска Memoh могут требоваться отдельные провайдеры. SimiRouter пока не предоставляет эмбеддинги; модель чата не заменяет векторную модель.
