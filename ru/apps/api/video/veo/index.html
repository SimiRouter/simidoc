Veo видео (предпросмотр-модели Gemini API отключены)

Генерация видео Veo 3.1: асинхронная операция predictLongRunning, опрос и пояснение об отключении 2026-10-22.

Обзор

Veo генерирует видео через long-running operation Gemini API: сначала вызывается predictLongRunning для запуска задачи, затем получается имя operation, после чего operation опрашивается, а по завершении MP4 скачивается по URI файла из ответа.

Предпросмотр-модели Gemini API veo-3.1-generate-preview, veo-3.1-fast-generate-preview и другие были отключены 2026-10-22. Эта страница сохраняет структуру протокола, чтобы можно было понять существующие вызовы и выполнить миграцию; сейчас этот эндпоинт нельзя считать доступным production-интерфейсом. Можно перейти на gemini-omni-1.2-flash или использовать GA-модели в Gemini Enterprise Agent Platform.

Ключевые понятия

  • Операция (operation) — не ID задачи: ответ создания возвращает name, например models/veo-3.1-generate-preview/operations/.... Для опроса, чтения результата и диагностики используется это полное имя.
  • Условие завершения — done: true: done: false означает только то, что обработка продолжается. При done: true нужно также проверить наличие error и пустоту response.generateVideoResponse.generatedSamples[0].video.uri.
  • Диапазон длительности: официально генерация занимает минимум 11 секунд, в пике — до 6 минут. Для опроса можно использовать интервал 10–15 секунд и задать общий предел ожидания на клиенте.
  • Длительность и разрешение связаны: длительность имеет только три значения — 4, 6 и 8 секунд. При использовании 1080p, 4k, референсного изображения или продления видео длительность должна быть 8 секунд; нельзя просто изменить запрос с 4 секунд на 1080p.
  • Аудио генерируется вместе с моделью: документация Gemini API описывает звук как всегда включённый, отдельного переключателя generateAudio нет. В промпте можно описать диалоги, звуковые эффекты и окружающий звук.
  • Тарификация различается по платформам: Gemini API и Agent Platform — две разные системы тарификации и квот; цена за единицу определяется страницей цен провайдера. После отключения предпросмотр-моделей новые вызовы не должны создавать расходы.

Разрешение и длительность — не независимые опции: 1080p, 4k, референсные изображения и продление требуют 8 секунд; 4 или 6 секунд можно сочетать только с 720p. Референсных изображений не больше 3; первый и последний кадры задают ограничения изображения, а не стилевой референс. Аудио генерируется всегда и не отключается параметром. После перехода на Agent Platform меняются ID моделей, аутентификация и квоты; нельзя просто заменить эндпоинт из этой статьи на имя GA-модели и продолжать использовать.

Процесс вызова

  1. Определите платформу и учётные данные. Gemini API использует x-goog-api-key; Agent Platform использует собственную аутентификацию платформы, и они не взаимозаменяемы.
  2. Отправьте на POST /v1beta/models/{MODEL_ID}:predictLongRunning instances и parameters. Промпт помещается в instances[0].prompt, первый кадр — в instances[0].image.
  3. Сохраните name из ответа. Успешное создание означает только то, что операция создана, а не то, что видео можно скачать.
  4. Опрашивайте GET /v1beta/{operation_name}, пока не будет done: true. Если присутствует error, завершите по содержимому ошибки и не продолжайте ожидание.
  5. Прочитайте адрес скачивания из response.generateVideoResponse.generatedSamples[0].video.uri, запросите этот URI с ключом API и разрешите HTTP-редиректы.
  6. Сохраните файл в собственное хранилище. Официальная документация указывает, что сгенерированное видео хранится 2 дня, а продление сбрасывает отсчёт; не полагайтесь на долговременный URL провайдера.

Подключение и сеансы

  • Базовый адрес: https://generativelanguage.googleapis.com/v1beta.
  • Заголовок аутентификации: x-goog-api-key: PASTE_API_KEY_HERE, одновременно отправляйте Content-Type: application/json.
  • Два набора адресов: для прямого подключения к Gemini API используйте https://generativelanguage.googleapis.com/v1beta с заголовком x-goog-api-key; используйте https://api.dwchainless.com и Authorization: Bearer с ключом сайта только при явном подтверждении сопоставления с этим шлюзом; одной замены адреса и аутентификации недостаточно. Если SimiRouter предоставляет модель с тем же именем, путь, поля и способ опроса определяются сопоставлением канала. GA-модели Agent Platform используют региональные адреса вроде https://{region}-aiplatform.googleapis.com и аутентификацию проекта; это не адрес generativelanguage и не замена строки модели.
  • Таймаут и идемпотентность: после таймаута запроса запуска сначала проверьте, не создана ли уже операция; сохранить name важнее, чем сохранить HTTP-статус. Не запускайте одну и ту же задачу повторно только из-за долгого ожидания.
  • Подсказка по миграции: интерфейс gemini-omni-1.2-flash отличается от predictLongRunning, и существующий код опроса, возможно, придётся переписать. Перед миграцией ориентируйтесь на официальную документацию по миграции и список моделей, доступных аккаунту.
