Текст в видео Kling

Kling видео из текста: асинхронная задача на основе текстового запроса.

Описание интерфейса

POST https://api-singapore.klingai.com/text-to-video/kling-3.0, авторизация Authorization: Bearer $KLING_API_KEY, тело JSON. Используется новый официальный Kling, не старое соответствие SimiRouter /kling/v1/videos/....

Параметры запроса

ПолеТипОбязателенОписание
promptstringДаДо 3072 символов, желательно до 2500; допустимы положительные и отрицательные описания.
settings.resolutionstringНет720p (по умолчанию), 1080p, 4k — по правам модели.
settings.durationintegerНетПо умолчанию 5 секунд; текущая справка 3.0 разрешает 3–15 секунд.
settings.audiostringНетoff (по умолчанию) или native для собственной звуковой дорожки.
settings.multi_shotbooleanНетПо умолчанию true; в примере false для одного плана.
settings.aspect_ratiostringНет16:9 (по умолчанию), 9:16, 1:1.
options.callback_urlstringНетCallback состояния; безопасный приём и идемпотентность реализует приложение.
options.external_task_idstringНетУникальный в аккаунте пользовательский ID для опроса, не заменяет системный.
options.watermark_info.enabledbooleanНетПредоставлять ли версию с водяным знаком; собственный знак не поддерживается.

Нельзя выводить ограничения моделей только из наличия поля. Многоплановые инструкции следуют официальному синтаксису shot; сумма длительностей должна равняться общей. Первый/последний кадр, число элементов и форматы зависят от текущей модели.

Ответ

data.id — системный ID для опроса, data.status принимает submitted, processing, succeeded, failed; время в миллисекундах. Создание не возвращает готовое видео. Не читайте старый data.task_id или task_status.

Примеры вызова

Для Python установите python3 -m pip install requests; Node.js 18+ использует fetch, Go — стандартную библиотеку.

Задайте официальный ключ Kling KLING_API_KEY. Вызов создаёт оплачиваемую задачу. Затем см. Опрос задачи.

Коды ошибок

HTTP / бизнес-кодОписание
200 / 0Запрос успешен; завершение генерации определяется status задачи.
400 / 1201Некорректные параметры, читайте message.
404 / 1202, 1203Неверный метод или нет модели/ресурса.
401Недействителен API Key или старый JWT.
400 / 1300, 1301Ограничение политики или безопасности: исправьте контент, не повторяйте вслепую.
429 / 1302, 1303, 1304Ограничение частоты, конкуренции или IP-политики.
500 / 5000; 503 / 5001; 504 / 5002Ошибка сервиса или тайм-аут; сохраните request_id.

HTTP 200 не означает бизнес-успех; сначала code=0, затем data.
