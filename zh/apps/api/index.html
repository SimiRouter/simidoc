API 参考

按功能和协议查阅 SimiRouter 接口及厂商官方 API 参考。

SimiRouter 使用 API Key 验证请求，并根据模型、分组和渠道转发模型调用。兼容接口与厂商原生接口可能采用不同的地址、鉴权方式和参数结构，不能只替换域名后混用。

概览

接口按三层组织：先选能力（文本、图片、视频、音频、工具、模型发现），再选协议（OpenAI 兼容、Gemini 原生、Claude Messages），最后在接口页核对参数。三种调用形态决定请求怎么写：

形态特征典型接口
同步同一连接返回完整结果模型列表、图片生成、音频转录
流式（SSE）同一连接分批返回事件聊天、图片理解、工具调用
异步任务先返回任务 ID，再查询任务状态视频生成、官方微调

客户端超时或断开连接不一定意味着上游任务已取消，生成类请求应先核对任务和使用记录，避免重复提交。

接入准备

  1. 按注册 SimiRouter Key创建密钥。
  2. 从模型广场选择账户可用的完整模型 ID。
  3. 在具体接口页确认服务地址、请求格式和模型要求。SimiRouter 的 API 根地址为 https://api.dwchainless.com；/v1 或 /v1beta 由接口路径决定。
  4. 将密钥保存在环境变量或服务端密钥存储中。真实请求可能产生费用，不要在浏览器前端或公开代码中暴露密钥。

API 脚本接入提供一次完整文本请求的 Python、Node.js、curl 和 Go 示例。

服务地址

切换到厂商直连前，请核对接口路径、鉴权、模型 ID 和请求字段。只有两端使用同一协议且接口页明确说明兼容时，才可以沿用请求结构。

功能目录

功能内容调用方式
聊天Chat Completions、Responses、Claude Messages、Gemini 内容生成非流式请求等待完整响应；流式请求逐步接收 SSE 事件
画图图片生成、编辑、参考图生成和图片识别，覆盖 OpenAI、Gemini、Qwen、即梦、Grok、FLUX 协议按协议返回图片数据、地址或文本；支持流式与否见具体接口
视频Seedance、Kling、Veo、PixVerse、Wan、Happy Horse、Grok Imagine 生成协议与视频理解；即梦待接入视频生成通常先提交任务，再查询结果；视频理解使用多模态内容接口
音频OpenAI、Gemini 和 MiMo 的音频输入输出文件请求、二进制音频或流式事件，不能混用响应解析器
语音合成文字转语音返回音频文件或模型支持的流式事件
语音转录音频转原语言文字上传音频后返回转录结果
音频翻译音频转英文文字上传音频后返回英文文本，不是语音翻译输出
音乐（不支持）Google Lyria 官方调用参考仅提供 Google 官方直连参考
嵌入（不支持）OpenAI、Gemini 官方向量接口参考仅提供厂商官方直连参考
重排序文档相关性排序按页面列出的厂商协议调用
实时语音OpenAI Realtime 协议双向实时连接，不是普通 HTTP 音频文件请求
工具Function Calling、网络搜索模型提出工具调用后，按工具类型执行并回传结果
内容审核文本与图片安全分类返回类别判定和评分
获取模型OpenAI 和 Gemini 格式模型列表返回模型标识；列表不等于每项能力均已开放
文件识别将文件内容传入支持的多模态模型与独立的 Files API 不同
微调（不支持）官方微调协议参考仅提供 OpenAI 官方直连参考
Files API（不支持）官方文件管理协议参考仅提供 OpenAI 官方直连参考
