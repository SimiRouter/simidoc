# 推广返利说明

## 返利规则说明

### 推广关系确认

* 被推广人必须在注册时使用推广人提供的推广链接，否则推广关系无法确认。
* 推广人可在控制台的[推广信息](https://api.dwchainless.com/promotion)中查看通过专属链接注册的用户、绑定关系及返利记录。

### 返利规则

* 返利规则：被推广人在充值成功后，推广人可以获得被推广人充值金额的10%作为返利。

### 提现规则

* 提现规则：推广人可以在推广详情中查看自己的返利金额，并申请提现。
  * 提现金额必须大于等于1000元。
* 提现审核：提现申请提交后，需要经过平台审核，审核通过后才会进行提现。
  * 首次申请的用户需要提供收款信息（支付宝、微信、银行卡等）。
* 关于新推广用户返利的问题：
  * 为避免恶意作弊等行为，推广后首次充值的新用户的返利需要经过审查。在审查充值用户行为正常后，推广人才能获得返利。详情见风控和处罚说明。

### 返现比例

* 一般推广人可以获得被推广人充值金额的10%作为返利。
* 用户可以申请成为"平台合伙人"获取更高的返现比例，具体比例根据用户等级和推广人数而定。有意愿成为平台合伙人的用户，可以通过客服等渠道向平台申请。

## 风控规则和处罚说明

### 风控审查目的

保护用户权益：防止恶意攻击、保障用户在平台的正常使用和其他合法权益。

维护平台公平，给平台用户创造良好的使用环境。

避免平台遭受损失，保障平台的经济利益。

遵守法律法规，确保平台合规经营。

### 风控审查范围

恶意攻击：通过技术手段或恶意行为，对平台造成损害。

套利作弊：利用平台技术或规则漏洞，套取平台奖励等。

违规宣传：在未经授权的情况下，冒用平台名义进行虚假宣传、承诺额外返利、或诱导他人注册。

扰乱市场秩序：违反平台规定出售、交易平台奖励等行为。

利用平台产品从事违法活动。

### 审查与处理流程

新用户首次充值返利冻结：被推广人首次充值成功后，该笔返利将被标记为“待审查”状态，冻结期为7个自然日。期间平台将通过数据分析与人工复核判断是否存在上述异常行为。

审查结果通知：审查完成后，推广人可在推广详情页查看结果。若判定正常，返利自动解冻进入可提现余额；若判定异常，返利将被取消，并可能触发进一步处罚。

复查机制：推广人对审查结果有异议的，可在收到通知后7个工作日内联系客服提交证明材料（如聊天记录、真实关系证明等），平台将在5个工作日内复核并反馈最终结论。

### 处罚措施

|    用户风险行为    | 风险等级 |        处罚措施       |
| :----------: | :--: | :---------------: |
|     恶意攻击     |   高  | 立即封禁账号，永久禁止使用平台服务 |
|     套利作弊     |   中  |   扣除套利所得，严重的封禁账号  |
|     违规宣传     |   中  |     情节严重的封禁账号     |
|    扰乱市场秩序    |   中  |    惩罚金额，严重的封禁账号   |
| 利用平台产品从事违法活动 |   高  | 立即封禁账号，永久禁止使用平台服务 |

### 违规行为

* 同一主体批量注册多个账号；
* 自行邀请自己、自充自返；
* 使用虚假身份或虚假支付信息；
* 伪造交易、虚假充值或恶意退款；
* 使用脚本、自动化工具批量刷取奖励；
* 利用系统漏洞、活动配置错误或接口异常套取奖励；
* 操纵、买卖或恶意转移推广关系；
* 借助代充、洗钱、盗刷或其他违法违规方式参与活动；
* 组织或协助他人实施恶意套利；
* 其他违反公平诚信原则、用户协议或法律法规的行为。
