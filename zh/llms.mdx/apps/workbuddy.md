# WorkBuddy 教程

<Callout type="info" title="适用范围">
  本教程适用于支持“配置自定义模型”功能的 WorkBuddy
  桌面客户端。不同版本的入口和设置项可能略有差异，请以实际界面为准。
</Callout>

## 前置条件

开始配置前，请确认已完成以下准备：

* 已安装并启动 WorkBuddy，且客户端中可以找到“配置自定义模型”入口。
* 已注册 SimiRouter，并在控制台的“API 密钥”页面创建 API Key。
* 已确认准备使用的完整模型 ID，且该 API Key 具有对应模型的调用权限和可用额度。

[打开 API 密钥管理](https\://api.dwchainless.com/keys)

## 配置步骤

### 1. 打开“配置自定义模型”

在 WorkBuddy 对话界面，点击输入框右下角的模型名称，在展开的列表中选择 **“配置自定义模型”**。

![在模型列表中打开“配置自定义模型”](/simidoc/assets/workbuddy/open-custom-model.png)

进入模型管理页面后，点击 **“添加模型”**。如果已直接打开“添加模型”窗口，可继续下一步。

### 2. 将供应商设置为“自定义”

在“添加模型”窗口中，展开 **“供应商”** 下拉列表，向下滚动，在“其他”分类中选择 **“自定义”**。

![在供应商列表的“其他”分类中选择“自定义”](/simidoc/assets/workbuddy/select-custom-provider.png)

选择完成后，确认“供应商”字段显示为 **“自定义”**。

### 3. 填写接口地址、API Key 和模型名称

按下表填写基础信息：

| 配置项     | 填写内容                                              |
| ------- | ------------------------------------------------- |
| 供应商     | 自定义                                               |
| 接口地址    | `https://api.dwchainless.com/v1/chat/completions` |
| API Key | 在 SimiRouter 创建的 API 密钥                           |
| 模型名称    | 准备调用的完整模型 ID                                      |

**接口地址：** 请完整复制上表中的地址，保留末尾的 `/v1/chat/completions`。

**API Key：** 仅粘贴密钥本身，不额外添加 `Bearer`、引号或说明文字，并检查前后是否有多余空格。

**模型名称：** 请从 SimiRouter 当前可用的模型信息中复制完整模型 ID，不要填写中文介绍、自定义昵称或不完整的系列名称。请确认所用 API Key 可以调用该模型。

### 4. 设置高级选项

首次配置时，建议保留输入、输出的默认设置，其他选项按所选模型及当前通道支持的能力配置。

| 配置项      | 设置建议                                       |
| -------- | ------------------------------------------ |
| 工具调用     | 需要使用工具任务时勾选，并确认所选模型及当前通道支持工具调用。            |
| 图片输入     | 需要处理图片，且所选模型及当前通道支持时勾选。                    |
| 思考模式     | 按所选模型的适配说明设置；首次配置可保持未勾选。                   |
| 自定义协议    | 没有明确配置要求时，保持未勾选。                           |
| 思考强度（如有） | 建议先保持默认，有明确需求时再调整。                         |
| 输入 / 输出  | 建议先保留“使用提供商默认值”；需要手动设置时，先核对具体模型及当前通道的长度限制。 |

![自定义模型配置表单：接口地址、API Key、模型名称及高级选项](/simidoc/assets/workbuddy/custom-model-form.png)

*截图为中文界面的配置字段示意，请按前述说明填写自己的 API Key 和实际模型 ID。*

### 5. 测试连接、保存并选中模型

填写完成后，点击 **“测试连接”** 检查连接情况，再点击 **“保存”**。如果连接测试失败，请参考下方“常见问题”排查。

返回 WorkBuddy 对话界面，打开输入框右下角的模型列表，**选中刚刚添加的自定义模型**，然后发送一条简短消息，例如：

```text
请只回复：连接成功。
```

收到正常回复后，可在 SimiRouter 控制台查看对应时间的调用记录，核对请求使用的模型。

基础对话正常后，再分别测试需要使用的工具调用、图片输入或思考模式。

## 常见问题

出现问题时，请先查看完整错误提示，再按下表排查。

| 遇到的问题             | 排查方法                                     |
| ----------------- | ---------------------------------------- |
| 找不到“配置自定义模型”      | 检查客户端版本是否支持该功能，并确认已打开对话界面右下角的模型列表。       |
| 测试连接或发送消息失败       | 根据错误提示，逐项核对接口地址、API Key、模型 ID、调用权限和可用额度。 |
| 已保存，但对话仍使用原来的模型   | 返回对话界面，在模型列表中选中刚保存的自定义模型。                |
| 开启图片输入、思考模式等选项后失败 | 恢复最近一次可以正常使用的设置，再核对所选模型及当前通道是否支持该功能。     |
| 长对话或较长输出报错        | 核对具体模型及当前通道的长度限制；根据错误提示缩短输入内容或调低输出上限。    |

如需协助排查，请提供 **WorkBuddy 版本、模型 ID、请求时间和完整错误提示**。

<Callout type="warn" title="密钥安全提示">

</Callout>
