# 图片调用示例已按协议整理

图片调用不再使用一份仅适用于 OpenAI Images 的通用脚本教程。请先选择实际使用的协议，每个协议页均按“请求格式与参数 → 返回参数 → 调用示例”整理，包含图片规格、四语言代码入口、智能体任务与安全保存流程：

* [OpenAI 格式](/simidoc/zh/apps/api/images/openai)：Images 生成与编辑、Responses 对话式生图及图片理解。
* [Gemini 原生格式](/simidoc/zh/apps/api/images/gemini)：GenerateContent 的文字与图片 Part、Base64 图片保存。
* [Qwen 原生格式](/simidoc/zh/apps/api/images/qwen)：百炼官方区域端点、原生消息结构及结果 URL 保存。

比较接口、效果和 1K / 2K / 4K 规格，请看[图片 API 总览](/simidoc/zh/apps/api/images)。已有链接保留在此，具体调用以对应协议为准；不同协议的凭据、参数和返回字段不可混用。
