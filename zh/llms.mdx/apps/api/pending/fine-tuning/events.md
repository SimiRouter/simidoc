# 获取微调任务事件

分页读取微调任务的日志消息和训练指标。

**SimiRouter 暂不支持此接口。以下为 OpenAI 官方 API 参考，调用地址为 `api.openai.com`，需要 OpenAI 项目的密钥，不能使用 SimiRouter Key。**

## 接口说明

* **方法**：`GET`
* **接口地址**：`/v1/fine_tuning/jobs/{fine_tuning_job_id}/events`
* **鉴权**：`Authorization: Bearer $OPENAI_API_KEY`
* **请求类型**：无请求体。

返回普通JSON分页列表，不是SSE订阅。事件消息用于诊断，任务最终成功与否仍应查询[任务详情](/simidoc/zh/apps/api/pending/fine-tuning/retrieve)的 `status`。

## 请求参数

| 参数                   | 类型        | 必填 | 说明                                        |
| -------------------- | --------- | -- | ----------------------------------------- |
| `fine_tuning_job_id` | string，路径 | 是  | 任务ID；代码通过 `OPENAI_FINE_TUNING_JOB_ID` 读取。 |

| 参数      | 类型         | 必填 | 说明           |
| ------- | ---------- | -- | ------------ |
| `after` | string，查询  | 否  | 上一页最后一个事件ID。 |
| `limit` | integer，查询 | 否  | 每页事件数量，默认20。 |

## 返回值

| 字段                  | 类型               | 说明                           |
| ------------------- | ---------------- | ---------------------------- |
| `object`            | string           | 固定为 `list`。                  |
| `has_more`          | boolean          | 是否有后续页。                      |
| `data`              | array            | 当前页事件。                       |
| `data[].id`         | string           | 事件ID，用于分页。                   |
| `data[].object`     | string           | 固定为 `fine_tuning.job.event`。 |
| `data[].created_at` | integer          | 事件时间，Unix秒级时间戳。              |
| `data[].level`      | string           | `info`、`warn`或`error`。       |
| `data[].message`    | string           | 可读的事件描述。                     |
| `data[].type`       | string，可选        | `message`或`metrics`。         |
| `data[].data`       | object / null，可选 | 事件附加数据；指标字段取决于事件类型。          |

```json
{
  "object": "list",
  "data": [{
    "id": "ft-event-demo",
    "object": "fine_tuning.job.event",
    "created_at": 1793491200,
    "level": "info",
    "message": "Training started",
    "type": "message",
    "data": null
  }],
  "has_more": false
}
```

## 代码调用

运行要求：Python 3、Node.js 20 或更新版本、curl、Go 1.20 或更新版本。各语言示例分别保存为 `.py`、`.cjs`、`.sh`、`.go` 文件后运行。

设置 `OPENAI_API_KEY` 和 `OPENAI_FINE_TUNING_JOB_ID`。下一页使用当前页最后一个事件的ID作为`after`。

<Tabs items={["Python","Node.js","curl","Go"]}>
  <Tab value="Python">
    ```python
    import json
    import os
    import urllib.error
    import urllib.parse
    import urllib.request

    def required(name):
        value = os.environ.get(name)
        if not value:
            raise SystemExit(f"请设置 {name}")
        return value

    key = required("OPENAI_API_KEY")
    job_id = required("OPENAI_FINE_TUNING_JOB_ID")
    job_id_encoded = urllib.parse.quote(job_id, safe="")
    request = urllib.request.Request(
        f"https://api.openai.com/v1/fine_tuning/jobs/{job_id_encoded}/events?limit=20",
        method="GET",
        data=None,
        headers={"Authorization": "Bearer " + key},
    )
    try:
        with urllib.request.urlopen(request, timeout=120) as response:
            result = response.read()
    except urllib.error.HTTPError as error:
        raise SystemExit(f"HTTP {error.code}: {error.read().decode('utf-8', errors='replace')}")
    print(json.dumps(json.loads(result), ensure_ascii=False, indent=2))
    ```

    function required(name) {
      const value = process.env[name];
      if (!value) throw new Error(`请设置 ${name}`);

    }
    async function main() {
      const key = required("OPENAI_API_KEY");
      const job_id = required("OPENAI_FINE_TUNING_JOB_ID");
      const jobId = encodeURIComponent(job_id);
      const response = await fetch(`https://api.openai.com/v1/fine_tuning/jobs/${jobId}/events?limit=20`, {
        method: "GET",
        headers: { Authorization: `Bearer ${key}` },
        signal: AbortSignal.timeout(120000),
      });
      if (!response.ok) throw new Error(`HTTP ${response.status}: ${await response.text()}`);
      console.log(JSON.stringify(await response.json(), null, 2));
    }
    main().catch(error => { console.error(error.message); process.exitCode = 1; });

    ```go
    package main

    import (
    	"fmt"
    	"io"
    	"log"
    	"net/http"
    	"net/url"
    	"os"
    	"time"
    )

    func check(err error) {
    	if err != nil {
    		log.Fatal(err)
    	}
    }
    func required(name string) string {
    	value := os.Getenv(name)
    	if value == "" {
    		log.Fatal("请设置 " + name)
    	}
    	return value
    }
    func main() {
    	key := required("OPENAI_API_KEY")
    	job_id := required("OPENAI_FINE_TUNING_JOB_ID")
    	target := fmt.Sprintf("https://api.openai.com/v1/fine_tuning/jobs/%s/events?limit=20", url.PathEscape(job_id))
    	req, err := http.NewRequest("GET", target, nil)
    	check(err)
    	req.Header.Set("Authorization", "Bearer "+key)
    	client := &http.Client{Timeout: 120 * time.Second}
    	response, err := client.Do(req)
    	check(err)
    	defer response.Body.Close()
    	result, err := io.ReadAll(response.Body)
    	check(err)
    	if response.StatusCode < 200 || response.StatusCode >= 300 {
    		log.Fatalf("HTTP %d: %s", response.StatusCode, result)
    	}
    	fmt.Println(string(result))
    }
    ```

## 错误码

以下为 OpenAI 官方直连请求的常见 HTTP 错误，不是 SimiRouter 的支持状态。

| HTTP 状态码      | 含义                | 处理方式                                       |
| ------------- | ----------------- | ------------------------------------------ |
| `400`         | 参数、文件用途或资源状态不符合要求 | 读取 `error.message` 和 `error.param`，修正后再提交。 |
| `401`         | 密钥无效或缺失           | 检查 OpenAI 密钥及其所属项目。                        |
| `403`         | 无权访问项目或资源         | 检查项目、组织和角色权限。                              |
| `404`         | 文件、任务或模型不存在       | 核对 ID，并使用资源所属项目的密钥。                        |
| `429`         | 速率限制或额度不足         | 区分限流与额度错误；限流时退避，额度不足时不要重复提交。               |
| `500` / `503` | 服务端异常或暂不可用        | 保留请求 ID；写入请求先核对是否已创建资源，避免重复上传或重复训练。        |

非成功响应通常包含 `error.message`、`error.type`、`error.param` 和 `error.code`；字段可能为空。
