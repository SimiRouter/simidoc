# 其他能力与待接入参考

本节收录尚未作为 SimiRouter 通用能力开放的接口：嵌入、文件、微调、Realtime、审核与重排序。它们与已开通能力的差别不在协议难度，而在是否由网关提供路由、鉴权与计费。

## 概览

先看状态，再决定是否写代码。同在本节，不代表状态相同。

| 状态    | 含义                    | 现在可以做什么            |
| ----- | --------------------- | ------------------ |
| 明确不支持 | 网关不提供该能力，也不会因为更换域名而可用 | 只能按厂商直连参考，使用厂商 Key |
| 暂不支持  | 当前未开放，协议本身稳定          | 按厂商直连参考验证，不要写成网关调用 |
| 需确认渠道 | 是否可用取决于账户与渠道配置        | 先确认模型与路由，再决定是否依赖   |

## 核心概念

* **直连参考**：本节示例的地址与鉴权属于厂商。把 `api.openai.com` 换成网关域名不等于能力可用，路径、字段映射和权限都需要渠道明确支持。
* **Key 归属**：厂商 Key 与 SimiRouter Key 不互通。直连示例必须使用对应厂商的 Key，不能把网关 Key 填进去。
* **资源归属**：文件 ID、任务 ID、会话 ID 都由创建它们的项目或组织持有，跨厂商、跨项目不能直接复用。
* **状态与计费**：异步任务先返回 ID，再查询状态；创建成功不等于执行成功，取消任务也不代表已发生的用量被撤销。

## 能力清单

| 分类       | SimiRouter 状态 | 协议性质                     | 参考                     |
| -------- | ------------- | ------------------------ | ---------------------- |
| 嵌入       | 暂不支持          | 同步向量返回、独立批任务             | [嵌入](/simidoc/zh/apps/api/pending/embeddings)     |
| 文件管理     | 不支持           | 上传、列表、元数据、下载和删除          | [文件](/simidoc/zh/apps/api/pending/files)          |
| 微调       | 不支持           | 创建异步训练任务、状态与事件           | [微调](/simidoc/zh/apps/api/pending/fine-tuning)    |
| Realtime | 需确认专用渠道       | WebRTC / WebSocket 有状态会话 | [Realtime](/simidoc/zh/apps/api/pending/realtime) |
| 审核       | 需确认模型与路由      | 同步安全分类，不是聊天过滤保证          | [内容审核](/simidoc/zh/apps/api/pending/moderations)  |
| 重排序      | 需确认模型与路由      | 同步文档相关性排名                | [重排序](/simidoc/zh/apps/api/pending/rerank)        |

音乐接口另见 [音乐（不支持）](/simidoc/zh/apps/api/music)。实时会话、上传资源和训练任务通常涉及额外权限、存储与费用，应用接入前应明确数据保留与删除策略。
