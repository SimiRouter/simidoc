# Gemini CLI 安装

## **前置条件：安装 Gemini CLI**

确保已安装 Node.js（v20 或更高版本），然后通过 npm 全局安装：

```bash
npm install -g @google/gemini-cli
```

安装完成后，验证是否成功：

```bash
gemini --version
```

如需升级到最新版本：

```bash
npm upgrade -g @google/gemini-cli
```

## 配置模型服务

安装后按 [Gemini CLI 配置](/simidoc/zh/apps/gemini-config)设置 SimiRouter 地址与 API Key。
