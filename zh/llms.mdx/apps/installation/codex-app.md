# Codex 桌面端安装

## 下载与安装

1. 打开 [OpenAI Codex 官方页面](https\://chatgpt.com/codex)，选择适合操作系统的安装包。
2. 完成安装并打开应用。系统要求与可用安装包以官方页面为准。
3. 按 [Codex 桌面端设置](/simidoc/zh/apps/codex-desktop)合并模型提供商与密钥配置。

安装和配置完成后，先提交一个低风险任务，并到 SimiRouter 使用日志核对实际模型和用量。只打开应用或看见登录界面不能确认网关接入成功。
