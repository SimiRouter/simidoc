# CC Switch配置

## 下载 CC Switch

1. 打开 [CC Switch 下载页面](https\://github.com/farion1231/cc-switch/releases/latest)，在 GitHub Releases 中选择适合您操作系统的安装包并完成安装。

## 使用模型站内的导入功能

### 快捷导入 `Codex`

![SimiRouter 密钥菜单中的 CC Switch 导入入口](/simidoc/assets/cc_switch/cc1.png)

选择使用 Codex 模型分组的令牌，点击导入旁的小箭头，选择 CC Switch

填入供应商名与 Codex 模型
![填写 CC Switch 供应商名称和模型](/simidoc/assets/cc_switch/cc2.png)

在弹出的`此站点正在尝试打开 CC Switch。`提示中选择打开
![浏览器请求打开 CC Switch 的确认窗口](/simidoc/assets/cc_switch/cc3.png)

检查即将导入的供应商配置是否正确
![CC Switch 待导入供应商的配置预览](/simidoc/assets/cc_switch/cc4.png)

无误后选择导入
![在 CC Switch 中确认导入供应商](/simidoc/assets/cc_switch/cc5.png)

导入完成后，发送一条简短消息测试。若需在 IDE 中接入，可参考[第三方插件配置（VS Code Roo）](/simidoc/zh/apps/roo-code)中的字段说明，并使用当前账户可用的模型名称；不同插件的配置项可能不同。
![CC Switch 导入后的供应商配置页面](/simidoc/assets/cc_switch/cc6.png)

可在 CC Switch 中查看当前账户余额，按需充值，避免余额不足导致任务中断。
![CC Switch 的账户余额查询页面](/simidoc/assets/cc_switch/cc7.png)
