Qwen image generation

Synchronous image generation with the native Qwen request body through this site's gateway.

Endpoint overview

POST /v1/images/generations, with a JSON body. The examples use this site's gateway https://api.dwchainless.com and a key from this site for API_KEY; the request body follows Qwen's native model, input.messages, and parameters structure, and the response is always data[].

Text-to-image needs only text content items. Describe composition, visual style, and text to render in the input text.

Request parameters

FieldTypeRequiredDescription
modelstringYesqwen-image-2.0-pro or a specific version supported by this site's channel.
input.messagesobject[]YesA single-round user message, exactly one.
input.messages[].rolestringYesAlways user.
input.messages[].content[].textstringYesChinese or English instructions; only one text item per turn.
parameters.sizestringNoWidth × height, such as 2048 × 2048; the 2.0 series supports total pixels from 512×512 to 2048×2048.
parameters.nintegerNoDefault 1; the 2.0 series supports 1–6.
parameters.negative_promptstringNoContent you do not want, up to 500 characters.
parameters.prompt_extendbooleanNoDefault true; automatically expands the positive prompt.
parameters.watermarkbooleanNoWhether to add a visible watermark; follow applicable synthetic-content labeling requirements.

Image specifications: 1K, 2K and 4K

K is a common shorthand for resolution; it is not file size and does not indicate a quality parameter. Actual width and height vary by model and aspect ratio; at the same ratio, doubling the edge length quadruples total pixels. The following is background only and must not be treated directly as the available sizes for every model.

Qwen uses parameters.size to enter the width and height allowed by the model, in a format such as 2048*2048, not 2K directly. The 2.0 series also has a total-pixel limit; the 4K square illustration below does not mean that size can be submitted.

Resolution labelCommon pixel illustration (not a model support guarantee)
1KBoth edges ≤ 1024 pixels; e.g. 1024×1024.
2KLongest edge > 1024 and ≤ 2048 pixels; e.g. 1280×720.
4KEither edge > 2048 pixels; e.g. 2560×1440.

This site's per-image billing tiers are a separate rule; do not apply the illustrative labels above directly as billing standards. Image specifications and billing rules.

Response

FieldDescription
createdResponse generation timestamp.
data[].urlGenerated image URL; validity is determined by the channel, so download or copy promptly.
data[].b64_jsonSome channels return raw Base64; when present, decode and save directly.
data[].revised_promptPrompt rewritten by the channel; may be absent.
error / messageError code and description on failure.

Code examples

Fill in API_URL and API_KEY at the top of the code. API_URL uses this site's gateway address https://api.dwchainless.com/v1/images/generations, API_KEY uses a key from this site, and model availability is subject to Models and pricing. The examples use standard libraries only, send one request, and print the returned JSON; they do not download or save images automatically.

Agent invocation demo

Copy the task below to an agent that can run code locally and inspect returned results; first fill in API_URL and API_KEY directly in the example code according to this protocol configuration and confirm the model name. Do not put the key in the prompt.
