Gemini image editing and image-to-image

Combine reference images and editing instructions to generate modified images using Gemini’s native content structure.

Endpoint overview

POST /v1beta/models/{model}:generateContent accepts editing instructions and reference images together in parts for editing, image-to-image, style transfer, background replacement, or multi-image composition. There is no separate native /images/edits Gemini path.

The gateway URL is https://api.dwchainless.com, with the request header Authorization: Bearer $API_KEY . Direct Google access uses https://generativelanguage.googleapis.com, usually with x-goog-api-key: $GEMINI_API_KEY, not the gateway Bearer key. Select a model available to the account that supports the required capability.

Upload only images you are authorized to process. Editing does not guarantee pixel-perfect preservation of identities, text, trademarks, or product details. Manually inspect important content before use.

Request parameters

FieldTypeRequiredDescription
model (path)stringYesA Gemini image model supporting both generateContent and image output; not a text-only model.
contentsarrayYesMessage list; text-to-image usually needs one user message.
contents[].rolestringNouser; use model for model replies in conversation history.
contents[].parts[].textstringYesImage description or editing instructions.
generationConfig.responseModalitiesarrayNoFor example, ["TEXT","IMAGE"] to request text and images; available combinations vary by model.
generationConfig.imageConfig.aspectRatiostringNoRatios such as 1:1, 16:9, 9:16 where supported.
generationConfig.imageConfig.imageSizestringNoSizes such as 1K, 2K, or 4K where supported; match the selected model. Not all image models support them.
contents[].parts[].inlineDataobjectYes (inline reference image)A separate Part from text, containing mimeType and data.
inlineData.mimeTypestringYesThe reference image’s actual MIME type, such as image/png, image/jpeg, or image/webp.
inlineData.datastringYesPure Base64 reference-file bytes, without a data: prefix.
contents[].parts[].fileDataobjectConditionalAn alternative to inline content, requiring an authorized fileUri/mimeType accessible to the vendor.

Use one Part per image. Add image Parts for multiple references and explain each image’s purpose in text. Image-count, resolution, and multi-turn consistency limits vary by model; one fixed number does not cover every Gemini image model.

Image specifications: 1K, 2K and 4K

K is a common resolution label, not file size or a quality setting. Actual dimensions depend on the model and aspect ratio. At the same ratio, doubling both edges quadruples the pixel count. The examples below explain the terms; they are not universally accepted sizes.

Where supported, Gemini uses generationConfig.imageConfig.imageSize to select 1K, 2K or 4K, and generationConfig.imageConfig.aspectRatio for the ratio. Check the selected model for actual dimensions.

Resolution labelCommon pixel examples (not a model support guarantee)
1K1024×1024 · About one thousand pixels per edge
2K2048×2048 · About two thousand pixels per edge
4K4096×4096 / 3840×2160 · About four thousand pixels per edge

The site’s per-image billing tiers are separate rules; do not use these illustrative resolution labels as the billing standard. Image specifications and billing rules.

Request structure

Replace BASE64_IMAGE_BYTES with the pure Base64 of the authorized image.

Response

FieldTypeDescription
candidates[]arrayCandidate list; may be empty after safety filtering.
candidates[].content.parts[]arrayOrdered text, image, or thinking parts; do not read only the first item.
parts[].textstringExplanatory text; its presence is model-dependent.
parts[].inlineData.mimeTypestringThe actual image MIME type, such as image/png or image/jpeg.
parts[].inlineData.datastringPure Base64 image data, without a data: prefix.
parts[].thoughtbooleanOptional thinking-part flag; do not treat thought=true intermediate images as final output.
parts[].thoughtSignaturestringOptional opaque signature; preserve it unchanged for multi-turn editing rather than constructing or modifying it.
candidates[].finishReasonstringSTOP means normal completion; handle MAX_TOKENS, SAFETY, and other reasons separately.
promptFeedbackobjectOptional input-blocking information.
usageMetadataobjectInput, candidate, thinking, and total token usage; fields vary by model.

The Base64 above illustrates structure only. Use the actual MIME type when saving results. For multi-turn editing, append the complete previous model content to history, preserve opaque fields such as thoughtSignature, then add the next user edit. Do not copy image bytes alone and discard required signatures or modify those fields.

Native Gemini editing describes regions in natural language; OpenAI’s mask is not a universal parameter here. For precise region constraints, verify the selected model’s input support rather than inferring equivalent fields.

Code examples

Fill in API_URL and API_KEY at the top of the code; the examples use gemini-3-pro-image and replace BASE64_IMAGE_BYTES with the pure Base64 of the authorized image (no data: prefix). API_URL is the full request URL and defaults to the gateway https://api.dwchainless.com. The examples use standard libraries only, send one request, and print the returned JSON to stdout; they do not save images automatically.

Agent invocation demo

Copy this task to an agent that can run local scripts and inspect the response. Fill in API_URL, API_KEY, and MODEL directly in the example first using the protocol configuration. Never put the key in the prompt.

Errors

HTTP statusMeaning or vendor error typeAction
400INVALID_ARGUMENT and similar errorsCheck JSON, model parameters, media MIME type, and input length.
403PERMISSION_DENIEDCheck the key, project permissions, region, or billing restrictions.
404NOT_FOUNDCheck the model name and API version.
429RESOURCE_EXHAUSTEDCheck rate limits and quotas; use bounded backoff when retrying is appropriate.
500 / 503INTERNAL / UNAVAILABLERecord the request identifier and retry a limited number of times or later.

Google’s native error object contains error.code (HTTP number), error.status (enum name), and error.message, optionally with details. The gateway may return authentication, routing, or quota errors before contacting the vendor; an HTTP number alone does not establish an upstream error. Handle model refusals, missing images, non-STOP termination, and HTTP errors separately. Never pass off the input image as an edited result.
