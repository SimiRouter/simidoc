# DeepChat configuration

DeepChat is an open-source AI client for cloud and local models. Tool calling and other extensions require model and provider support.

* Official Website\: [https\://deepchat.thinkinai.xyz](https\://deepchat.thinkinai.xyz)
* GitHub repository\: [https\://github.com/ThinkInAIXYZ/deepchat](https\://github.com/ThinkInAIXYZ/deepchat)
* Download Address\: [https\://deepchat.thinkinai.xyz/#/download](https\://deepchat.thinkinai.xyz/#/download)

## Connect DeepChat manually

1. In SimiRouter, open [API key management](https://api.dwchainless.com/keys) page to copy the intended API key.

2. Open DeepChat **Settings → Provider settings** and select New API or add a compatible provider. **Set API URL to `https://api.dwchainless.com`** and paste the key.

   ![SimiRouter address and API key fields in DeepChat](/simidoc/assets/deepchat/simirouter-manual.png)

3. Validate the key, refresh or add models, enable the provider, and select an available model. Send a short message and verify the request in SimiRouter logs.

<Callout type="warn" title="Protect your key">
  Never expose keys in screenshots or share them with untrusted apps. Client labels may change across versions.
</Callout>
