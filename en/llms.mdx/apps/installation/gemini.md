# Gemini CLI Installation

## **Prerequisite\: Install Gemini CLI**

Make sure Node.js v20 or later is installed, then install Gemini CLI globally with npm\:

```bash
npm install -g @google/gemini-cli
```

After installation, verify that it works\:

```bash
gemini --version
```

To upgrade to the latest version\:

```bash
npm upgrade -g @google/gemini-cli
```

## Configure the model service

After installation, follow [Gemini CLI configuration](/simidoc/en/apps/gemini-config) to set the SimiRouter address and key.
