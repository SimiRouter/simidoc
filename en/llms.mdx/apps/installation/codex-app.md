# Install Codex desktop

## Download and install

1. Open [OpenAI Codex official page](https\://chatgpt.com/codex) and choose the package for your operating system.
2. Install and open the application. Available packages and system requirements follow the official page.
3. Follow [Codex desktop setup](/simidoc/en/apps/codex-desktop) to merge provider and key settings.

After setup, run a low-risk task and check the actual model and usage in SimiRouter logs. An open application or login screen does not verify gateway connectivity.
