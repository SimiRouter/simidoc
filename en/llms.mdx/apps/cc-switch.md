# CC Switch configuration

## Download CC Switch

1. Open [CC Switch downloads](https\://github.com/farion1231/cc-switch/releases/latest) on GitHub Releases, choose the installer for your operating system, and install it.

## Using the Built-in Import Feature

### Quick Import `Codex`

![CC Switch import entry in the SimiRouter key menu](/simidoc/assets/cc_switch/cc1.png)

Select the token under the Codex model group, click the small arrow next to Import, and choose CC Switch.

Fill in the provider name and Codex model\:
![Enter the CC Switch provider name and model](/simidoc/assets/cc_switch/cc2.png)

When prompted with `此站点正在尝试打开 CC Switch。`, click Open\:
![Browser confirmation to open CC Switch](/simidoc/assets/cc_switch/cc3.png)

Review the provider configuration to make sure it's correct\:
![Preview the provider configuration before import](/simidoc/assets/cc_switch/cc4.png)

Confirm and click Import\:
![Confirm provider import in CC Switch](/simidoc/assets/cc_switch/cc5.png)

After importing, send a short test message. For an IDE integration, see the field descriptions in [Third-party plugin configuration (VS Code Roo)](/simidoc/en/apps/roo-code) and use a model available to your account. Configuration fields may differ between plugins.
![Provider configuration after CC Switch import](/simidoc/assets/cc_switch/cc6.png)

You can check your current account balance directly in CC Switch and top up as needed to avoid interruptions caused by insufficient funds.
![Account balance lookup in CC Switch](/simidoc/assets/cc_switch/cc7.png)
