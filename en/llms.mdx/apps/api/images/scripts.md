# Image calling examples are now organized by protocol

Image calls no longer use a shared script tutorial that applies only to OpenAI Images. Choose the protocol you actually use. Each protocol page follows “Request format and parameters → Response parameters → Calling examples,” including image specifications, links to code in four languages, agent tasks, and safe saving workflows\:

* [OpenAI format](/simidoc/en/apps/api/images/openai)\: Images generation and editing, Responses conversational image generation, and image understanding.
* [Gemini native format](/simidoc/en/apps/api/images/gemini)\: GenerateContent text and image Parts, and saving Base64 images.
* [Qwen native format](/simidoc/en/apps/api/images/qwen)\: official Alibaba Cloud regional endpoints, native message structures, and saving result URLs.

For interface, effect, and 1K / 2K / 4K comparisons, see the [Image API overview](/simidoc/en/apps/api/images). This page preserves existing links; follow the relevant protocol for actual calls. Do not mix credentials, parameters, or response fields between protocols.
