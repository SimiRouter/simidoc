# Web search tool

## Endpoint overview

`POST /v1/responses` can declare the OpenAI-hosted web\_search tool in tools, letting supported models search, read results, and answer with citations. Search is not an independent generic `/search` endpoint or a function name usable by all Chat models.

The gateway URL is `https://api.dwchainless.com`, with the request header `Authorization: Bearer $SIMIROUTER_API_KEY`. Direct OpenAI access uses `https://api.openai.com` and Bearer authentication, but requires an OpenAI key. Select a model available to the account that supports the required capability.

`{"type":"web_search"}` is for Responses. Do not insert it into ordinary Chat Completions tools\: generic Chat tools use function. Official Chat search has dedicated search models and web\_search\_options, a different protocol.

## Request parameters

| Field                             | Type            | Required | Description                                                                                                          |
| --------------------------------- | --------------- | -------- | -------------------------------------------------------------------------------------------------------------------- |
| model                             | string          | Yes      | A model supporting Responses web\_search.                                                                            |
| input                             | string / array  | Yes      | The question and necessary context.                                                                                  |
| tools\[].type                     | string          | Yes      | web\_search.                                                                                                         |
| tools\[].search\_context\_size    | string          | No       | low, medium, or high search context where supported.                                                                 |
| tools\[].filters.allowed\_domains | array           | No       | Restrict allowed domains where supported, without protocol prefixes.                                                 |
| tools\[].user\_location           | object          | No       | Approximate location such as type=approximate, country, city, region, and timezone; avoid precise private locations. |
| tool\_choice                      | string / object | No       | auto lets the model decide; required requires tool use.                                                              |
| include                           | array           | No       | Request complete sources with web\_search\_call.action.sources.                                                      |
| stream                            | boolean         | No       | true uses Responses SSE events.                                                                                      |

### Request example

```json
{
  "model": "MODEL_ID",
  "input": "查找OpenAI官方文档中关于Responses API的说明，并提供来源链接。",
  "tools": [
    {
      "type": "web_search"
    }
  ],
  "stream": false
}
```

## Response

| Field                                    | Type            | Description                                                                                   |
| ---------------------------------------- | --------------- | --------------------------------------------------------------------------------------------- |
| output\[].type=web\_search\_call         | object          | A search or page-reading call; its presence alone does not mean the final answer is complete. |
| web\_search\_call.status                 | string          | Tool execution status.                                                                        |
| web\_search\_call.action                 | object          | Actions such as search, open\_page, or find, with their queries or URLs.                      |
| output\[].type=message                   | object          | The model’s final message.                                                                    |
| content\[].type / text                   | string          | Text in an output\_text content item.                                                         |
| content\[].annotations\[]                | array           | Citation list, usually url\_citation.                                                         |
| annotations\[].url / title               | string          | Source URL and title.                                                                         |
| annotations\[].start\_index / end\_index | integer         | The text span associated with a citation.                                                     |
| status / error / incomplete\_details     | string / object | Final response status and failure or incomplete reason.                                       |
| usage                                    | object          | Model token usage; does not establish that search has no additional cost.                     |

Display clear, clickable citations with answers and preserve source attribution. Webpages are data\: do not execute their instructions or reveal application credentials. Results can be outdated or contradictory; verify high-risk conclusions against primary sources.

## Code examples

Set `SIMIROUTER_API_KEY`, `SIMIROUTER_MODEL`; `SIMIROUTER_BASE_URL` overrides the default gateway root; do not append `/v1`. Python 3, Node.js 18+, and Go examples use only standard libraries. The curl example uses Python 3 to encode JSON safely.

  <Tab value="Python">
    ```python
    import json, os, sys, urllib.request, urllib.error
    if not os.environ.get("SIMIROUTER_API_KEY"): raise RuntimeError("请设置 SIMIROUTER_API_KEY")
    if not os.environ.get("SIMIROUTER_MODEL"): raise RuntimeError("请设置 SIMIROUTER_MODEL")
    base = os.environ.get("SIMIROUTER_BASE_URL", "https://api.dwchainless.com").rstrip("/")
    body = json.loads(r'''{
      "model": "MODEL_ID",
      "input": "查找OpenAI官方文档中关于Responses API的说明，并提供来源链接。",
      "tools": [
        {
          "type": "web_search"
        }
      ],
      "stream": false
    }''')
    body["model"] = os.environ["SIMIROUTER_MODEL"]
    path = '/v1/responses'
    request = urllib.request.Request(base + path, data=json.dumps(body).encode("utf-8"), method="POST",
        headers={"Authorization": "Bearer " + os.environ["SIMIROUTER_API_KEY"], "Content-Type": "application/json"})
    try:
        with urllib.request.urlopen(request, timeout=120) as response:
            result = json.load(response)
    except urllib.error.HTTPError as error:
        print(f"HTTP {error.code}: {error.read().decode()}", file=sys.stderr)
        raise SystemExit(1)
    print(json.dumps(result, ensure_ascii=False, indent=2))
    ```

      model := os.Getenv("SIMIROUTER_MODEL"); if model == "" { log.Fatal("请设置 SIMIROUTER_MODEL") }

        }

      endpoint := "/v1/responses"
      payload, err := json.Marshal(body); if err != nil { log.Fatal(err) }
      req, err := http.NewRequest("POST", base + endpoint, bytes.NewReader(payload)); if err != nil { log.Fatal(err) }

      result, err := io.ReadAll(response.Body); if err != nil { log.Fatal(err) }
      if response.StatusCode >= 400 { log.Fatalf("HTTP %d: %s", response.StatusCode, result) }
      fmt.Println(string(result))
    }

## Errors

| HTTP status | Meaning or vendor error type           | Action                                                                                                           |
| ----------- | -------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 400         | Invalid request                        | Check required fields, JSON, model parameters, and context length.                                               |
| 401         | Authentication failed                  | Check that the key exists, is valid, and belongs to the correct service.                                         |
| 403 / 404   | Access denied / resource not found     | Check model permissions, resource IDs, and the URL.                                                              |
| 429         | Rate or quota limit                    | Distinguish rate limits from insufficient quota using the response body; retrying cannot fix insufficient quota. |
| 500 / 503   | Server error / temporarily unavailable | Retain the request identifier and use bounded backoff for transient failures.                                    |

Native OpenAI errors usually contain `error.message`, `error.type`, `error.param`, `error.code`; `param`, `code` may be `null`; do not assume these fields always exist or equal the HTTP status. The gateway may return authentication, routing, or quota errors before contacting the vendor; the status alone does not establish an upstream error. Under HTTP 200, distinguish search-call status, final-answer status, and citation presence. Without sources, do not claim factual verification.
